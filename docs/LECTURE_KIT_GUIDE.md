# Windows 휴대용 강의키트

## 공식 실행 방식

공식 방식은 `.cmd` 실행 파일과 Node.js 공식 Windows x64 휴대용 ZIP 런타임의 조합이다. 별도 EXE 래퍼, 관리자 권한, 시스템 Node.js 설치, PowerShell 실행 정책 변경은 요구하지 않는다.

## 소스 모드

`강의_실행.cmd`는 package/lock/Node 버전 지문이 달라졌을 때만 `npm ci`를 실행하고, 최신 학생용·강사용·PDF 빌드를 검사한 뒤 로컬 허브를 연다.

- 실행: `강의_실행.cmd` 또는 `npm run lecture`
- 상태: `강의키트_상태확인.cmd` 또는 `npm run lecture:status`
- 종료: `강의_종료.cmd` 또는 `npm run lecture:stop`

## 휴대용 키트 생성

기본 생성은 clean working tree에서만 허용한다.

```text
강의키트_생성.cmd
```

검토 중인 미커밋 소스로 생성해야 할 때만 명시적으로 다음을 사용한다.

```text
강의키트_생성.cmd --allow-dirty
```

출력은 `release/AI_건축디자인_강의키트_windows_x64/`와 같은 이름의 ZIP이다. 생성 실패 시 기존 키트를 교체하지 않으며, 성공 교체 시 직전 버전 하나만 `.backup`으로 보존한다.

## 로컬 경계

세 서버는 모두 `127.0.0.1`에만 바인딩된다. 학생용 사이트에는 강사 콘솔, 프로젝터 제어 코드, 강사 YAML과 메모 본문이 포함되지 않는다. 정적 서버는 경로 이탈, `.git`, `.env`, `source`, YAML 및 로컬 강사 메모 경로 접근을 거부한다.

## 강사 소개·과정 안내와 발표 화면

강의 허브의 `강의 시작` 버튼은 강사 소개 1장과 과정 안내 17장을 하나의 연속 덱으로 연다. 강사 소개 다음에는 과정 안내 첫 장이 나오며, 과정 안내 마지막 장에서 제1차시를 직접 선택한다. 제1차시는 자동으로 시작하지 않는다. 강사 소개는 강사용 로컬 빌드에만 있다.

- 통합 시작 콘솔: 강사 사이트의 `/instructor-console/lecture-start/`
- 통합 시작 프로젝터: 강사 사이트의 `/presentation/lecture-start/`
- 학생용 과정 안내 e-book: 학생 사이트의 `/course-overview/`

기존 강사 소개와 과정 안내 데이터는 각각 재사용하며, 통합 시작 덱의 고정 순서는 `instructor-introduction` → `course-overview-title` → 과정 안내 나머지 슬라이드이다. 콘솔의 이전·다음 또는 차시 선택으로 강사 소개와 과정 안내 사이를 오갈 수 있고, 마지막 장에서는 콘솔과 프로젝터가 각자의 제1차시 화면으로 이동한다.

프로젝터 화면은 세로 스크롤이 없는 16:9 슬라이드 방식이다. 오른쪽·왼쪽 방향키, `Space`, `PageDown`, `PageUp`, `Home`, `End`로 이동하고 `Esc`로 전체 슬라이드 목록을 연다. `F` 또는 화면의 전체화면 버튼으로 브라우저 전체화면을 전환한다.

### 고정 슬라이드 manifest

강사용 빌드는 1280×720을 최소 안전 화면으로 사용해 과정 안내와 각 차시를 한 번만 분할하고, 그 결과를 고정 slide manifest로 강사 콘솔과 프로젝터 페이지에 함께 기록한다. 1920×1080을 포함한 다른 화면 크기에서는 슬라이드를 다시 나누지 않고 CSS 크기와 여백만 조정하므로 슬라이드 수, 순서, `slideId`, `slideIndex`와 내용 범위가 동일하다.

동기화 메시지는 `buildId`, `deckId`, `lessonId`, `slideId`, `slideIndex`, `timestamp`를 포함한다. 강사 콘솔과 프로젝터는 같은 `buildId`와 `deckId`의 동일한 `slideId`만 동기화하며, 섹션 내 상대 위치를 이용한 근사 이동은 사용하지 않는다. 강의 콘텐츠나 발표 스타일을 변경한 뒤에는 강사용 빌드를 다시 생성해 manifest를 갱신한다.

## 강사 빠른 수정

강사 콘솔에서는 현재 슬라이드의 제목, 문장, 목록 항목과 이미지 캡션을 plain text로 임시 수정할 수 있다. 저장 즉시 같은 브라우저 프로필의 프로젝터 화면에 동기화되며, HTML과 script 입력은 실행되지 않고 문자 그대로 표시된다.

- 저장 위치: 강사용 브라우저의 `localStorage`
- 공개 e-book·PDF·소스 MDX 반영: 안 됨
- 다른 PC 자동 이동: 안 됨
- 백업·이동: 강사 콘솔에서 JSON 내보내기·가져오기 사용
- 정식 반영: 내보낸 변경 목록을 검토한 뒤 소스에 별도 반영

다른 Git SHA에서 내보낸 JSON은 자동 적용하지 않고 확인 경고를 표시한다. 브라우저 데이터 삭제나 다른 PC 이동 전에 JSON을 내보내 보관한다.

## 강사 수업 진행 체크

차시별 강사 콘솔은 `durationMinutes`와 기존 `timePlan`을 읽어 3시간·6시간 수업의 경과시간, 권장 누적시간, 남은 시간과 주요 체크포인트를 표시한다. 슬라이드와 시간표의 정확한 문구 연결이 없으면 시간을 추정하지 않고 `권장 시간 미매핑`으로 표시한다.

- 저장 위치: 강사 브라우저의 `localStorage`
- 일반적인 휴식: 수업 시간에 포함하므로 타이머를 멈추지 않음
- 일시정지: 기기 장애나 긴급 상황으로 강의 전체가 중단될 때만 사용
- 로컬 조정: 현재 브라우저의 후속 체크포인트에만 적용되며 MDX·PDF·공개 e-book을 변경하지 않음

## 강사 전용 자산

강사 프로필 사진과 INFOREST 로고는 `instructor-content/assets/profile/`에 두고 Git에 추적하지 않는다. 강사용 빌드 시 `dist-instructor/instructor-assets/profile/`에만 복사하며, 두 파일 중 하나라도 없으면 강사용 빌드를 명확한 오류로 중단한다. 학생용 빌드와 PDF는 이 자산을 참조하거나 복사하지 않는다.

## ZIP 무결성

ZIP 자체의 실제 SHA-256은 인접한 `.zip.sha256` 파일에 기록한다. ZIP 내부 파일이 자기 자신을 포함한 ZIP 해시를 그대로 포함하는 것은 순환 참조라 불가능하므로, `BUILD_INFO.json.portableZipSha256`은 해당 외부 검사 파일명을 기록한다.
