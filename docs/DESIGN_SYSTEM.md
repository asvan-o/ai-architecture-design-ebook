# 디자인 시스템

## 1. 방향

건축사무소 포트폴리오의 절제된 정보 표현과 교육용 편집 디자인의 읽기 구조를 결합합니다. 장식보다 본문 가독성, 정보 위계, 긴 학습 시간의 피로 감소를 우선합니다.

## 2. 시각 원칙

- 밝은 종이색 배경과 진한 먹색 텍스트
- 넓은 여백과 큰 제목
- 선과 번호를 사용한 편집 구조
- 직각에 가까운 패널과 제한적인 pill 배지
- 작은 화면에서는 정보 열을 순차적으로 재배치
- 의미 없는 애니메이션 없음

네온 그라데이션, 글래스모피즘, 과도한 둥근 카드, 복잡한 장식 배경은 사용하지 않습니다.

## 3. 색상 토큰

| 토큰 | 값 | 용도 |
| --- | --- | --- |
| `--paper` | `#f4f1ea` | 기본 배경 |
| `--paper-deep` | `#e9e5dc` | 보조 배경 |
| `--surface` | `#fbfaf7` | 콘텐츠 표면 |
| `--ink` | `#18201d` | 본문과 강조 배경 |
| `--muted` | `#68706b` | 보조 텍스트 |
| `--line` | `#c9cbc4` | 일반 구분선 |
| `--line-dark` | `#8f958e` | 강한 구분선 |
| `--accent` | `#bd4b2d` | 번호, 진행률, 주요 강조 |
| `--blue` | `#315b66` | 비교/시연 보조색 |

## 4. 타이포그래피

- 본문: Pretendard → Noto Sans KR → 시스템 sans-serif
- 큰 제목: Noto Serif KR → Nanum Myeongjo → Georgia
- 기본 본문: 약 17px, 행간 1.75
- 큰 제목: `clamp()`로 화면 폭에 맞춰 확대
- 작은 라벨은 영문 대문자와 자간으로 보조 정보임을 표현

외부 웹폰트 요청 없이 시스템 폰트를 사용합니다.

## 5. 레이아웃

- 데스크톱: 고정 왼쪽 목차 + 가변 본문
- 태블릿/모바일: sticky 상단 바 + modal 목차
- 본문 최대 폭: 약 73rem
- 일반 페이지 최대 폭: 약 83rem
- 강의 섹션은 선으로 구분하고 충분한 세로 간격 유지

## 6. 상태 배지

`StatusBadge.astro`는 콘텐츠 유형, 작성 방식, 검증 상태, 최신성, 위험도, 전문가 검토를 각각 표시합니다. 한 콘텐츠에 여러 배지를 동시에 사용할 수 있으며, 색상은 상태를 보조하지만 텍스트 레이블을 항상 함께 표시합니다. `pending`은 안전이나 검토 불필요를 뜻하지 않는 “검토 대기” 상태입니다.

## 7. 접근성

- 모든 상호작용 요소에 3px 포커스 표시
- 본문 바로가기 링크 제공
- 현재 페이지에 `aria-current="page"` 사용
- 모바일 목차와 검색에 dialog 의미 제공
- 이미지 placeholder에 대체 설명 제공
- 키보드로 검색 열기: Ctrl/Cmd + K
- `prefers-reduced-motion` 대응

## 8. 반응형 기준

- 1060px: 사이드바 폭 축소
- 820px: 고정 사이드바를 모바일 상단 메뉴로 전환
- 700px 전후: 복수 열 콘텐츠를 단일 열로 전환

새 컴포넌트는 360px 모바일 폭과 프로젝터 환경에서 모두 읽을 수 있는 크기를 기준으로 검토합니다.
