## A. COURSE OVERVIEW

제1차시 전에 독립 페이지로 존재하며 차시 번호에 포함하지 않는다.

1. 이번 과정에서 배우는 것 — 실무자료에서 시작해 디자인 시각화·도면·3D·검증·결과보고로 이어지는 건축·인테리어 AI Workflow를 경험합니다.
2. AI와 디자이너의 역할 — AI는 제안하고, 디자이너는 판단한다.
3. 전체 Workflow — 현재 합의한 방향을 보여줍니다. 세부 차시와 일정은 검토 후 확정합니다.
4. 도구별 역할 — 아래는 이 과정에서의 역할 배치입니다. 도구별 성능이나 전문 판단을 보장하는 설명은 아닙니다.
5. 반복하는 기본 Workflow — 한 번의 생성으로 끝내지 않고, 원자료와 결과를 비교하며 다시 판단합니다.
6. 안전한 AI 활용 원칙 — 입력 권한을 확인하고, 확인되지 않은 내용을 사실로 확정하지 않습니다.
7. 과정 후반 실무 프로젝트 집중 실습 — 수강생 실무자료를 바탕으로 분석·시각화·검증을 연결합니다. 프로젝트 시간과 세부 운영은 검토 중입니다.
8. 최종 산출물 — 만든 결과와 사람이 판단한 과정을 함께 남깁니다.

사용자 지정 Workflow 순서를 반영했다. 초기 요청 분석은 먼저 하고 RFP/Design Brief는 첫 시각화 뒤 정식 요구조건으로 발전시키는 위치다. 도구별 역할은 과정 계획이며 실제 성능/전문 판단 보장이 아니다. 후반 프로젝트 시간을 확정하지 않았다.
