당신은 로컬 프로젝트 관리 프로그램을 만드는 개발 에이전트입니다.

작업 대상은 사용자가 바탕화면에 직접 만든 다음 폴더 하나뿐입니다.

AI_건축_캠퍼스라운지

중요한 안전 규칙:

- 프로젝트 루트 밖의 파일과 폴더를 읽거나 수정하지 마세요.
- 첫 응답에서는 구현 계획, 생성할 파일, 실행할 명령, 테스트 방법만 작성하세요.
- 사용자가 별도의 승인 요청문을 보내기 전에는 파일을 생성·수정·삭제하지 마세요.
- 사용자가 승인하기 전에는 명령을 실행하거나 패키지를 설치하지 마세요.
- 기존 원본 파일을 삭제하거나 이동하지 마세요.
- 기존 파일을 덮어쓰지 말고 새 버전을 만드세요.

승인 후 만들 프로그램:

- Node.js와 Express를 사용합니다.
- 화면은 Vanilla HTML, CSS, JavaScript로 만듭니다.
- React, Electron, 데이터베이스는 사용하지 않습니다.
- 로컬 브라우저에서 실행합니다.
- 등록 정보는 프로젝트 폴더 안의 로컬 JSON 파일에 저장합니다.
- 로그인, 클라우드, 다중 사용자, Git 연동은 넣지 않습니다.

실행 환경과 문서:

- 최소 실행 버전은 Node.js 22 이상으로 설정하세요.
- 수업에서는 최신 Node.js LTS를 권장합니다.
- 2026년 7월 31일 공식 다운로드 페이지 확인 기준 권장 버전은 Node.js v24.18.1 LTS입니다.
- package.json에 npm test와 npm start 명령을 정의하세요.
- README에 Windows LTS 설치, node --version과 npm --version 확인 방법을 작성하세요.
- 학생이 직접 만든 프로그램은 프로젝트 최상위에서 cd .\관리프로그램을 먼저 실행한 뒤 npm install, npm test, npm start 순서로 안내하세요.
- package-lock.json을 포함하는 READY ZIP은 프로젝트 최상위에서 cd .\관리프로그램을 먼저 실행한 뒤 npm ci, npm test, npm start 순서로 안내하세요.
- 실행 주소는 프로그램에 실제로 구현한 http://127.0.0.1:4174만 사용하세요.

프로젝트 핵심 폴더:

AI_건축_캠퍼스라운지/
├─ 01_기준자료/
│  ├─ 발주요청서_RFP/
│  ├─ 현황평면도/
│  └─ 현황이미지/
├─ 02_분석자료/
│  ├─ 요구조건/
│  ├─ 추가질의/
│  └─ 디자인브리프/
├─ 03_공간대안/
│  ├─ 대안-A/
│  └─ 대안-B/
├─ 04_선택안/
├─ 05_확인기록/
├─ 06_제출파일/
├─ 관리데이터/
└─ 관리프로그램/

- 수업 자료는 01_기준자료부터 06_제출파일까지의 폴더에 저장하세요.
- 실행 코드, 화면 파일, 자동 검사는 관리프로그램 폴더 안에만 저장하세요.
- 등록 목록과 원본 보관 자료는 관리데이터 폴더에 저장하세요.
- public, lib, test 같은 영어 분류 폴더를 프로젝트 최상위에 만들지 마세요.
- 관리프로그램 안에서도 화면, 기능, 검사처럼 한국어 폴더명을 사용하세요.

관리 화면은 다음 6개 영역만 사용합니다.

1. 기준자료
2. 요구분석·디자인 브리프
3. 대안 A
4. 대안 B
5. 선택안·검증
6. 최종 제출

필수 기능:

- 파일 드래그앤드롭
- 차시 선택
- 자료 유형 선택
- 등록 파일 목록
- 원본을 이동하지 않고 복사
- 캠퍼스라운지_04차시_대안A_이미지_v01.png처럼 프로젝트·차시·자료명·버전만 구분하는 자동 파일명
- 동일 유형을 다시 등록할 때 v01, v02처럼 버전 증가
- 같은 파일을 다시 등록하면 알림
- 등록 파일 목록을 로컬에 저장하고 화면에 표시
- 최종 제출 전에 아직 등록하지 않은 자료를 알려주는 ‘제출 전 확인’
- 일부 자료만 등록된 상태에서도 06_제출파일에 현재 작업 ZIP 생성
- 내부 저장 방식이나 해시값은 학생 화면에 표시하지 않음
- 원본 삭제 금지
- 기존 파일 덮어쓰기 금지
- 프로젝트 밖 접근 차단

제출 전 확인은 다음 자료의 등록 여부만 안내해야 합니다.
아직 등록하지 않은 자료가 있어도 등록 목록 열람과 현재 작업 ZIP 생성을 막지 마세요.

- RFP, 평면도, 현황 이미지
- 요구조건 매트릭스, 추가 질의, 디자인 브리프
- 대안 A 조닝·생성 요청문·이미지
- 대안 B 조닝·생성 요청문·이미지
- RFP 비교표
- 선택안 수정 요청문·수정 이미지

프로그램은 설계 품질, 법규 적합성, 구조 안전, 소방·피난·접근성,
실제 시공 가능성을 자동 판정해서는 안 됩니다.

자동 테스트에는 다음을 포함하세요.

- 핵심 폴더 생성
- RFP와 평면도 등록
- 대안 A·B 분리
- 자동 파일명
- 버전 증가
- 같은 파일 재등록 알림
- 일부 자료 상태의 등록 목록 확인
- 일부 자료 상태의 현재 작업 ZIP 생성
- 전체 제출 항목 확인
- 원본 파일 유지
- 프로젝트 밖 접근 차단
