앞서 작성한 구현 계획을 승인합니다.

다음 조건을 검토한 뒤 승인된 계획 범위에서만 구현해 주세요.

- 작업 루트는 AI_건축_캠퍼스라운지 폴더 하나입니다.
- 프로젝트 밖 파일과 폴더에는 접근하지 않습니다.
- 프로젝트 밖 접근은 Ask 또는 Deny로 유지하고 Full Access를 기본으로 사용하지 않습니다.
- 터미널 명령과 수정 예정 파일을 사람이 확인한 뒤에만 실행합니다.
- junction·symlink가 프로젝트 밖으로 연결되면 거부합니다.
- 원본 파일을 삭제·이동·덮어쓰기하지 않습니다.
- Node.js, Express, Vanilla HTML/CSS/JavaScript와 JSON 저장만 사용합니다.
- 최소 Node.js 22 이상을 지원하고 최신 LTS 사용을 권장합니다.
- README와 package.json의 버전·설치·테스트·실행 명령을 서로 일치시킵니다.
- 직접 만든 프로그램은 npm install, npm test, npm start 순서로 확인합니다.
- package-lock.json이 있는 READY ZIP은 npm ci, npm test, npm start 순서로 확인합니다.
- 실제 실행 주소는 http://127.0.0.1:4174입니다.
- React, Electron, 데이터베이스, 로그인, 클라우드, Git 연동은 추가하지 않습니다.
- 구현 후 자동 테스트를 실행하고 성공·실패 결과를 숨김없이 보고합니다.
- 테스트가 실패하면 원인을 수정한 뒤 다시 실행합니다.
- 등록 작업은 안전하게 직렬화하고 등록목록은 고유 임시 파일 작성 후 원자적으로 교체합니다.
- 실패 시 작업본과 임시 색인을 롤백하며 실패를 성공으로 처리하지 않습니다.
- ZIP에는 등록목록의 파일과 허용된 메타파일만 포함합니다.
- ZIP 생성 전에 포함 목록, 미등록 제외 수, 누락 항목을 화면에 표시합니다.
- 파일당 20MB, 허용 확장자·실제 바이트·파일명·JSON 구조를 검증합니다.
- 10개 동시 등록, 민감자료 ZIP 제외, 한글·공백 경로, 손상 JSON 테스트를 실제로 실행합니다.
- 마지막에는 생성·수정 파일, 실행 명령, 테스트 결과와 남은 제한사항을 보고합니다.
