첨부한 이미지들을 활용하여
**9:16 세로형 건축·인테리어·디자인 포트폴리오의 COVER PAGE를 제작해 주세요.**

이 포트폴리오는 한 장으로 끝나는 디자인이 아니라
**COVER PAGE → 2PAGE → 3PAGE → 이후 페이지로 이어지는 하나의 연속된 포트폴리오 시리즈**입니다.

따라서 이번 표지는 독립적인 포스터처럼 디자인하지 말고,
이후 페이지까지 일관되게 확장할 수 있는 **공통 디자인 시스템의 기준 페이지**로 제작해 주세요.

# 0. PORTFOLIO COMMON DESIGN SYSTEM

아래 디자인 시스템은 이번 COVER PAGE뿐 아니라
**이후 제작할 모든 포트폴리오 페이지에서 공통으로 유지할 기준**입니다.

페이지별 콘텐츠와 레이아웃은 달라질 수 있지만
전체 Visual Identity는 변경하지 마세요.

---

## 0-1. PAGE FORMAT

**9:16 Portrait**

모든 포트폴리오 페이지는 동일한 9:16 세로형 비율을 유지합니다.

---

## 0-2. DESIGN DIRECTION

전체 포트폴리오는 다음 디자인 언어를 유지합니다.

- Architectural Editorial Design
- High-end Architecture Portfolio
- Minimal
- Contemporary
- Sophisticated
- Premium
- Quiet
- Refined
- Professional
- Clean Grid
- Generous Negative Space
- Restrained Typography
- Image-driven Composition

화려한 장식보다

**절제 / 여백 / 정렬 / 프로젝트 이미지의 힘**

을 우선합니다.

광고 포스터, 카드뉴스, SNS 홍보물, 부동산 분양 광고처럼 보이지 않도록 합니다.

---

## 0-3. BACKGROUND SYSTEM

포트폴리오의 기본 Background Tone은

**Warm Off-White 또는 프로젝트 이미지와 조화되는 매우 밝은 Neutral Tone**

을 기준으로 합니다.

단, PROJECT IMAGE가 Full-bleed로 사용되는 페이지에서는
배경색을 억지로 노출할 필요는 없습니다.

이후 페이지에서도 동일하거나 매우 유사한 Background Tone을 유지하세요.

페이지마다 새로운 배경 테마를 만들지 마세요.

---

## 0-4. TYPOGRAPHY SYSTEM

전체 포트폴리오에서 동일한 Typography 계열을 유지하세요.

현대적인 Sans-serif Typography를 사용합니다.

한글:

- Pretendard
- SUIT

와 유사한 현대적인 스타일

영문:

- Helvetica
- Neue Haas Grotesk
- Inter

와 유사한 스타일

Font Weight:

- Regular
- Medium
- SemiBold

정도로 제한합니다.

Bold / Extra Bold / Black Weight를 과도하게 사용하지 마세요.

Typography의 크기보다 다음 요소의 완성도를 우선합니다.

- Alignment
- Letter Spacing
- Line Spacing
- Margin
- Negative Space

페이지마다 다른 서체 분위기를 사용하지 마세요.

---

## 0-5. COLOR SYSTEM

전체 포트폴리오의 Color System은 다음을 기본으로 합니다.

BACKGROUND / BASE
= Warm Off-White 또는 밝은 Neutral Tone

PRIMARY TEXT
= Dark Charcoal

SECONDARY TEXT
= Medium Gray

ACCENT COLOR
= PROJECT IMAGE에서 추출한 절제된 색상 1개만 사용 가능

Accent Color는 다음 정도에만 제한적으로 사용할 수 있습니다.

- Small Section Label
- Thin Line
- Page Number
- Small Graphic Point

페이지마다 새로운 Accent Color를 만들지 마세요.

---

## 0-6. GRID / MARGIN / SPACING SYSTEM

모든 페이지에서 동일한 편집 시스템을 유지합니다.

- 좌우 기본 Margin의 비율 유지
- 상하 여백의 시각적 기준 유지
- 동일한 Alignment 원칙
- 일정한 Image Gap
- 일정한 Text / Image Spacing
- 정돈된 Architectural Editorial Grid
- 충분한 Negative Space

페이지마다 Layout은 달라질 수 있지만
**Margin과 Grid의 디자인 언어는 동일하게 유지**하세요.

---

## 0-7. IMAGE TREATMENT SYSTEM

PROJECT IMAGE는 포트폴리오 전체에서
가장 중요한 시각 요소입니다.

다음 원칙을 공통으로 유지하세요.

- 이미지 중심 구성
- 과도한 Shadow 금지
- Glow 금지
- 불필요한 Decorative Frame 금지
- 카드뉴스식 이미지 박스 금지
- 이미지 간 여백을 정교하게 유지
- 원본 이미지의 핵심 디자인 보존
- 필요한 경우 Crop / Scale / Position 조정 가능

이미지가 Graphic Element보다 우선해야 합니다.

---

## 0-8. LOGO TREATMENT SYSTEM

`LOGO.png`는 전체 포트폴리오에서
**BRAND / DESIGNER LOGO ONLY**로 사용합니다.

- 로고 재디자인 금지
- 원본 형태와 비율 유지
- 배경 패턴으로 사용 금지
- 건축 또는 인테리어 디자인 모티프로 사용 금지
- 대형 워터마크 사용 금지
- 큰 Logo Card 생성 금지

필요한 페이지에서는
하단 또는 모서리에 작은 브랜드 서명처럼 사용하세요.

로고의 크기와 표현 방식은 전체 포트폴리오에서 일관되게 유지하세요.

## 0-9. PAGE CONTINUITY RULE

이번 COVER PAGE에서 확정된

- Typography

- Accent Color
- Margin
- Grid

중요:

**통일성은 모든 페이지의 Layout을 똑같이 만드는 것을 의미하지 않습니다.**

페이지 목적에 따라

- 이미지 크기
- 이미지 개수
- Column 수
- Text / Image 비율
- Diagram 위치

등은 달라질 수 있습니다.

하지만 디자인 시스템 자체는 변경하지 마세요.

# 1. 이번 페이지 목적 — COVER PAGE

이번 작업은 프로젝트 소개 페이지,
인테리어 상세 페이지, 재료 설명 페이지가 아닙니다.

**오직 포트폴리오의 첫 번째 페이지인 COVER PAGE를 제작하는 작업입니다.**

새로운 건축물이나 새로운 인테리어 디자인을 생성하지 말고,
내가 제공한 프로젝트 이미지와 로고를 활용하여

**전문 건축·인테리어·디자인 스튜디오의 고급 포트폴리오 표지처럼 편집·디자인해 주세요.**

# 2. 첨부 SOURCE 구분

첨부 이미지 중 파일명이

`LOGO.png`

인 이미지는 **BRAND / DESIGNER LOGO**입니다.

`LOGO.png`를 제외한 나머지 첨부 이미지는 모두
**동일 프로젝트의 PROJECT SOURCE IMAGE**입니다.

PROJECT SOURCE IMAGE의 파일명은 중요하지 않습니다.

먼저 모든 PROJECT SOURCE IMAGE를 분석한 후
**표지에 가장 적합한 이미지를 선택하여 사용하세요.**

---

# 3. PROJECT IMAGE 선택 규칙

첨부된 이미지를 모두 표지에 넣을 필요는 없습니다.

가장 중요한 목표는

**“첨부 이미지를 최대한 많이 사용하는 것”이 아니라**
**“가장 완성도 높은 COVER PAGE를 만드는 것”입니다.**

다음 순서로 판단하세요.

## A — SINGLE HERO COVER

첨부 이미지 중 가장 시각적으로 강하고
표지에 적합한 이미지 1장을 선택하여

**MAIN HERO IMAGE**

로 크게 사용하세요.

한 장만 사용하는 것이 더 세련된 경우
다른 이미지들은 사용하지 않아도 됩니다.

## B — HERO + SUPPORTING IMAGE

두 번째 이미지가 표지 디자인의 완성도를 실제로 높이는 경우에만

- MAIN HERO IMAGE 1장
- SUPPORTING IMAGE 1장

정도로 사용할 수 있습니다.

SUPPORTING IMAGE는 HERO보다 훨씬 작게 사용하며
HERO를 보조하는 역할만 해야 합니다.

### 중요

- 첨부 이미지를 모두 사용해야 하는 것은 아닙니다.
- 필요하지 않으면 1장만 사용하세요.
- 여러 이미지를 동일한 크기로 나열하지 마세요.
- 사진 콜라주처럼 만들지 마세요.
- 갤러리 페이지처럼 만들지 마세요.
- 인테리어 소개 페이지처럼 만들지 마세요.
- 재료 상세 페이지처럼 만들지 마세요.

# 4. LOGO 사용

`LOGO.png`

= **BRAND / DESIGNER LOGO ONLY**

로고는 PROJECT IMAGE가 아닙니다.

- HERO IMAGE 후보에서 제외
- SUPPORTING IMAGE 후보에서 제외
- 디자인 스타일 참고 이미지로 사용 금지
- 배경 패턴으로 사용 금지
- 프로젝트 이미지 안에 합성 금지
- 건축 또는 인테리어 디자인 요소로 재해석 금지
- 로고 재디자인 금지
- 원본 형태와 비율 유지

로고는 표지 하단 또는 모서리에
**작은 브랜드 서명처럼 절제된 크기로 배치**하세요.

로고가 PROJECT TITLE이나 HERO IMAGE보다 강하게 보이면 안 됩니다.

로고 주변에 별도의 큰 흰색 카드나 사각형 박스를 만들지 마세요.

# 7. 표지 텍스트 위계

시각적 우선순위는 다음과 같이 설정하세요.

## PROJECT TITLE

가장 중요한 메인 타이틀.

하지만 화면을 압도할 정도로 크게 만들지 마세요.

## SUB TITLE

PROJECT TITLE 아래 또는 주변에 배치되는 작은 보조 텍스트.

## PROJECT TYPE

가장 작은 Category / Label 성격의 텍스트.

## DESIGNER / COMPANY

가장 작은 Designer / Company 정보.

가능하면 텍스트를 하나의 정돈된 Title Group으로 묶으세요.

텍스트를 화면 여러 곳에 불필요하게 흩어놓지 마세요.

---

# 8. TITLE 표현 규칙

모든 주요 텍스트는 기본적으로 **가로 방향**으로 사용하세요.

금지:

- PROJECT TITLE 세로쓰기
- 글자 90도 회전
- 페이지 전체 높이에 걸친 거대한 제목
- 화면의 절반 이상을 차지하는 타이포그래피
- PROJECT IMAGE보다 강한 제목
- 과도한 Bold Typography

PROJECT TITLE은 명확하게 읽혀야 하지만
**HERO IMAGE가 항상 가장 강한 시각적 요소**여야 합니다.

# 9. COVER LAYOUT

이번 페이지는 반드시 **표지처럼 보여야 합니다.**

전문 건축·디자인 스튜디오의

- Architecture Portfolio
- Interior Design Portfolio
- Architectural Editorial Book
- Design Competition Portfolio
- Professional Design Portfolio

의 첫 번째 COVER PAGE처럼 구성하세요.

프로젝트 이미지는 페이지 전체에서 약 **80~90%의 시각적 비중**을 갖도록 합니다.

텍스트와 로고는 나머지 영역에서 절제되게 사용하세요.

대표 이미지의 구도를 분석하여
건축물이나 인테리어의 핵심 대상을 가리지 않는

**Natural Negative Space**

영역을 찾아 텍스트를 배치하세요.

# 13. 시안 제작

동일한 SOURCE와 동일한 텍스트를 이용하여
**서로 다른 COVER PAGE 시안 2개를 제작해 주세요.**

두 시안 모두 반드시 표지처럼 보여야 합니다.

각 시안에서는 다음 정도만 다르게 표현하세요.

- 이미지 선택
- HERO IMAGE Crop
- Title Group 위치
- Negative Space 활용
- Editorial Grid

시안 수를 늘리기 위해
한 시안을 MATERIAL DETAIL PAGE나 INTERIOR DESCRIPTION PAGE처럼 만들지 마세요.

두 결과 모두 반드시 **COVER PAGE**여야 합니다.

첨부된 프로젝트 이미지 중 가장 적합한 이미지 1장만 사용하는 것이 더 좋다면
두 시안 모두 1장만 사용해도 됩니다.

추가 이미지가 실제로 표지의 완성도를 높이는 경우에만
SUPPORTING IMAGE 1장을 제한적으로 사용하세요.
