<LessonSection id="section-04" number="04" title="생성형 AI(Generative AI)의 기본 개념" class="lesson-one-section">
  <div class="lesson-prose">
    <h3>생성형 AI(Generative AI)</h3>

    <p>생성형 AI(Generative AI)는 사용자의 요청과 제공된 자료를 바탕으로 텍스트, 이미지, 영상 등 새로운 결과를 만드는 인공지능이다.</p>

    <p>생성형 AI(Generative AI)는 사실을 확인한 뒤 정답을 꺼내는 시스템이 아니다. 학습된 패턴과 현재 입력을 바탕으로 상황에 적절해 보이는 결과를 생성한다.</p>

    <p>따라서 문장이 자연스럽고 구체적이라고 해서 실제 조건이나 사실과 일치한다고 판단해서는 안 된다.</p>

    <h3>대규모 언어 모델(Large Language Model, LLM)</h3>

    <p>대규모 언어 모델(Large Language Model, LLM)은 많은 텍스트를 학습해 문맥상 이어질 가능성이 높은 언어를 생성하는 모델이다.</p>

    <p>활용 예:</p>

    <ul>
      <li>의뢰 내용 정리</li>
      <li>회의록 요약</li>
      <li>조건 분류</li>
      <li>질문 목록 작성</li>
      <li>디자인 방향 제안</li>
      <li>여러 결과 비교</li>
      <li>수정 요청 정리</li>
    </ul>

    <p>대규모 언어 모델(Large Language Model, LLM)의 답변은 검증된 설계 결과나 사실 데이터 그 자체가 아니다.</p>

    <h3>멀티모달 AI(Multimodal AI)</h3>

    <p>멀티모달 AI(Multimodal AI)는 텍스트뿐 아니라 이미지, PDF 등 여러 형식의 자료를 함께 다루는 AI다.</p>

    <p>이번 과정에서는 Gemini의 파일 업로드 기능을 사용할 수 있다. 다만 파일을 읽을 수 있다는 것과 모든 정보를 정확하게 해석한다는 것은 다르다. AI 답변은 반드시 원본과 대조한다.</p>

    <h3>과정에서 사용할 모델</h3>

    <p>사용자가 실제 강의 준비 환경에서 확인한 UI 명칭을 기준으로 표기한다.</p>

    <ul>
      <li>빠른 초기 분석과 생성: <code>Gemini 3.6 Flash</code></li>
      <li>복잡한 분석과 재검토: <code>Gemini 3.6 Flash의 Thinking 설정 또는 Thinking level</code></li>
    </ul>

    <aside class="lesson-callout lesson-callout--verification">
      <strong>강의 전 사실 검증</strong>
      <ul>
        <li>공식 API 모델 ID나 내부 기술 명칭을 임의로 만들지 않는다.</li>
        <li>모델과 Thinking 설정은 서로 다른 개념이며, 명칭과 화면은 변경될 수 있으므로 강의 시점 실제 환경을 다시 확인한다.</li>
        <li>아래 북카페 답변은 Gemini 3.6 Flash에서 생성된 실제 결과다.</li>
      </ul>

<LessonSection id="section-06" number="06" title="안전하게 사용하기 위한 핵심 용어" class="lesson-one-section">
  <div class="lesson-term-grid">
    <article>
      <span>01</span>
      <h3>할루시네이션(Hallucination)</h3>
      <p>AI가 근거가 없거나 사실과 다른 내용을 그럴듯하게 생성하는 현상이다.</p>
      <p>공간디자인에서는 제공되지 않은 면적, 예산, 창문 위치, 기둥, 구조 조건 등을 실제 정보처럼 표현하는 형태로 나타날 수 있다.</p>
    </article>
    <article>
      <span>02</span>
      <h3>그라운딩(Grounding)</h3>
      <p>AI의 답변을 사용자가 제공한 원문, 도면, 이미지, 문서, 확인된 자료에 연결하는 과정이다.</p>
      <p>그라운딩(Grounding)은 AI가 절대 틀리지 않게 만드는 방법이 아니라, 답변의 근거를 확인하고 오류를 줄이기 위한 방법이다.</p>
    </article>
    <article>
      <span>03</span>
      <h3>인간 개입형 검토(Human in the Loop, HITL)</h3>
      <p>AI가 만든 결과를 사람이 검토하고 수정·승인·보류·제외하는 구조다.</p>
      <p>AI는 제안하고, 최종 판단과 책임은 사람이 맡는다.</p>
    </article>
  </div>
</LessonSection>
