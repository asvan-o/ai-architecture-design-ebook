# 승인된 14차시 커리큘럼

- 승인 상태: 사용자 승인
- 총 강의시간: 48시간
- 대상: 건축·인테리어·공간디자인 분야 실무자
- 사용 도구 범위: Gemini, Nano Banana, Veo, AGY 등 AI 도구
- 제외 범위: AutoCAD, Revit, SketchUp 등 기존 설계 프로그램
- 공통 원칙: **AI는 제안하고, 디자이너는 판단한다.**

이 과정의 목표는 건축설계의 정답이나 시공 가능한 도면을 만드는 것이 아니라,
AI를 이용해 공간디자인 의뢰를 정리하고, 콘셉트 이미지와 수정안을 제작하며,
영상과 프로젝트 자료를 전달 가능한 형태로 완성하는 것이다.

## 콘텐츠 작성 시 유지할 경계

- 건축 설계의 정답이나 시공 가능성을 단정하지 않는다.
- 확인되지 않은 건축 실무 관행, 법규, 구조, 시공, 소방, 접근성, 자재
  성능을 사실처럼 작성하지 않는다.
- 실제 이미지·영상·문서는 제작 및 사용 권한 확인 전까지 플레이스홀더로 둔다.
- 미추적 `건축영상/`과 `건축영상.zip`은 승인된 공개 교재 자산이 아니다.
- AGY의 실제 명령어와 지원 기능은 실제 환경 검증 후 작성한다.
