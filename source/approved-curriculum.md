# 승인된 14차시 커리큘럼

- 승인 상태: 사용자 승인
- 총 강의시간: 48시간
- 대상: 건축·인테리어·공간디자인 분야 실무자
- 사용 도구 범위: Gemini, Nano Banana, Veo, AGY 등 AI 도구
- 제외 범위: AutoCAD, Revit, SketchUp 등 기존 설계 프로그램
- 공통 원칙: **AI는 제안하고, 디자이너는 판단한다.**

이 과정의 목표는 건축설계의 정답이나 시공 가능한 도면을 만드는 것이 아니라,
AI를 이용해 공간디자인 의뢰를 정리하고, 콘셉트 이미지와 수정안을 제작하며,
영상과 프로젝트 자료를 전달 가능한 형태로 완성하는 것이다.

## 1차시 · 3시간

### 제목

AI가 할 일과 디자이너가 판단할 일

### 핵심

- 전체 과정과 최종 결과물 이해
- 생성형 AI, LLM, 멀티모달의 직관적인 이해
- Gemini, Nano Banana, Veo, AGY의 역할 구분
- Hallucination, Grounding, Human in the Loop
- 사실, 가정, 해석, 디자인 제안 구분

### 결과물

- AI 활용 및 검증 체크리스트
- 첫 공간디자인 요청 분석표

## 2차시 · 3시간

### 제목

한 줄 공간 요청을 첫 콘셉트 이미지로 만들기

### 핵심

- 간단한 공간 요청을 Gemini와 구조화
- 목적, 사용자, 공간, 분위기, 시점 정리
- Nano Banana를 활용한 공간 이미지 생성
- 생성 결과 비교와 초기 오류 확인

### 결과물

- 공간 콘셉트 이미지 3~4장
- 초기 요청문과 생성 기록

## 3차시 · 3시간

### 제목

레퍼런스와 무드보드에서 디자인 방향 찾기

### 핵심

- 레퍼런스를 형태, 재료, 색, 빛, 분위기로 분해
- 여러 이미지의 공통 특징 찾기
- 레퍼런스 복제와 디자인 요소 분석의 차이
- 무드보드와 디자인 키워드 제작

### 결과물

- 무드보드
- 디자인 키워드표
- 레퍼런스 분석표

## 4차시 · 6시간

### 제목

무드보드에서 공간 콘셉트 보드까지

### 핵심

- 강사가 제공한 공간디자인 의뢰서 검토
- 무드보드와 디자인 방향 2~3안 제작
- 외관 또는 실내 대표 이미지 생성
- 중간 발표, 피드백, 수정

### 결과물

- 미니 공간디자인 콘셉트 보드
- 디자인 방향 비교표
- 수정 전후 결과

## 5차시 · 3시간

### 제목

AI로 실무 문서와 반복 정리 업무 줄이기

### 핵심

- 회의 메모를 결정사항, 미결사항, 담당업무로 정리
- 클라이언트 수정 요청을 작업 목록으로 변환
- 레퍼런스와 자료의 공통 항목 비교
- AI가 원문에 없는 내용을 추가했는지 확인

### 결과물

- 회의 정리표
- 클라이언트 요청표
- 자료 비교표
- 원문 대조 및 오류 확인표

## 6차시 · 3시간

### 제목

클라이언트 의뢰를 디자인 브리프로 변환하기

### 핵심

- 문의 메일, 미팅 메모, 참고 이미지 분석
- 확정 조건, 희망 조건, 미확정 조건 구분
- 추가로 확인할 질문 작성
- 공간디자이너가 검토할 브리프 초안 제작

### 결과물

- 클라이언트 질문 목록
- 디자인 브리프
- 확정 및 미확정 조건표
- AI 제안과 수강생 수정 비교

> 이 차시는 공간계획의 정답을 가르치는 수업이 아니다. AI가 의뢰 정보를
> 구조화하고, 수강생이 자신의 공간디자인 전문성으로 검토·수정하는 과정이다.

## 7차시 · 3시간

### 제목

공간을 유지하며 재료·조명·가구 수정하기

### 핵심

- 유지할 요소와 변경할 요소 구분
- 동일 공간의 재료 변경
- 조명과 분위기 변경
- 가구, 식재, 소품 추가 및 삭제
- AI가 공간 구조를 임의로 변경했는지 확인

### 결과물

- 원본 이미지
- 재료 및 조명 대안
- 가구와 식재 수정안
- 수정 전후 비교판

## 8차시 · 3시간

### 제목

클라이언트 피드백 대응과 수정 제안서 만들기

### 핵심

- 클라이언트 코멘트를 변경, 유지, 모호한 요청으로 분류
- 추가 확인 질문 작성
- 수정 우선순위 설정
- 이미지 수정과 변경 이력 기록

### 결과물

- 클라이언트 코멘트 분석표
- 수정 지시서
- 수정 전후 이미지
- 변경 이력표
- 수정 제안판

## 9차시 · 3시간

### 제목

여러 공간 이미지의 디자인 일관성 관리

### 핵심

- 프로젝트의 고정 디자인 기준 작성
- 재료, 색상, 창호, 가구, 조명 기준 설정
- 외관, 실내, 상세 이미지 생성
- 이미지 간 불일치 탐색
- 수정하거나 제외할 이미지 판단

### 결과물

- 프로젝트 디자인 기준표
- 공간 이미지 3~5장
- 이미지 일관성 검사표
- 실패 이미지와 제외 이유

> 완벽하게 동일한 건축물을 여러 시점에서 생성한다고 보장하지 않는다.
> 발표자료에서 하나의 프로젝트로 인식될 수 있도록 일관성을 관리하고
> 검토하는 것이 학습 목표다.

## 10차시 · 3시간

### 제목

도면·PDF에서 정보 찾기와 AI 오독 확인

### 핵심

- 교육용 평면 이미지 또는 PDF에서 공간명과 표기 정보 추출
- 주요 공간 관계와 동선 설명
- 판독이 어려운 부분 표시
- AI가 잘못 읽은 내용을 수강생이 확인
- 추가 확인 질문 작성
- 선택적으로 참고용 개념 조감 이미지 제작

### 결과물

- 도면 정보 추출표
- AI 오독 목록
- 확인 질문 목록
- 선택적 개념 조감 이미지

> 정확한 CAD 도면, BIM 모델, 치수 기반 3D 모델, 법규 검토, 시공도면을
> 제작하는 수업이 아니다. 생성된 입체 이미지는 개념적 시각화로만 표시한다.

## 11차시 · 3시간

### 제목

공간 이미지를 짧은 영상으로 만들기

### 핵심

- 대표 공간 이미지 선택
- 시작 장면과 마지막 장면 설정
- 카메라 위치와 이동 방향 설정
- Gemini로 영상 지시 검토
- Veo로 공간 콘셉트 영상 제작
- 공간 형태 왜곡과 카메라 오류 확인

### 결과물

- 영상 장면표
- 영상 생성 지시문
- 15~30초 공간 콘셉트 영상
- 영상 오류 확인표

## 12차시 · 3시간

### 제목

AGY로 프로젝트 자료 구조 만들기

### 핵심

- 프로젝트 폴더 구조 설계
- 파일명과 버전 규칙 작성
- 프롬프트와 생성 이미지 연결
- 출처와 변경 이력 기록
- 이미지와 영상 자료 인덱스 제작

### 결과물

- 표준 프로젝트 폴더
- 파일명 규칙
- 자료 인덱스
- 출처 목록
- 변경 이력
- 최종 제출 체크리스트

## 13차시 · 3시간

### 제목

AGY 기반 반복 점검과 제출 패키지 만들기

### 핵심

- 파일명 규칙 위반 확인
- 프롬프트 기록이 없는 이미지 확인
- 출처가 없는 자료 확인
- 필수 결과물 누락 확인
- 프로젝트 상태 보고서 제작
- 최종 제출 폴더 패키징

### 결과물

- 프로젝트 검사 프로세스
- 누락 파일 보고서
- 프로젝트 상태 보고서
- 최종 제출 패키지

> AGY의 실제 명령어, 지원 기능, 권한 범위는 아직 확정하지 않는다.
> 확인되지 않은 명령어나 기능은 “실제 환경 검증 후 작성 예정”으로 표시한다.
> 복잡한 MCP 구축이나 별도 프로그램 개발은 포함하지 않는다.

## 14차시 · 6시간

### 제목

AI 공간디자인 콘셉트 패키지 완성

### 핵심

- 1~13차시 결과물 선별
- 누락된 이미지와 영상 보완
- 기획, 무드, 공간 이미지, 수정 과정 정리
- AI가 수행한 부분과 수강생이 판단한 부분 구분
- 포트폴리오 페이지 구성
- 발표, 피드백, 최종 수정

### 최종 결과물

- 프로젝트 의뢰서와 디자인 브리프
- 확정 및 미확정 조건표
- 무드보드와 디자인 키워드
- 공간 콘셉트 이미지
- 재료, 조명, 가구 대안
- 클라이언트 수정 전후 이미지
- 이미지 일관성 검사표
- 15~30초 공간 콘셉트 영상
- AI 작업, 수정, 검증 기록
- 정리된 프로젝트 폴더
- 최종 포트폴리오 페이지

## 콘텐츠 작성 시 유지할 경계

- 건축 설계의 정답이나 시공 가능성을 단정하지 않는다.
- 확인되지 않은 건축 실무 관행, 법규, 구조, 시공, 소방, 접근성, 자재
  성능을 사실처럼 작성하지 않는다.
- 실제 이미지·영상·문서는 제작 및 사용 권한 확인 전까지 플레이스홀더로 둔다.
- 미추적 `건축영상/`과 `건축영상.zip`은 승인된 공개 교재 자산이 아니다.
- AGY의 실제 명령어와 지원 기능은 실제 환경 검증 후 작성한다.
