# 승인된 14차시 커리큘럼

- 승인 상태: 사용자 승인
- 총 강의시간: 48시간
- 대상: 건축·인테리어·공간디자인 분야 실무자
- 사용 도구 범위: Gemini, Nano Banana, Veo, AGY 등 AI 도구
- 제외 범위: AutoCAD, Revit, SketchUp 등 기존 설계 프로그램
- 공통 원칙: **AI는 제안하고, 디자이너는 판단한다.**

이 과정의 목표는 건축설계의 정답이나 시공 가능한 도면을 만드는 것이 아니라,
AI를 이용해 공간디자인 의뢰를 정리하고, 콘셉트 이미지와 수정안을 제작하며,
영상과 프로젝트 자료를 전달 가능한 형태로 완성하는 것이다.

## 6차시 · 3시간

### 제목

DWG·평면도 기반 공간 수정과 3D·아이소메트릭 분해도

### 핵심

- 원본 DWG와 사람이 확인 가능한 평면도 이미지를 함께 읽기
- 지정 영역만 수정하고 원본 구조 보존 여부 검토
- 수정 평면도를 Top View 3D로 입체화
- Top View 3D를 사선 시점의 아이소메트릭 스타일 이미지로 변환
- 기존 구성요소를 Z축 방향으로 분리한 Exploded Isometric View 제작
- 확인된 구조 정보와 높이·재질·조명 등 추정 표현 구분

### 결과물

- 수정 영역이 표시된 평면도와 수정 평면도
- 수정 평면도 기반 Top View 3D 이미지
- 아이소메트릭 스타일 공간 이미지
- 아이소메트릭 분해도
- 원자료와 생성 결과의 불일치·추정·추가 확인 기록

> 생성 결과는 실제 설계 확정안이나 기술도면이 아니다. 원본 도면의 구조 보존 여부를
> 사람이 비교하고, 실제 치수·구조·법규·설비·재료 성능·시공 가능성은 별도로 확인한다.

## 7차시 · 3시간

### 제목

PDF 도면 기반 공간 수정과 Gaussian Splatting 3D 시각화

### 핵심

- PDF 전체 평면도에서 확인 정보와 추정 정보 구분

- 부분 수정 결과를 전체 PDF에 반영하고 원본 보존 여부 검토
- 수정된 전체 평면도를 Top View 3D 기준 이미지로 시각화
- 3D Gaussian Splatting의 기본 표현 개념과 Polygon Mesh의 차이 이해
- 제공된 ComfyUI 결과를 여러 시점에서 검토하고 현실형 렌더와 업스케일 결과 비교

### 결과물

- PDF 도면 분석 기록
- 부분 공간 수정 결과와 수정 반영 전체 도면
- 전체 평면도 기반 Top View 3D
- Gaussian 또는 Gaussian 기반 3D 결과 검토 기록
- 현실형 그래픽 렌더

> 현장 도면과 파생 이미지는 공개 e-book에 포함하지 않는다. Gaussian 기반 결과와
> 현실형 렌더는 CAD/BIM 모델, 실측 3D 모델 또는 설계 확정안이 아니며 실제 치수·구조·
> 법규·설비·재료 성능·시공 가능성은 별도로 확인한다.
