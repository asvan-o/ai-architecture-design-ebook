# 캠퍼스 라운지 프로젝트 관리 프로그램

제3·4차시 캠퍼스 라운지 실습 파일을 로컬에서 복사·정리하고, 사람이 검토한
등록 파일만 제출 ZIP으로 묶는 교육용 프로그램입니다. 프로그램 버전은 1.1.0입니다.

이 프로그램은 설계 품질, RFP 충족, 법규·구조·소방·설비·접근성·시공성,
저작권 또는 개인정보 안전을 판단하지 않습니다. 파일의 내용도 승인하지 않습니다.

## 프로그램이 하는 일

- 원본 파일을 `관리데이터/원본보관`에 복사
- 프로젝트·차시·자료 유형·버전으로 파일명 정리
- 실제 파일 바이트의 SHA-256 기록과 동일 파일 알림
- 등록목록 작성과 필수 결과물 누락 표시
- 등록목록에 있는 파일만 제출 ZIP에 포함
- ZIP 생성 전 포함 목록·미등록 제외 수·누락 목록 표시

원본 삭제·이동·덮어쓰기, 더 좋은 디자인 선택, 문서 내용 승인,
법규·구조·소방·설비·시공성 검증은 하지 않습니다.

## Antigravity, Node.js와 npm

- Antigravity 2.0 → 이번 수업에서 프로그램 파일과 코드를 만드는 데스크톱 제작 도구
- Node.js → 생성된 로컬 프로그램을 실행하는 환경
- npm → 패키지 설치, 자동 테스트와 프로그램 실행

Antigravity CLI는 터미널 중심의 별도 도구이며 이번 실습의 주 도구가 아닙니다.
IDE는 코드 편집기와 개발 도구를 묶은 일반 용어입니다.

## 설치 버전

- 최소 요구: Node.js 22 이상
- 수업 권장: 최신 Node.js LTS
- 2026-08-04 확인 기준: Node.js v24.18.1 LTS
- 기능 시험용 Current보다 LTS 권장

버전은 변경될 수 있으므로 설치 직전에
[Node.js 공식 다운로드](https://nodejs.org/en/download)를 다시 확인합니다.

## Windows 설치와 확인

1. 공식 다운로드 페이지에서 LTS를 선택합니다.
2. 일반 Windows 노트북은 Windows Installer(.msi) x64를 선택합니다.
3. ARM Windows에서만 ARM64를 선택합니다.
4. npm package manager와 Add to PATH를 설치 상태로 유지합니다.
5. 설치 후 Antigravity와 터미널을 종료하고 다시 실행합니다.

```bash
node --version
npm --version
```

`node --version`이 v22 이상이고 npm 버전 숫자가 표시되면 정상입니다.
최초 패키지 설치에는 네트워크 연결이 필요할 수 있습니다. 관리자 권한은 기본 요구가 아닙니다.

## 실행

학생이 직접 만든 프로그램:

```bash
cd .\관리프로그램
npm install
npm test
npm start
```

제공된 READY ZIP:

```bash
cd .\관리프로그램
npm ci
npm test
npm start
```

프로젝트 최상위에서 바로 `npm ci`를 실행하지 마십시오. 터미널 경로의 끝이
`\관리프로그램`인지 확인합니다. 실행 후 <http://127.0.0.1:4174>를 엽니다.

## Antigravity 최소 권한

1. `AI_건축_캠퍼스라운지` 폴더만 프로젝트로 엽니다.
2. 프로젝트 밖 폴더 접근은 Ask 또는 Deny를 사용합니다.
3. Full Access를 기본으로 켜지 않습니다.
4. 터미널 명령과 수정 예정 파일 목록을 사람이 먼저 확인합니다.
5. 프로젝트 밖 수정이 표시되면 즉시 중단합니다.
6. 개인정보·기밀자료가 있는 폴더를 프로젝트에 포함하지 않습니다.
7. 관리자 권한으로 실행하지 않습니다.

## 제3→4차시 등록 대응

기존 6개 관리 영역을 그대로 사용합니다.

### 공통 기준자료와 제3차시 결과물

| 자료 | 관리 영역 | 자료 유형 |
|---|---|---|
| 가상 RFP | 기준자료 | 발주요청서(RFP) |
| 교육용 현황 평면도 | 기준자료 | 현황 평면도 |
| 교육용 현황 이미지 | 기준자료 | 교육용 현황 이미지 |
| 요구조건 매트릭스 | 요구분석·디자인 브리프 | 요구조건 매트릭스 |
| 추가 질의 | 요구분석·디자인 브리프 | 추가 질의 |
| 디자인 브리프 | 요구분석·디자인 브리프 | 디자인 브리프 |
| 평면도 기반 현황 이미지 후보 | 기준자료 | 평면도 기반 현황 이미지 후보 |
| 수정된 현황 이미지 후보 | 기준자료 | 수정된 현황 이미지 후보 |
| 평면도·이미지 불일치 기록 | 선택안·검증 | 평면도·이미지 불일치 기록 |
| 대안 평가기준 | 요구분석·디자인 브리프 | 제4차시 대안 평가기준 |

### 제4차시 필수 제출물

| 자료 | 관리 영역 | 자료 유형 |
|---|---|---|
| 대안 A 전략 | 대안 A | 대안 A 전략 |
| 대안 A 조닝 | 대안 A | 대안 A 조닝 |
| 대안 A 이미지 | 대안 A | 대안 A 이미지 |
| 대안 B 전략 | 대안 B | 대안 B 전략 |
| 대안 B 조닝 | 대안 B | 대안 B 조닝 |
| 대안 B 이미지 | 대안 B | 대안 B 이미지 |
| 비교표 | 선택안·검증 | RFP 기준 대안 비교표 |
| 선택안 수정 요청문 | 선택안·검증 | 선택안 수정 요청문 |
| 선택안 수정 이미지 | 선택안·검증 | 선택안 수정 이미지 |

대안 A·B 이미지 요청문은 판단 근거로 등록할 수 있지만 필수 누락 검사에는 포함하지 않습니다.
제출 ZIP은 위 등록 파일로 프로그램이 생성합니다.

## 허용 파일과 제한

허용 확장자:

```text
.pdf .png .jpg .jpeg .webp .docx .xlsx .pptx .txt .md .csv .json
```

- 파일당 최대 크기: 20MB
- 조사한 수업 원본 중 최대 파일: RFP PDF 약 0.65MB
- 이미지·문서 작업 여유를 고려해 20MB로 설정
- `.exe`, `.msi`, `.bat`, `.cmd`, `.ps1`, `.js` 등 실행·스크립트 업로드 금지
- 확장자, 브라우저가 보고한 형식, 실제 파일 바이트를 함께 확인
- 빈 파일, 위험 경로 문자, 손상된 JSON 거부

## 제출 ZIP 정책

ZIP에는 다음만 포함합니다.

- 등록목록의 파일
- `관리데이터/등록파일목록.json`
- `관리데이터/누락점검.json`
- `제출안내.txt`

미등록 파일, 원본보관 폴더, 캐시, 로그, 환경변수 파일, 프로그램 코드,
이전 ZIP은 포함하지 않습니다. 화면에서 포함 예정 파일, 제외되는 미등록 파일 수,
누락 항목을 확인하고 확인란을 선택해야 ZIP을 만들 수 있습니다.

ZIP은 파일 존재와 등록 상태만 정리합니다. 개인정보·기밀·저작권·설계 적합성은
사람이 마지막으로 검토해야 합니다.

## 테스트

```bash
npm test
```

테스트 범위:

- 10개 동시 등록과 고유 버전
- 동일 바이트 중복과 동일 이름의 다른 버전
- 한글·공백·특수문자 파일명
- 손상된 등록목록 JSON
- 비허용 확장자·크기 초과·가짜 바이트
- 프로젝트 외부 경로와 junction·symlink 방어
- 등록 파일 ZIP 포함과 미등록 민감자료 제외
- 실패 뒤 임시 색인 파일이 남지 않는지 확인

링크 생성 권한이 없는 Windows 환경에서는 junction·symlink 생성 테스트만
명시적으로 건너뛸 수 있습니다. 실제 방어 코드는 항상 적용됩니다.

## 오류 시 대체 방법

- Antigravity 설치·로그인 실패 → READY ZIP 사용
- 에이전트 응답 60초 이상 지연 → READY ZIP 또는 준비된 시연 화면 사용
- npm 설치 실패 → 사전 설치 PC 또는 준비된 실행 환경 사용
- 프로그램 오류 → 동일한 한국어 폴더와 파일명 체크리스트로 수동 정리
- ZIP 생성 실패 → 등록 파일 목록을 확인하고 제출 폴더를 직접 압축한 뒤 목록표 동봉

## 라이선스

프로그램 코드는 교육용 프로젝트 내부 사용을 전제로 합니다. 제3자 패키지 안내는
`THIRD_PARTY_LICENSES.md`와 `package-lock.json`을 확인하십시오. `node_modules`는
READY ZIP에 포함하지 않습니다.
