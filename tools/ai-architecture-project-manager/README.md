# 캠퍼스 라운지 프로젝트 관리 프로그램

제4차시 캠퍼스 라운지 실습 파일을 로컬에서 정리하는 교육용 프로그램입니다.
파일 복사, 간단한 파일명, 버전 구분, 같은 파일 알림과 작업 ZIP 생성을
지원합니다. 설계 품질, 법규 적합성 또는 실제 시공 가능성을 판단하지 않습니다.

## Antigravity, Node.js와 npm의 역할

- Antigravity 2.0 → 관리 프로그램의 파일과 코드 제작
- Node.js → 생성된 로컬 관리 프로그램 실행
- npm → 필요한 패키지 설치, 자동 테스트와 프로그램 실행

## 설치 버전

- 프로그램 최소 요구: Node.js 22 이상
- 수업 권장: 최신 Node.js LTS
- 2026년 7월 31일 공식 다운로드 페이지 확인 기준: Node.js v24.18.1 LTS
- Current가 아니라 LTS를 선택합니다.

Node.js 버전과 지원 상태는 향후 변경될 수 있으므로 설치 직전에
[Node.js 공식 다운로드 페이지](https://nodejs.org/en/download)를 다시 확인합니다.

## Windows 설치

1. Node.js 공식 다운로드 페이지에 접속합니다.
2. Current가 아닌 LTS를 선택합니다.
3. 일반 Windows 노트북은 Windows Installer (.msi)의 x64를 선택합니다.
4. ARM 기반 Windows 장치에서만 ARM64를 선택합니다.
5. 설치 프로그램의 기본 옵션을 유지합니다.
6. npm package manager 항목을 설치 상태로 유지합니다.
7. Add to PATH 항목을 설치 상태로 유지합니다.
8. 설치가 끝나면 Antigravity와 열려 있던 터미널을 모두 종료한 뒤 다시 실행합니다.

## 설치 확인

```bash
node --version
npm --version
```

`node --version` 결과가 v22 이상이고 `npm --version`에서 버전 숫자가 표시되면
정상입니다.

- `node` 명령을 찾을 수 없음: 터미널과 Antigravity를 다시 실행하고, 계속되면
  Windows를 재시작합니다. 설치 프로그램에서 Add to PATH가 선택되었는지도 확인합니다.
- `npm` 명령을 찾을 수 없음: Node.js 설치 프로그램에서 npm package manager가
  설치되었는지 확인한 뒤 터미널과 Antigravity를 다시 실행합니다.

## 학생이 직접 만든 프로그램 실행

프로젝트 최상위에서 다음 명령을 순서대로 실행합니다.

```bash
cd .\관리프로그램
npm install
npm test
npm start
```

## 제공된 READY ZIP 실행

ZIP을 풀면 `AI_건축_캠퍼스라운지` 폴더 안에서 수업 자료와 프로그램이
분리되어 있습니다. 프로젝트 최상위에서 다음 명령을 순서대로 실행합니다.

```bash
cd .\관리프로그램
npm ci
npm test
npm start
```

`AI_건축_캠퍼스라운지` 최상위에서 바로 `npm ci`를 실행하면
`package-lock.json`을 찾을 수 없다는 오류가 발생합니다. 터미널 경로의 끝이
`\관리프로그램`인지 확인한 뒤 실행합니다.

- `npm install`: 학생이 직접 만든 프로그램의 의존성을 설치합니다.
- `npm ci`: READY ZIP의 `package-lock.json`에 기록된 버전과 동일하게 설치합니다.
- `npm test`: 파일 등록, 버전 구분, 목록 표시와 ZIP 생성 기능을 검사합니다.
- `npm start`: 로컬 관리 프로그램을 실행합니다.

브라우저에서 `http://127.0.0.1:4174`를 엽니다. 프로그램을
`관리프로그램` 폴더에서 실행하면 상위 `AI_건축_캠퍼스라운지` 폴더에
한국어 분류 폴더와 등록 파일 목록이 자동으로 준비됩니다.

```text
AI_건축_캠퍼스라운지/
├─ 01_기준자료/
│  ├─ 발주요청서_RFP/
│  ├─ 현황평면도/
│  └─ 현황이미지/
├─ 02_분석자료/
│  ├─ 요구조건/
│  ├─ 추가질의/
│  └─ 디자인브리프/
├─ 03_공간대안/
│  ├─ 대안-A/
│  └─ 대안-B/
├─ 04_선택안/
├─ 05_확인기록/
├─ 06_제출파일/
├─ 관리데이터/
└─ 관리프로그램/
```

`관리프로그램`에는 실행에 필요한 코드와 패키지 파일만 모여 있습니다.
`관리데이터`는 등록 목록과 원본 보관에 사용하는 자동 관리 영역입니다.

자료는 일부만 등록해도 목록에서 바로 확인할 수 있고 현재 작업을 ZIP으로
묶을 수 있습니다. `제출 전 확인`은 ZIP 생성을 막는 기능이 아니라,
최종 제출 전에 아직 등록하지 않은 자료를 알려주는 안내 기능입니다.
등록 파일 목록의 파일명을 누르면 해당 자료를 바로 열거나 내려받을 수 있습니다.

다른 폴더를 프로젝트 루트로 지정해야 할 때만 환경변수를 사용합니다.

```powershell
$env:PROJECT_ROOT="C:\Users\student\Desktop\AI_건축_캠퍼스라운지"
npm start
```

테스트는 임시 폴더에서 폴더 생성, 파일 등록, 버전 구분, 같은 파일 알림,
일부 자료 ZIP, 전체 제출 항목 확인, 원본 유지와 프로젝트 밖 접근 차단을 확인합니다.

## 보안·운영 경계

- 등록 파일의 원본은 `관리데이터/원본보관`에 보존하며 삭제하지 않습니다.
- 기존 파일을 덮어쓰지 않고 `v01`, `v02`처럼 새 버전을 만듭니다.
- 프로젝트 루트 밖 경로는 거부합니다.
- 데이터는 로컬 JSON과 파일로만 저장합니다.
- 로그인, 클라우드, 데이터베이스, Git 연동은 포함하지 않습니다.
