AI 건축디자인 강의키트 · Windows x64
=====================================

이 키트는 현재 공개된 제1~6차시 학생 e-book·PDF와 제1~14차시 강사용 콘솔·
프로젝터 화면을 인터넷·관리자 권한·별도 Node.js 설치 없이 1대의 Windows PC에서 실행합니다.
서버는 127.0.0.1에만 연결되며 같은 PC 밖에서는 접속할 수 없습니다.

[강의 전]
1. ZIP을 짧고 찾기 쉬운 폴더에 완전히 압축 해제합니다.
2. 압축 파일 안에서 직접 실행하지 않습니다.
3. 강의_실행.cmd를 두 번 클릭합니다.
4. Windows 경고가 나타나면 파일 위치와 배포자를 확인한 뒤 실행 여부를 판단합니다.
5. 브라우저에 강의 허브가 열리면 학생·강사·프로젝터 서버 상태를 확인합니다.

[강의 중]
- 차시를 선택하고 학생 e-book, 강사용 콘솔, 프로젝터 화면을 엽니다.
- 기본 포트 4310~4312가 사용 중이면 4310~4399에서 빈 포트를 자동 선택합니다.
- 같은 키트의 강의_실행.cmd를 다시 실행하면 중복 서버 대신 기존 허브가 열립니다.
- 공개 e-book 버튼만 인터넷을 사용합니다. 로컬 화면과 PDF는 오프라인에서 동작합니다.

[강의 종료]
- 허브의 '강의 서버 안전 종료' 또는 강의_종료.cmd를 사용합니다.
- 상태는 강의키트_상태확인.cmd로 확인합니다.
- 다른 Node.js나 브라우저 프로세스는 종료하지 않습니다.

[업데이트]
- 새 ZIP은 기존 키트와 다른 폴더에 압축 해제한 뒤 BUILD_INFO.json의 버전과 Git SHA를 확인합니다.
- 실행 중인 이전 키트를 먼저 종료합니다.
- 개인 파일을 키트 내부에 저장하지 마세요. 키트 교체 시 함께 삭제될 수 있습니다.

[보안·구성]
- runtime/: Node.js 공식 Windows x64 휴대용 런타임과 LICENSE
- sites/student/: 강사 메모가 없는 학생용 정적 사이트
- sites/instructor/: 로컬 강사용 콘솔·프로젝터 정적 사이트
- pdf/: 학생용 PDF 사본
- logs/: 실행 상태와 개인 경로를 기록하지 않는 최소 로그
- source/, instructor-content/, 원본 YAML, .env, Git 정보는 포함하지 않습니다.

공식 배포본의 ZIP SHA-256은 ZIP 옆의 .sha256 파일로 확인합니다.
BUILD_INFO.json의 portableZipSha256은 자기 자신을 포함한 ZIP 해시를 ZIP 내부에
동시에 기록할 수 없는 순환 제약 때문에 외부 .sha256 파일명을 가리킵니다.
