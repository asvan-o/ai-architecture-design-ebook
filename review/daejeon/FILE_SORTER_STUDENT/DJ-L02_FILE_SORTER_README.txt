파일 정리 자동화 · 수강생 사용방법

1. 이 프로그램은 무엇인가
Windows 교육용 로컬 프로그램입니다.
00_수집함에 넣은 파일을 확장자와 파일명 규칙으로 분류합니다.
파일 내부 의미를 읽는 AI 분류 프로그램이 아닙니다.
확실한 파일은 자동으로, 애매한 파일은 사람이 판단합니다.

2. 준비사항
Windows와 시스템에 설치된 Node.js LTS가 필요합니다.
Node.js는 이번에 만든 로컬 프로그램을 실행하기 위한 실행환경입니다.
실제 검증한 최소 버전은 Node.js 22.23.2입니다.
실행 기준은 22.23.2 이상인 LTS 버전이며 모든 버전·PC를 검증했다는 뜻은 아닙니다.
명령 창에서 node --version으로 확인합니다.
설치 안내: https://nodejs.org/en/download
npm install과 관리자 권한은 필요하지 않습니다.
이 ZIP에는 Node.js runtime을 포함하지 않았습니다.

3. 실행하기
프로그램 ZIP을 쓰기 가능한 위치에 압축 해제합니다.
압축파일 안에서 실행하지 말고 AI_파일자동정리 폴더 전체를 풉니다.
START.bat을 더블클릭하고 실행 성공 안내에 표시된 주소를 브라우저로 엽니다.
기본 주소: http://127.0.0.1:4174/
같은 포트가 사용 중이면 오류를 표시합니다. 다른 포트로 자동 변경하지 않습니다.

4. 파일 넣기
방법 1 · 수집함에 직접 넣기
SORT_TEST ZIP을 별도로 압축 해제합니다.
실습파일 11개만 복사해서 00_수집함에 넣습니다.
README.txt와 manifest.json은 넣지 않습니다. 하위 폴더째 넣지 않습니다.
테스트 원본은 그대로 보관합니다.
방법 2 · 다른 폴더에서 가져오기
화면의 “폴더 선택”으로 Windows 폴더 선택창을 엽니다.
선택창을 사용할 수 없으면 가져올 폴더의 전체 경로를 입력하고 “목록 확인”을 누릅니다.
파일 수·용량·복사 대상·건너뜀·오류를 확인한 뒤 “파일 가져오기”를 누릅니다.
최상위 일반 파일만 수집함으로 복사합니다. 하위 폴더·링크·임시파일은 제외합니다.
가져온 원본 파일은 이동하거나 삭제하지 않습니다. 원본 이름과 내용도 변경하지 않습니다.
분류 결과를 미리 확정하지 않습니다. 복사된 파일은 기존 감시·분류·원본보관 흐름으로 처리합니다.
일부 파일의 읽기 오류는 파일명과 이유를 표시하며 다른 파일을 계속 가져옵니다.
두 방법 모두 같은 분류 규칙·원본보관·SHA 중복·버전 정책을 사용합니다.
선택하거나 입력한 폴더만 읽습니다. 프로그램은 바탕화면·사용자 홈·드라이브 전체를 검색하지 않습니다.
Windows PowerShell과 Windows Forms 선택창을 사용하며 별도 패키지 설치는 필요하지 않습니다.
휴대폰으로 localhost 화면을 원격 조작하는 방식은 지원하지 않습니다. 모바일 검수는 좁은 화면의 레이아웃 확인입니다.

5. 자동분류 확인
약 2초 동안 파일 상태가 안정되면 원본보관본을 먼저 만듭니다.
보관본과 분류 출력본의 SHA-256을 확인한 뒤 수집함의 작업 복사본을 옮깁니다.
00_원본보관 파일은 자동 삭제하지 않습니다.
UI에서 자동분류 개수와 최근 기록을 예상 결과표와 비교합니다.
같은 내용의 파일은 중복을 알리고 추가 보관·출력하지 않습니다.
중복 입력은 확인을 위해 수집함에 남습니다.
내용이 변하지 않으면 한 실행 중 같은 입력을 계속 기록하지 않습니다.
재시작하면 남아 있는 중복 입력이 한 번 더 기록될 수 있습니다.
같은 이름에 다른 내용은 _v02, _v03으로 저장하며 기존 파일을 덮어쓰지 않습니다.

6. 99_분류확인 사용하기
image001.png와 scan003.pdf는 용도를 자동 확정하지 않습니다.
UI에서 파일을 확인하고 분류 유형을 선택해 “선택한 유형으로 이동”을 누릅니다.
결과 폴더와 기록을 확인합니다.
“기타 · 확인 대기 유지”는 파일을 99_분류확인에 남깁니다.
일부 이미지는 미리보기가 있습니다. PDF 등은 파일을 직접 열어 확인합니다.

7. 종료하기
STOP.bat 또는 UI의 “프로그램 종료”를 사용합니다.
새 파일 감시를 멈추고 진행 중인 처리를 마무리한 뒤 종료 완료 안내를 확인합니다.
다른 Node 프로그램은 종료하지 않습니다.
폴더 복사·이동은 먼저 종료하고 폴더 전체를 옮깁니다.

8. 프로그램 삭제하기
정상 종료한 뒤 필요한 입력·분류 파일·원본보관본을 별도로 보존합니다.
그 뒤 프로그램 폴더 전체를 삭제할 수 있습니다.
폴더 안의 자체 data와 log, 보관본도 함께 삭제됩니다.
OS cache나 browser cache까지 제거된다는 뜻은 아닙니다.

9. 주의사항
실제 업무 원본 대신 복사본으로 먼저 실습합니다.
.tmp / .part / .crdownload / ~$로 시작하는 임시파일은 처리하지 않습니다.
하위 폴더·심볼릭 링크·junction·hardlink는 처리하지 않습니다.
실패는 성공으로 표시하지 않습니다. 입력·보관본과 UI 오류 기록을 확인합니다.
강제 종료 뒤 시작이 거부되면 실행 여부와 남은 제어 기록을 강사와 확인합니다.
원본보관과 registry/log를 임의로 지우면서 재시도하지 않습니다.

10. 알려진 한계
2초 안정은 복사 완료의 추정입니다. 큰 파일은 복사가 끝난 뒤 투입합니다.
장시간 멈춘 복사·전원 차단·저장장치 고장의 절대 무손실을 보증하지 않습니다.
파일 내용·설계 사실을 확인하지 않으며 모델과 외부 참조의 연결을 복구하지 않습니다.
PNG/JPEG/WEBP/GIF 20MB 이하만 미리보기 대상입니다.
Node.js 설치가 필요하므로 Portable Runtime 포함 버전이 아닙니다.

실습파일 안내
building_model.blend / animation_cache.abc는 파일명 분류 시험용 stub(형식만 빌린 예제 파일)입니다.
실제 Blender 모델이나 애니메이션 캐시가 아니며 모델 도구로 열리지 않습니다.
lighting_ref_3000K.jpg는 파일명 분류 시험용이며 실제 3000K 측정·보증 자료가 아닙니다.
office_floorplan.png는 교육용 카페 평면도 복사본이며 오피스 실측도면이 아닙니다.
scan003.pdf는 교육용 PDF 복사본이며 실제 스캔 자료가 아닙니다.
walkthrough.mp4는 1초 정지 화면 영상이며 실제 건축 walkthrough가 아닙니다.
