# 입체·분해도·조닝 체크리스트

- [ ] 오피스 입력이 D2 이동을 마친 실제 회의실 6석 결과다.
- [ ] 카페 입력이 중앙 6석과 하단 2석 반영 결과다.
- [ ] 외곽 비율 12:7과 업무·회의·탕비 구획을 기준 평면과 대조한다.
- [ ] 오피스 업무 4석, 회의실 6석, 탕비·수납 코어가 각 결과에 유지된다.
- [ ] D2와 D3는 업무공간에서 각 실로 독립적으로 연결된다.
- [ ] 탕비 코어 앞이나 외벽 방향으로 계단이 생성되지 않았다.
- [ ] 카페 바·백바와 싱크·머신·쇼케이스의 위치를 대조한다.
- [ ] 카페 W1/W2가 가벽 양쪽에 분리되고 W3도 외벽에 유지된다.
- [ ] 분해도는 천장·조명 / 벽·유리 가벽·문·창 / 바닥·가구 층위가 정렬된다.
- [ ] 실내 서브 시점은 업무공간에서 D2와 회의실 6석 방향을 본다.
- [ ] 버블과 조닝의 동선은 ENTRY → WORK ZONE에서 MEETING과 PANTRY로 분기한다.
