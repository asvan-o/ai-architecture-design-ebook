DJ-CF-01 예시 A | 빠른 이용 · 픽업 편의
강사용 시범 Prompt · 정답 또는 수강생 제출물이 아님

[목적]
빠른 이용과 픽업 편의를 우선한 Z1 제안 이미지를 만든다.

[맥락]
혼자 짧게 머물거나 두 사람이 빠르게 이용하는 상황. 서비스영역은 고정 배경이다.

[입력자료]
현황 이미지 02 PNG(편집 기준·CAM 02) + 기준 평면도 PNG(고정 요소·Z1/S1 확인). 두 안에 같은 파일을 첨부한다. RFP와 공간 조건표의 수치는 아래 고정 조건으로 전달한다.

[작업 단계]
제공 조건 확인 → Z1 전경·중경에 작은 사각 2인 테이블과 경량 좌석 구성 → S1 후면과 카운터 전면 비움 확인 → 같은 CAM 02로 시각화 → 고정 요소 대조

[조건·제한]
D1·W1·W2·C1·외곽 벽체·층고, K1의 위치, S1의 위치·서비스 기능을 유지한다. D1·W1은 CAM 02 뒤에 있으므로 화면에 새로 만들지 않는다. S1은 없애거나 상세 재설계하지 않는다. Z1의 가구·벽면·바닥 분위기·조명·브랜딩 없는 소품만 제안한다. 주방 신설·카운터 이전·구조 변경·설비 재설계·서비스영역 상세 재설계·화장실 및 주방·설비 상세계획은 제외한다. 좌석 수는 12~16석의 교육용 목표이며 이미지로 실제 수용인원을 확정하지 않는다. S1 후면 벽·바닥과 K1 상판은 비워 둔다. 모든 새 좌석은 K1 전면을 연장한 기능 경계의 고객공간 쪽에 둔다.

[출력 형식]
같은 CAM 02의 3:2 가로 이미지 1장. 텍스트·로고·사람 없이 고정 요소와 가구 구성을 읽을 수 있게 표현한다.

[검토 기준]
고정 요소 유지 / 작은 사각 테이블·경량 좌석 / 우측 픽업 접근 / S1 비움 / 짧은 이용 전략 / 임의 구조 변경 없음

도구 사용: 한국어 실습용 구조화 Prompt입니다. 실제 내장 image_gen 호출 원문은 별도 generation-prompt.txt에 보존합니다. Nano Banana에서 직접 실행한 결과라고 표시하지 않습니다.
