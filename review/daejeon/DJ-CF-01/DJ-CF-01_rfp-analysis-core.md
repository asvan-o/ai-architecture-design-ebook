## 원문 검증과 다음 단계

1. 각 영역의 근거를 RFP·PLAN에 다시 대조한다. 현황 이미지는 공간 표현이며 치수·재료 성능의 근거로 사용하지 않는다.
2. 사람은 PASS / REVISE / REMOVE / ADDITIONAL QUESTION / EXPERT CHECK로 검토할 수 있다. 별도 29행 표를 만들 필요는 없다.
3. 수정한 핵심 내용과 남아 있는 질문을 검증본으로 정리한다. 답변이 없으면 미확정 상태를 보존한다.
4. Brief 작성 Prompt로 핵심 문제·우선순위·실행 전략·평가 기준을 작성한다. 유지·제외 조건은 정확히 전달하되 다른 내용은 다음 디자인 행동으로 바꾼다.

## 상세 29행 매트릭스의 보존 역할

기존 M01~M29 분석·검증·검증본과 Workflow 검토 보고서는 수정 전 R6를 사용한 상세 검토 이력으로 그대로 보존했다. 수치 근거를 추적하는 강사용 참고로 사용할 수 있지만, 그중 M17의 A/B 선지정 설명은 현재 R6에 적용하지 않는다. 현재 전략·비교 판단은 C10과 수정된 RFP를 기준으로 한다. 기존 문서를 새 RFP로 다시 실행한 결과처럼 표시하지 않는다.
