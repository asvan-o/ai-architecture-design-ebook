# DJ-CF-01 Design Brief v0.1

2026-10-08 · review/draft · design-pending · 발주자 답변 미반영

작성 방식: 앞선 검증 Workflow의 Brief v0.1을 유지하고, 승인된 R6 수정에 맞춰 대안 전략의 성격만 갱신했다. 현재 기준은 수정 R6와 수강생용 핵심 분석 C01~C10이다. 기존 M01~M29는 수정 전 상세 검토 이력이며 R6 이외의 근거 추적에 사용한다. 외부 AI 응답이나 강사 승인본이 아니다. 발주자 답변이 없으므로 v1.0으로 확정하지 않는다. 아래 ‘원문 조건’은 교육용 자료의 조건, ‘디자이너 제안’은 이번 샘플의 판단이며 변경 가능한 검토안이다.

## 1. 프로젝트 목표

**원문 조건:** DJ-CF-01 소형 카페의 고객공간 Z1을 리뉴얼한다. 픽업·출입과 좌석 이용의 간섭을 줄이면서 짧은 체류에도 편안한 공간을 만든다. 좌석 최대화보다 이용 흐름·사용성을 우선한다. [M01]

**실행 목표 제안:** 각 안에 대해 ‘어디로 들어와서 주문하고, 어디에서 기다리고, 어떤 좌석을 사용하는가’를 설명할 수 있는 고객공간 구성을 제안한다. 이미지의 분위기와 별도로 이용 흐름 설명을 남긴다. [M03, M29]

## 2. 주요 사용자와 이용 상황

**원문 조건:** 인근 직장인·생활권 고객의 1인 잠시 머무름, 2인 짧은 대화, 출근·점심시간 주문·픽업을 고려한다. [M02]

**검토 방식 제안:** ‘픽업 고객이 접근하는 동안 1인 고객이 착석하는 상황’과 ‘2인 대화 중 다른 고객이 주문하는 상황’을 두 안에 공통으로 대입한다. 이는 검토 시나리오이며 실제 이용 조사 결과가 아니다. 시간대별 비율은 Q1로 확인한다. [M03, M21]

## 3. 핵심 설계 문제

**원문 조건:** 고정된 출입·창호·기둥·카운터·서비스영역 안에서 픽업 대기·이동과 짧은 체류가 서로 방해하지 않아야 한다. [M01, M03~M05]

**문제 재구성 제안:** K1로 접근하는 고객의 움직임을 좌석 이용과 어떻게 분리하고, 남은 Z1에 1인·2인 이용을 어떻게 배치할 것인가? 빈 공간을 좌석으로 채우는 순서보다 ‘접근·대기 관계 → 좌석 군 → 마감·조명’ 순서로 검토한다. 실제 주문·인도 지점은 Q5 답변 전 확정하지 않는다. [M25, M29]

## 4. 설계 우선순위

| 순서 | 실행 기준 | 출처·판단 구분 |
|---|---|---|
| 먼저 | 고정 요소와 과업 범위 준수 여부 확인. 위반한 안은 비교 전에 수정. | 원문 M04·M05·M09·M18을 작업 순서로 구체화 |
| 다음 | D1에서 K1에 접근하는 흐름, 대기와 좌석 이용의 충돌 검토. 인도 지점·대기 방식은 Q5 확인 전 임시 제안으로만 다룸. | 흐름 우선은 원문 M01·M03; 검사 방식은 제안 |
| 다음 | 1인·2인 이용과 12~16석 교육용 목표 검토. 흐름을 해치며 목표 숫자를 맞추지 않음. | 원문 M02·M06 |
| 이후 | 두 안의 사용 전략 차이가 드러난 뒤 따뜻하고 현대적인 마감·조명 방향 제안. | 분위기는 원문 M07; 작업 순서는 제안 M29 |
| 마지막 | 관리·사용성의 근거와 확인이 필요한 성능을 분리하고 조건부 추천 작성. | 원문 M07·M18·M28을 실행 기준으로 구체화 |

흐름 우선과 고정 조건 우선은 이미 RFP에 있다. 이 Brief에서 새로 만든 것은 검사 순서와 시나리오이며 우선순위 원칙 자체를 새 판단이라고 세지 않는다.

## 5. 필수 기능

- 출입·주문·픽업·대기·좌석 이용의 관계를 설명한다. 주문·서비스 기능은 기존 K1·S1을 유지한다. [원문 M03~M05]
- 1인과 2인의 짧은 이용을 지원한다. [원문 M02, M06]
- **제안:** 가구를 고르기 전에 각 기능이 겹치는 지점을 말로 표시한다. 주문·인도 위치를 별도 시설로 신설하는 제안은 하지 않는다. [M03, M09, M25]

## 6. 반드시 유지해야 할 조건

- D1·W1·W2·C1·외곽 벽체·천장 높이, K1 위치와 S1 위치·서비스 기능을 유지한다. S1은 배경이며 새 경계벽을 만들거나 없애지 않는다. [M04, M05]
- 기준 영역 8000×10000mm, 명목 80㎡, H3000mm. 도면의 개구부·기둥·카운터 형상은 기존 PLAN을 연결해서 확인한다. 80㎡ 전체를 고객 좌석 면적으로 보지 않는다. [M10~M14]
- 시점별 화면 밖 요소는 PLAN과 다른 현황 시점으로 확인한다. 이미지에 가구가 보이지 않는다고 기존 가구가 없거나 철거되었다고 확정하지 않는다. [M15]
- **샘플 제작 기준 제안:** RFP의 예시 비교 방식에 맞춰 현황 이미지02(CAM02)를 A/B 공통 편집 입력으로 사용한다. 이미지01은 첫 실습, 01·03은 공간 이해 보조 자료로 구분한다. 원본 이미지02의 구도·시점을 유지한다. [M15, C10·R6, M20]

## 7. 변경 가능한 범위

**원문 조건:** Z1의 가구 배치, 테이블·의자 종류·조합, 벽면 재료·색감, 바닥 분위기, 조명 분위기·등기구, 스타일링과 브랜딩 없는 소품이다. [M08]

**이번 제안:** 사용 전략을 드러내는 가구의 조합·배치부터 바꾸고, 두 안 모두 따뜻하고 현대적인 분위기를 공통 바탕으로 둔다. 소재·색상 변화만으로 A/B 차이를 대신하지 않는다. 신규 가구의 실제 구매와 마감 성능은 아직 확정하지 않는다. [M07, C10·R6, M22, M23, M28]

## 8. 제외 범위

주방 신설 / 카운터 이전 / 구조 변경 / 설비 재설계 / S1 상세 인테리어 재설계 / 화장실 및 주방·설비 상세계획을 제외한다. [원문 M09]

**실행 기준:** 이미지가 기존 서비스영역을 다른 용도나 새 인테리어로 바꾸면 재검토한다. 등기구 제안은 분위기 표현이며 전기 공사나 설치 가능성을 승인한 것이 아니다. [M05, M27]

## 9. 미확정 조건과 현재 가정

| 미확정 조건 | 이번 Brief의 처리 |
|---|---|
| 시간대별 픽업·체류 비율 | 비율을 만들지 않는다. 최종 A/B 선택 보류. [M21] |
| 기존 가구 재사용 | 유무·수량·재사용 비율 미정. 이미지의 가구 종류는 제안이며 구매 결정 아님. [M22] |
| 예산 상한 | 금액·제품·견적을 확정하지 않는다. [M23] |
| 운영 중단 기간 | 일정·공법을 확정하지 않는다. [M24] |
| K1의 주문·인도 및 대기 운영 | Q5에서 확인. 구체 운영·대기 위치는 검토 제안으로만 설명. [M25] |

**현재 사실 가정:** 없음. 미확정에 임의의 숫자나 발주자 답변을 넣지 않았다. 아래 대안 전략은 확인된 현황 사실이 아닌 디자인 제안이다.

## 10. 추가 질문

| 우선순위·질문 | 대상 | 답변이 바꾸는 결정 |
|---|---|---|
| 우선 Q1: 시간대별 픽업·체류 비율과 혼잡 상황은? | 발주자·운영자 | 두 안의 상대적 적합성과 선택 이유 [M21] |

| 다음 Q2: 기존 가구 재사용 의향·목록·상태는? | 발주자 | 가구 구성·구매 범위 [M22] |

## 11. 전문가 확인 항목

실제 치수·가구 배치 가능성, 구조·소방·접근성 등 적합성 [M26], 등기구의 전기·설비·시공 조건 [M27], 제안 재료의 관리·성능·시공 적합성 [M28]은 별도 확인한다. 이번 과제에서 설비·구조 상세계획을 추가하라는 뜻은 아니다. 이미지 검토의 결과는 전문 승인으로 기록하지 않는다.

## 12. 디자인 대안 수립 기준

**원문이 정한 것:** 수정 R6는 사용 방식·공간 사용 전략이 다른 두 대안을 요구하며 구체적인 A/B 전략은 지정하지 않는다. 동일 공간·카메라·고정 요소를 유지하고 가능하면 비슷한 좌석 수로 비교한다. 색상이나 재료만 다른 결과는 서로 다른 공간 대안이 아니다. [C10·R6]

**Brief에서 도출할 수 있는 전략 예시:** 아래 구성은 유일한 정답이 아니며 기존 A/B 결과 이미지를 답안으로 가져온 것이 아니다. 정확한 배치·수량·간격의 실행 가능성은 이 단계에서 검증하지 않았다.

| 비교 요소 | A: 가장자리 좌석과 읽기 쉬운 접근 흐름 | B: 작은 대화 좌석 군과 머무는 편안함 |
|---|---|---|
| 전략의 근거 | R1의 흐름·대기 간섭을 강조한 디자이너 제안 | R3의 1인·2인 이용 및 R4의 사용성을 강조한 디자이너 제안 |
| 좌석 구성 제안 | Z1 가장자리에 짧게 이용하는 1인 좌석과 작은 2인 테이블을 조합 | Z1에 작은 2인 테이블 군과 등받이 있는 의자를 조합하고 1인 이용도 가능하게 함 |
| 흐름 제안 | 좌석 사이를 관통하지 않고 K1로 접근하는 길을 읽기 쉽게 표현 | 주문·픽업 접근이 대화 좌석 군의 중심을 가르지 않도록 가장자리로 연결 |
| 대기 검토 | 접근과 착석이 겹치는 지점을 먼저 검사. 실제 대기·인도 운영은 Q5 확인 | 대기 고객이 대화 군을 둘러싸지 않는지 검사. 실제 운영은 Q5 확인 |
| 분위기 제안 | 따뜻하고 현대적인 공통 방향 안에서 간결한 가구 조합 | 동일한 공통 방향 안에서 좌석 군의 편안함을 드러내는 조명·가구 조합 |
| 비교에서 통제할 것 | 두 안에 같은 현황02·PLAN, 카메라·고정 요소·유사한 좌석 목표 사용 | A와 같은 조건. 더 많은 좌석이나 색상 차이만으로 우위를 만들지 않음 |
| 보류할 판단 | 회전율 향상·대기시간 단축 수치·실제 통로 적합성 | 체류시간 증가·쾌적성 성능·실제 통로 적합성 |

위 전략은 M01·M02·M03·M06·M07·M08·C10·R6·M25·M29를 실행 방식으로 연결한 예시다. 12~16석의 목표는 유지하되 그림 속 의자 수가 실배치 가능성을 증명하지 않는다. 구체 가구 수량을 사실로 추가하지 않는다.

## 13. 결과 비교·검토 기준

| 검토 단계 | 확인할 것 | 기록 방식 |
|---|---|---|
| 1 조건 확인 | 고정 요소·S1·제외 범위·동일 시점 유지 여부 | 유지 / 위반 / 화면만으로 판단 불가. 위반은 수정 후 비교. [M04·M05·M09·C10·R6] |
| 2 사용 전략 | 같은 두 이용 시나리오에서 접근·대기·좌석 관계가 어떻게 다른가? | 이미지에서 보이는 근거 + 설명. 개선 효과 수치를 만들지 않음. [M02·M03·M18] |
| 3 가구·체류 | 1인·2인 이용을 어떻게 지원하며 색상 이외의 차이가 있는가? | 좌석 조합·군집·통과 관계를 비교. [M02·M06·C10·R6] |
| 4 분위기·관리 | 따뜻하고 현대적인 인상과 관리 고려의 근거는? | 시각적 제안과 성능 확인 필요사항을 분리. [M07·M28] |
| 5 선택 | 어떤 확인 답변이 있을 때 어느 안을 우선 검토할 것인가? | 조건부 추천 + 남은 질문. 현재 승자 확정 없음. [M18·M21~M25] |

예: 픽업 혼잡이 주요 문제라는 Q1·Q5 답변이 확인되면 A의 접근 흐름을 우선 검토한다. 짧은 대화의 편안함이 우선이라는 답변이 확인되면 B의 좌석 군을 우선 검토한다. 이는 선택 규칙의 제안이며 그런 답변을 이미 받았다는 뜻이 아니다. 어느 경우에도 고정·범위 조건 위반은 허용하지 않는다.

이미지 Prompt에는 이 중 눈으로 확인할 공간 지시와 금지 조건을 옮긴다. 예산·기간·고객 비율이나 전문 적합성을 이미지가 해결한 사실처럼 적지 않는다.

수정 R6는 A/B의 정답을 미리 정하지 않는다. 위 두 전략은 요구를 실행 기준으로 바꾼 가능한 예시이며 수강생이 다른 전략을 도출해도 된다. 기존 A/B 이미지와 일치시키기 위해 전략을 선택하지 않는다. 목표·유지·제외 조건의 전달과 실제 디자인 판단을 구분하는 기존 Workflow는 유지한다.
