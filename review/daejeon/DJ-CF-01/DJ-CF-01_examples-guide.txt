DJ-CF-01 결과 예시 A/B 사용 방법

공통 입력: 현황 이미지 02 PNG + 기준 평면도 PNG. 두 안 모두 CAM 02.
S1은 없애는 영역이 아니라 서비스 기능을 유지하는 배경입니다. 개입 대상은 Z1입니다.

[예시 A / 빠른 이용 · 픽업 편의]
작은 사각 2인 테이블과 경량 좌석을 Z1 전경·중경에 배치하고, 우측 카운터 접근 공간을 비웁니다.
- 사각 목재 테이블과 얇은 프레임 의자를 중심으로 이동·재배치하기 쉬운 구성이 표현되었습니다.
- 좌측·중앙 좌석을 묶고 우측 카운터 전면을 비워 빠른 이용과 픽업 접근을 강조했습니다.
- 밝은 테라조 계열 바닥 표현과 간결한 펜던트가 보입니다.
- 모든 테이블이 2인 구성으로 고정되지는 않았습니다. 좌석 수·통로 폭과 후면 좌석의 S1 경계는 도면으로 추가 검토합니다.
구조화 Prompt: DJ-CF-01_example-A-prompt.txt
실제 도구 전달 원문: DJ-CF-01_example-A-generation-prompt.txt
결과 PNG: DJ-CF-01_example-A.png

[예시 B / 짧은 체류 · 편안함]
Z1 전경에 독립형 낮은 쿠션 벤치와 라운지 좌석·원형 테이블을 대화 단위로 묶고, 우측 카운터 접근 공간을 유지합니다.
- 전경의 독립형 쿠션 벤치와 원형 테이블, 두 라운지 의자가 대화 단위를 만듭니다.
- 우측 카운터 접근 여유를 남기면서 앉는 방식과 체류의 편안함을 강조했습니다.
- 기존 회색 바닥을 유지하는 방향에 쿠션 질감·목재·확산형 펜던트를 더했습니다.
- Prompt의 2~3개 조명 요청보다 많은 4개가 표현되었습니다. 생성 변동성의 검토 사례로 기록하며 정답으로 제시하지 않습니다.
구조화 Prompt: DJ-CF-01_example-B-prompt.txt
실제 도구 전달 원문: DJ-CF-01_example-B-generation-prompt.txt
결과 PNG: DJ-CF-01_example-B.png

[실제 제작과 증빙]
실제 도구는 Codex 내장 image_gen이며 세부 모델 식별자는 도구가 제공하지 않습니다. Nano Banana 실행 결과라고 표시하지 않습니다. generation-prompt.txt는 실제 전달 원문이고, prompt.txt는 이를 설명하는 한국어 실습용 구조입니다. 생성 기록 JSON에 호출 시각, 실제 인수, 입력 파일 해시, 생성 원본 경로, 결과 해시와 채택 여부를 남겼습니다. 파일 연결 증빙과 디자인 조건 충족 판정은 구분합니다.

[다른 이미지 도구에서 실습하기]
1. 현재 R6는 A/B의 전략을 지정하지 않습니다. 수강생이 분석·검증 후 Brief에서 두 전략을 정합니다. 기존 A/B는 가능한 전략의 예시입니다.
2. 학습용 7단 Prompt로 구성 요소를 이해한 뒤, DJ-CF-01_image-prompt-execution.txt의 [선택한 대안 이름]을 Brief의 이름으로 바꿉니다.
3. 같은 현황 02·평면도 PNG·Brief를 첨부하고 두 안을 각각 실행합니다. 긴 generation Prompt는 기본 실습 입력이 아닙니다.
4. 결과와 원본을 대조해 카메라·C1·W2·K1·S1과 변경 범위를 확인합니다. 부분 수정도 원본에서 시작하고 고정 조건을 유지합니다.
5. 좌석 수·통로 폭·치수·재료 성능·법적 적합성은 이미지로 확정하지 않습니다.

[사용 순서]
수강생의 조건 분석·첫 Prompt·자체 판단을 먼저 기록한 뒤 강사가 A/B를 비교 시연합니다. 전체 Brief와 A/B 완성은 제1차시 필수 완료 범위가 아닙니다. 예시 이미지를 현황 입력이나 정답으로 다시 제공하지 않습니다.

동일한 현황 02·평면도 PNG를 입력한 CAM 02 비교 후보입니다. C1·W2·K1 및 벽체의 주요 화면상 위치 관계와 서비스 배경 유지 여부를 시각 검토했습니다. 픽셀 단위 정합을 보증하지 않으며, 12~16석 달성·통로 폭·후면 가구의 S1 경계 간섭·재료 성능은 검증하지 않았습니다. Prompt가 완전히 그대로 구현되었다고 표시하지 않습니다. A의 테이블별 좌석 구성과 B의 조명 개수 차이도 비교 판단에 포함합니다.
