도면 제출 전 빠른 점검 · 사용방법

1. 무엇을 하는 프로그램인가
도면 파일명을 한꺼번에 읽어 도면번호·도면명·리비전·파일형식을 정리하고 확인할 항목을 보여주는 작은 읽기 전용 도구입니다. 파일 내부 내용을 열거나 설계 오류를 판단하지 않습니다.

2. 준비와 실행
프로그램 ZIP을 모두 압축 해제하고 drawing-quick-check 폴더의 index.html을 Chrome 또는 Edge로 엽니다. 설치·관리자 권한·Node.js·인터넷 연결이 필요하지 않습니다. 파일 하나만 옮기지 말고 폴더 전체를 함께 보관하세요. 강의의 브라우저 실행 데모도 같은 프로그램입니다.

3. 파일 선택
“도면 폴더 선택”은 하위 폴더까지 포함합니다. “파일 여러 개 선택”은 선택한 파일만 확인합니다. 선택할 때마다 이전 목록을 대체하며 취소하면 현재 목록을 유지합니다. 폴더 기능을 지원하지 않는 브라우저에서는 여러 파일 선택을 사용합니다.
실습 테스트 ZIP을 푼 DRAWING_TEST 폴더를 선택해보세요. 내장 “샘플 불러오기”도 같은 이름·상대경로를 사용합니다.

4. 결과 읽기
기본 파일명: A-101_1층평면도_R02.pdf
도면번호 A-101 / 도면명 1층평면도 / 리비전 R02 / 형식 PDF
지원 형식: PDF, DWG, DXF. 영문 대소문자는 구분하지 않습니다. R번호는 숫자로 비교하므로 R10이 R02보다 큽니다. R2와 R02는 같은 리비전입니다.
파일마다 한 줄이며 해당 파일 리비전·상대경로와 번호별 최신 후보·최신 후보 보유 형식을 함께 보여줍니다.
정상: 파일명 규칙과 최신 후보의 PDF/DWG 짝이 맞음. 도면 내용·제출 승인이 확인됐다는 뜻이 아닙니다.
확인 필요: 최신 후보의 PDF 또는 DWG 없음, 같은 번호·숫자 리비전·형식의 중복 후보, 같은 번호의 도면명 차이.
이전 리비전: 최대 R번호보다 낮음. 삭제하지 않으며, 이전 파일에도 중복 사항이 있으면 “확인 필요”를 우선 표시합니다. 이 파일은 두 필터에서 모두 볼 수 있습니다.
파일명 확인: 정해진 이름 규칙으로 구분할 수 없음.
DXF는 보조 형식입니다. DXF가 있어도 최신 PDF/DWG 짝을 대신하지 않습니다.

5. 숫자와 필터
전체 파일은 선택한 파일 수이며 제외 대상도 포함합니다. 도면번호는 규칙에 맞는 고유 번호 수입니다. 확인 필요와 이전 리비전은 각각 파일 수이며 서로 겹칠 수 있습니다. 제외 수는 별도 표시합니다.
전체 / 정상 / 확인 필요 / 이전 리비전 필터로 살펴봅니다. 번호가 건너뛰어도 누락이라고 단정하지 않습니다.

6. 제외하는 파일
지원하지 않는 형식, .tmp/.part/.crdownload/.bak/~ 임시·백업 파일, ~ 또는 ~$로 시작하는 이름, 점으로 시작하는 파일·폴더 경로를 제외하고 이유를 보여줍니다.
Windows의 숨김 속성만 설정된 파일은 브라우저 파일정보에서 구분할 수 없습니다. 이름 기반 제외 규칙만 적용합니다.

7. CSV 저장
“결과 CSV”는 현재 필터와 관계없이 모든 점검 결과와 제외 이유를 저장합니다. UTF-8 BOM으로 한글을 보존하며 쉼표·큰따옴표 등을 처리합니다. 수식처럼 시작하는 값은 작은따옴표를 붙여 문자로 저장합니다. CSV는 도면 또는 제출 승인을 대체하지 않습니다.

8. 초기화와 종료
초기화는 화면 목록만 지웁니다. 원본 파일은 변경하지 않습니다. 창을 닫으면 프로그램이 종료되며 브라우저 안의 목록도 사라집니다. 계속 보관하려면 먼저 CSV를 저장하세요. 프로그램 폴더를 삭제하면 프로그램 파일이 제거됩니다. 브라우저/운영체제의 방문기록·다운로드 기록까지 지워진다는 의미는 아닙니다.

9. 실습파일 주의
DRAWING_TEST의 모든 파일은 이름 점검용 stub이며 실제 PDF·DWG·DXF 도면이 아닙니다. CAD나 PDF 뷰어로 열 자료가 아닙니다. sample-manifest.json에 파일별 예상 결과를 제공합니다. lighting이나 설계 성능 측정 자료는 포함하지 않습니다.

10. 알려진 한계
교육용 파일명 규칙에 한정합니다. 다른 회사의 명명 규칙, 최종 승인번호, 파일 내부의 도면명·내용·오류·법규·적합성은 알 수 없습니다. 가장 높은 R번호도 최신 “후보”이며 제출본 확정은 사람이 합니다. 파일 정보는 페이지 메모리에서만 처리하고 외부로 보내지 않습니다. 파일을 자동 삭제·이동·이름 변경하지 않습니다. 표의 파일명·도면명·상대경로는 일반 문자로 표시합니다.
