# 소형 근린생활시설 외관 리뉴얼

출입 인지성과 거리 경관의 균형

교육용 가상 프로젝트 · review/draft · 실측·시공·법규 적합성을 증명하지 않음

## 01 프로젝트 개요
건물 운영자는 노후한 2층 근린생활시설의 도로변 전면을 개선하려 합니다. 건물의 규모와 개구부는 그대로 두고, 처음 방문하는 사람이 입구를 쉽게 찾으면서 주변 거리와 자연스럽게 어울리는 외관을 제안해 주세요.

## 02 주요 사용자
처음 방문하는 보행자, 1층 상업시설 이용자, 2층 업무·서비스 시설 이용자, 건물 운영자. D1은 두 층 이용자의 공용 진입구로 설정합니다. 내부 계단·점포 구성은 이번 과제에서 다루지 않습니다.

## 03 설계 문제
주 출입구가 창호와 비슷하게 읽혀 진입 위치를 찾기 어렵고, 단조로운 외벽과 빈 간판 영역 때문에 건물의 인상이 약합니다. 1층과 2층이 한 건물로 읽히면서도 보행자가 입구를 바로 찾을 수 있어야 합니다.

## 04 요구조건
R1 / 출입 인지성 / 처음 방문한 보행자가 D1을 주 출입구로 알아볼 수 있도록 전면에서 시각적 우선순위를 만들어 주세요.

R2 / 유지 조건 / 10m 폭, 7.2m 높이의 2층 매스, 지붕선, 층간 관계, D1 1개와 W1~W5의 위치·개수·크기, 창호 사이 벽체를 유지합니다. 구조체와 인접 건물·보도·도로의 기본 관계도 변경하지 않습니다.

R3 / 외관 정체성 / 단조로운 외관 인상을 개선하되 증축이나 과도한 조형물 없이 기존 건물에 맞는 정체성을 제안해 주세요.

R4 / 변경 범위 / 외장재·외벽 색상·입구 주변 마감과 강조, 소형 캐노피, SZ1의 무문자 간판 표현, 외부 조명, 소규모 조경을 제안할 수 있습니다. 창호를 가리거나 보행을 방해하지 마세요.

R5 / 주변 관계 / 주변의 단순한 저층 건물과 거리 환경을 고려해 존재감과 조화를 함께 설명해 주세요. 실제 상호·로고 대신 비어 있는 SZ1을 사용합니다.

R6 / 대안 제안 / R1~R5를 근거로 서로 다른 외관 전략 2개를 제안해 주세요. 동일 IMAGE 01, 카메라, 매스, 개구부, 주간 조건으로 비교합니다. 색상만 다른 결과는 서로 다른 전략으로 보지 않습니다. 각 전략의 장점·한계와 선택 이유를 설명해 주세요.

유지: 전체 매스·폭·높이·2층 규모·지붕선·층간 관계 / D1·W1~W5 / 구조체 기본 위치 / 창호 사이 벽체 / 인접 건물·보도·도로 관계. SZ1은 제공 위치·범위 안에서 표현합니다.

변경: 외장 마감 재료·색상 / 입구 주변 강조 / 소형 캐노피 / SZ1의 무문자 표현 / 외부 조명 / 소규모 조경. 개구부를 침범하지 않고, 보행 공간은 비워 둡니다.

제외: 층수·폭·높이 변경, 출입구·창호 이동이나 확대, 새 대형 개구부, 증축, 구조체 삭제, 발코니·대형 구조물·과도한 조형물, 도로 구조 변경. 실내·구조·설비·시공 상세와 실제 인허가 판단은 과제 밖입니다.

## 05 제공 조건 / 미확정 조건
K1 / 교육용 형상 / 전면 폭 10m, 높이 7.2m, 깊이 6m. 2층 바닥 기준 +3.6m, 지붕 슬래브 +6.8m, 상단 +7.2m.

K2 / 개구부 / D1 1개 / 1층 W1·W2 / 2층 W3·W4·W5. 위치·크기는 기준 입면도에서 확인. 우측 측벽에 개구부 없음.

K3 / 간판과 거리 / SZ1 8.4×0.5m, 하단 +3.0m. 전면 보도 깊이 2m와 평탄한 도로 관계를 교육용으로 설정. 공공 보도 점유는 허용 조건이 아님.

K4 / 사용 범위 / 1층 상업, 2층 업무·서비스, 공용 D1. 실내계획·용도변경·실제 입주 업종은 설계 범위 밖. 현황은 가상이며 실제 주소·발주자 없음.

U1 / 주요 이용 시간대 및 야간 운영 여부

U2 / 예산 및 공사 중 영업 유지 조건

U3 / 기존 외장재·간판 영역의 보존 여부

U4 / 원하는 건물 이미지 또는 분위기

## 06 요청 결과물
- 서로 다른 외관 리뉴얼 콘셉트 2안
- 각 안의 디자인 전략과 출입 인지성 개선 방향
- 외장재·입구·간판 영역·조명의 주요 제안
- 기존 외관과 비교 가능한 콘셉트 이미지
- 유지 조건 준수 여부와 추가 확인이 필요한 사항

## 07 자료 사용 방법
RFP는 요청과 범위의 근거, 기준 입면도는 가상 치수·개구부의 근거입니다. IMAGE 01은 편집 원본, IMAGE 02는 같은 건물의 깊이·출입 관계를 읽는 보조 자료입니다. 별도 Reference를 쓰면 재료·분위기만 참고하고 구조를 가져오지 않습니다.

외장재 성능·부착, 캐노피 구조·돌출 가능 범위, 간판·조명·보도 관련 기준, 전기·방수 상세는 해당 전문가가 별도 확인해야 합니다. 이미지로 적합성을 확정하지 않습니다.
