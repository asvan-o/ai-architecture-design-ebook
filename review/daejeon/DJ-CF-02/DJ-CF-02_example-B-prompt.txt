목적
현황 IMAGE 01을 '거리의 수평 리듬' 전략의 외관 콘셉트로 바꿔 주세요.

맥락
처음 방문하는 사람이 공용 D1을 쉽게 찾고, 단순한 저층 거리와 어울리는 2층 근린생활시설입니다.

입력자료
IMAGE 01은 편집 원본, 입면도는 고정 요소의 근거, 검증한 Brief는 전략의 기준입니다. IMAGE 02는 깊이 이해용입니다.

작업 단계
고정 요소를 확인한 뒤 선택한 전략을 적용하고 원본과 대조하세요.

조건·제한
매스·2층·폭·높이·지붕선·D1·W1~W5·SZ1 영역·카메라·주변 도로를 유지하세요. 1층의 불투명 벽에 얇은 점토벽돌 계열 마감, 상부에 중립적인 회벽을 제안합니다. SZ1을 따라 수평 띠와 낮은 강도의 선형 조명을 묶고, 벽체 사이 작은 조명을 반복하며 D1에 보조 빛을 둡니다. 돌출 캐노피 없이 전면 리듬으로 안내합니다. 창호 확대·이동·추가, 증축·발코니·구조 변경·문자·로고·보도 점유는 금지합니다.

출력 형식
원본과 같은 시점·화면비·주간 조건의 사실적인 이미지 1장.

검토 기준
입면도와 원본 대비 고정 요소, D1 인지성, 거리 조화와 전략 차이를 확인하세요. 예산·야간 운영·철거 가능 여부, 실제 치수·구조·시공·법규는 확정하지 않습니다.
