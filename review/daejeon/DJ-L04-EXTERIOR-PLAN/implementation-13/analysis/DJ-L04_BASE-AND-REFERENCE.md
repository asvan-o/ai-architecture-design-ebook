# 기준 이미지와 참고자료 역할

- BASE01·02·03은 건물 매스·개구부·카메라·주변 맥락의 기준입니다. 같은 원본에서 A/B를 각각 실행합니다.
- A는 기존 크림 라임스톤·수직 월넛 포털·브론즈 안입니다. A2는 A의 상층을 고정하고 1층 띠·캐노피·포털 프레임만 다크 루버·라인 빛으로 보완합니다.
- B는 상층 세로 골 웜 테라코타·블랙 창틀, 저층 바살트 슬레이트·블랙 캐노피와 따뜻한 소핏/쇼윈도 빛을 비교합니다.
- m-21-dark-walnut.png는 A/A2의 목재 색·결, m-02-almond-limestone.png는 A의 크림 석재, m-10-charcoal-microcement.png는 B 저층의 짙은 색 대비만 참고합니다.
- m-24-natural-oak.png와 m-20-light-grey-microcement.png는 선택 색·질감 참고입니다. 현재 A2의 첨부를 연회색으로 대신하지 않습니다.
- 스케치 분기의 08 선화와 09 월넛·브론즈·웜 스톤 콘셉트는 보존합니다. 10의 편집 대상은 09 한 장이며, 상부 2~3층·개구부·월넛 포털·카메라는 유지 기준입니다. 1층의 밝은 샴페인 브론즈 수직 핀·크림 화이트 코브 면발광·트래버틴/웜 라임스톤·따뜻한 쇼룸 전시만 보완합니다. A/A2·조경 분기의 입력으로 바꾸지 않습니다.
- 재질 Reference는 색·무늬·질감 자료입니다. 다른 건물의 구조·가구 배치를 가져오거나 실제 제품·가격·시공·성능을 확정하지 않습니다.
- 7단·짧은 요청문은 학습용 문안입니다. 실제 이미지 도구 호출 기록과 분리해 읽습니다.
