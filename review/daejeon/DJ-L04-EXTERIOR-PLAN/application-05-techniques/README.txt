제4차시 외관 인페인팅 실습자료

기준 건물3종·재질 참고5종·A/B/A2·응용 이미지13종·학습용 Prompt TXT42종을 제공합니다.
원본→A와 원본→B는 독립 대안입니다. A→A2는 상층A를 고정하고 1층 띠·캐노피·포털 프레임에 다크 월넛/브론즈 루버와 따뜻한 빛을 더하는 국소 보완입니다.
조경은 A→05(다층 석재 플랜터·다간형 수목·그라스·초화·하부 빛·진입 포장)→11(보행 광장·가로수·벤치·볼라드)→12(사람·노천 좌석) 순서입니다.
06 석양과07 입구 근접은 현재05,13 코너·15 반조감은 현재11+12,14 보행자 뷰는 현재12를 기준으로 합니다.
08 선화→09 래피드→10 국소 보완은 보존된 별도 스케치 분기입니다. 새 A·05에서 만든 연속 결과가 아닙니다.

7step TXT는 학습용 조건 정리, short TXT는 같은 조건의 압축 요청문입니다. 실제 도구 호출·추가 국소 보정 기록과 구분합니다. 같은 문구·입력도 같은 생성 결과를 보장하지 않습니다.
첨부 순서와 역할은 각 카드와 manifest의 attachments에서 확인합니다. A2의 재질 첨부는 다크 월넛이며 연회색 재질을 자동 적용하지 않습니다.
건물 매스·창 그리드·문·캐노피 외곽·카메라와 원래 거리 경계를 고정합니다. 입구·보행 경로를 비우고 도로·이웃 대지로 임의 확장하지 않습니다.
식재·가구·노천 좌석은 교육용 가정입니다. 실제 가용 대지·보행 유효폭·설치/영업 허가·법규·구조·재료 및 조명 성능은 별도 확인합니다.
학습과 비교를 위한 시각자료이며 실측·시공 도면이나 제품 성능 자료가 아닙니다.
