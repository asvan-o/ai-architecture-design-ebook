7step TXT에는 예시 이미지의 실제 생성 원문을 그대로 보존했습니다. short TXT는 핵심 유지·변경·금지 조건을 3~5문장으로 압축한 실무 반복 실행용 요청문입니다. 예시 이미지를 short로 생성했다는 뜻이 아니며, 같은 결과를 보장하지 않습니다. 첨부 순서와 역할은 manifest의 attachments에서 확인합니다.

실제 호출 Prompt와 표시·복사·TXT의 일치는 검사하지만 ChatGPT/Nano Banana의 모델·버전·실행마다 동일 픽셀 결과를 보장하지 않습니다. 이 예시는 ChatGPT 화면에서 별도로 재실행해 검증한 결과가 아닙니다.

이미지는 초기 시각 대안입니다. 실제 제품·구조 안전·법규·시공비·단열·방화·내후 성능은 별도 검토합니다.
