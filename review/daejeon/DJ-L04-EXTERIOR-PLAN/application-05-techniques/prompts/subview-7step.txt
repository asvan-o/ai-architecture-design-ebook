첨부 이미지: 05_landscape-additive.png (현재 메인 외관·조경 기준)

목적
입구 포털을 사선 아이레벨 근접 시점으로 보여 준다.

맥락
정면 입력에 없는 측벽·깊이·지붕·가려진 면은 새 시점에서 생성 추정된다. 같은 3D 모델의 검증된 카메라 이동으로 설명하지 않는다.

입력자료
05_landscape-additive.png (현재 메인 외관·조경 기준). 편집 원본이 건물·카메라 기준이며 다른 자료는 명시한 역할로만 참고한다.

작업 단계
크림 석재·브론즈 띠·수직 월넛 포털과 새 다층 석재 플랜터·다간형 수목·그라스·초화·하부 빛의 디자인 언어를 유지하고 입구 가까이에서 사선으로 본다.

조건·제한
매스·층수·창 그리드·문·캐노피·마감·식재와 가구의 상대 배치를 유지하고 카메라 시점만 바꾼다. 중앙 출입구와 연속된 보행 동선을 비우고 쇼윈도·문을 가리지 않는다. 보도와 차도·이웃 대지의 경계를 옮기거나 길을 넓히지 않는다. 식재·가구·조명 배치는 교육용 가정이며 실제 가용 대지·유효 보행 폭·설치 허가는 미확정이다.
이미지로 실제 치수·제품 규격·구조 안전·법규 적합성·시공비·단열·방화·조명 성능을 확정하지 않는다. 요청 밖 창·문·층·문자·로고·차량을 만들지 않는다.

출력 형식
지정한 시점의 현실적인 외관 이미지 한 장만 만든다. 비교판·주석·글자는 넣지 않는다.

검토 기준
입구 근접 시점의 포털·플랜터 재료와 관계가 메인05와 이어지는가? 가려진 창·새 측면·깊이·원경의 추정과 비대상 변화를 원본과 대조해 구분한다.
