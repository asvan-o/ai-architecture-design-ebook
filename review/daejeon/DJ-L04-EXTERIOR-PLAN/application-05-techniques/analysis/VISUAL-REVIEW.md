# 현재 외관·조경 연속 예시 비교 안내

## 입력과 변경 범위
- 교체 B는 원본 EXT-BASE-01에서 독립 실행한 재질·조명 제안입니다. 상층은 세로 골 테라코타, 저층은 바살트 질감과 블랙 캐노피·웜 쇼룸 빛으로 구분합니다.
- A2는 A에서 출발합니다. 1층 수평 밴드·캐노피·포털의 루버와 빛만 보완했습니다. 교재 결과는 생성 후 상부를 기준 A의 원본으로 복원한 국소 편집 예시입니다. 생성 모델이 한 번에 모든 비대상 영역을 완전히 고정했다고 해석하지 않습니다.
- 05는 A에 다층 석재 플랜터·다간형 수목·그라스·초화·하부 조명과 진입 포장을 더한 주간 예시입니다.
- 11은 05의 조경을 바탕으로 외곽 교목·석재 벤치·볼라드·포장 패턴을 더합니다. 12는 이를 바탕으로 보행자·방문객·테이블 이용을 더합니다.
- 08 선화와 09 월넛·브론즈·웜 스톤 콘셉트는 별도 스케치 분기의 기준으로 보존합니다. 새 10은 09의 상부 2~3층·개구부·수직 월넛 포털을 유지 기준으로 두고, 1층의 밝은 수직 핀·코브 면발광·석재 기둥과 기단·쇼룸 전시를 보완합니다. Part 2 A2의 어두운 수평 루버 보완과 구분합니다.

## 실제로 대조할 점
- B의 상층 창 8개·1층 쇼윈도 2개·중앙 문과 외곽 매스를 원본과 대조합니다. 어두운 석재와 밝은 내부가 구분되는지 살펴봅니다.
- A2의 상부 크림 마감과 창 구획을 A와 대조하고, 1층 루버·소핏 빛이 유리를 가리지 않는지 확인합니다.
- 05/11의 중앙 진입 접근은 비워 둡니다. 12에서는 출입 연출로 기존 문 한 짝이 열려 보이고, 보행자와 이용객은 일시적인 활동 요소입니다. 인원수 자체를 정답으로 삼지 않습니다.
- 06은 새 05를 기준으로 시간대·조명을 바꿨습니다. 식재·플랜터 위치와 색감 변화, 유리 반사·노출의 재표현을 함께 대조합니다.
- 07/13/14/15는 새 메인의 재료·다층 식재를 다른 시점으로 확장한 시각 제안입니다. 식재의 세부 분포와 사람 위치는 재해석될 수 있습니다. 측면·옥상·가려진 공간은 도면·모델 없이 정확히 복원했다고 단정하지 않습니다.
- 09/10은 상부 마감·창 그리드·포털 외곽과 1층 변경 경계를 나누어 비교합니다. 새 10의 샴페인 브론즈 수직 핀·플리츠, 상하 라인 빛, 크림 화이트 코브 면발광과 둘레 빛, 석재 기단 하부 그레이징, 유리 너머 전시 포디움이 지정 범위에 있는지 확인합니다. 유리 반사와 주변의 재표현도 따로 살펴봅니다. 학습 요청문과 실제 도구 호출·후처리 기록을 같은 원문으로 취급하지 않습니다.

## 자료의 경계
- 사진 속 루버·석재·식재·빛은 교육용 시각 제안입니다. 실제 제품·수명·방화·내구·가격·구조·시공 상세를 확정하지 않습니다.
- 3000K는 따뜻한 조명의 표현 의도이며 실제 측정·보증 수치가 아닙니다.
- 조경은 가상의 외부 공간 제안입니다. 실제 대지 경계·보행 유효 폭·공공 보도 점용·피난·유지관리·수종 적합성은 별도 자료와 전문가 검토가 필요합니다.
- 학생용 7단·짧은 요청문은 조건을 배우는 문안입니다. 실제 제작 도구 호출·기준 영역 복원 기록과 구분하며, 같은 문장으로 동일한 결과를 보장하지 않습니다.
