검토한 구조에 따라 “도면 제출 전 빠른 점검”을 구현해줘.

작업 폴더
내가 연결한 실습 프로젝트 안의 drawing-quick-check 폴더에만 새 프로그램을 만든다. 다른 업무 파일을 수정하지 않는다. 동일 이름 파일이 이미 있다면 먼저 내용을 확인하고 임의로 덮어쓰지 않는다.

생성 파일
index.html, app.js, rules.js, style.css, sample-data.js, sample-manifest.json, README.txt. 외부 라이브러리 없이 정적 웹으로 만들고, Chrome/Edge에서 index.html을 직접 열거나 로컬 정적 서버로 사용할 수 있게 한다.

입력과 파일명 규칙
폴더 선택과 여러 파일 선택을 모두 제공한다. FileList의 파일명·크기·수정일·상대경로만 읽고 파일 본문은 읽지 않는다.
[영문 코드-숫자]_[도면명]_R[정수].[pdf|dwg|dxf]를 교육용 규칙으로 사용한다. 예: A-101_1층평면도_R02.pdf. 한글 도면명을 지원한다. 리비전은 문자열이 아닌 숫자로 비교하고 R2와 R02는 같은 리비전으로 본다.

상태 판정
같은 번호의 가장 큰 R번호는 최신 후보이며 최종 제출본으로 확정하지 않는다. 낮은 R번호는 이전 리비전이다.
최신 후보의 PDF/DWG 짝이 없으면 형식 확인 필요로 표시한다. DXF는 이 짝을 대신하지 않는다.
같은 번호·숫자 R·형식이 두 개 이상이면 폴더가 달라도 중복 후보이다. 파일명 규칙 오류는 파일명 확인, 같은 번호의 도면명 차이도 확인 대상으로 표시한다.
지원하지 않는 확장자, 임시·백업 이름, 점으로 시작하는 파일·폴더를 제외하고 이유를 보여준다. Windows 숨김 속성 자체는 판단하지 못한다는 한계를 명시한다.
전체/정상/확인 필요/이전 리비전 필터를 제공한다. 요약 숫자는 파일 수와 고유 도면번호 수를 구분한다. 도면번호가 건너뛴다는 이유로 누락을 확정하지 않는다.

파일 보호와 외부 전송
입력 파일 삭제·이동·이름 변경·수정 금지. 파일 본문 분석·설계 적합성·법규 판단 금지. 외부 전송·계정·DB·클라우드 저장 금지. 결과는 페이지 메모리에서만 보관한다.

CSV
사용자가 누르면 상태·확인사항·상대경로를 포함한 전체 결과와 제외 목록을 UTF-8 BOM CSV로 저장한다. 쉼표·큰따옴표·줄바꿈을 escaping하고 수식처럼 시작하는 값은 문자로 처리한다.

화면
단일 화면, 다음 행동을 알려주는 빈 화면, 샘플 불러오기·초기화, 텍스트와 기호를 함께 쓰는 상태 표시, 키보드 접근성을 제공한다. 1440/390/320px에서 잘림 없이 확인하고 모바일 결과는 카드로 바꾼다. 파일명·도면명은 HTML이 아닌 일반 문자로 표시한다.

기대 결과와 실제 결과 확인
15개 이상의 실제 이름 stub을 별도 테스트 세트로 만든다. 정상/형식 누락/숫자 R02와 R10/중복 하위폴더/잘못된 이름/제외 파일을 검증한다. stub은 실제 도면이 아니라고 표시한다.
새 임시 위치에 프로그램 ZIP을 풀어 파일과 폴더 선택, 샘플, 네 필터, CSV 한글·escaping, 초기화, 외부 요청 0, 원본 변경 0을 확인한다. 실제 Excel 확인이 가능하면 실행하고 불가능하면 미검증으로 명시한다.

오류 처리
파일 선택 취소 시 기존 목록을 유지한다. 처리 실패는 이해하기 쉬운 문구로 알리고 원본을 변경하지 않는다. 미검증 기능을 완료했다고 표시하지 않는다.

완료 보고
구현 파일·판정 기준·실제 검증 결과·한계·추가 수정 사항을 보고한다. 첫 요청 한 번만으로 최종 프로그램이 완성됐다고 설명하지 않는다.
