# 교육용 오피스 2D 가구 치수 보정 원천

## 목적과 범위

기존 자체 제작 A3 오피스 평면도의 소장 책상을 2,800×1,200mm에서 **1,800×800mm**로, 회의테이블을 5,600×2,100mm에서 **3,200×1,200mm·8석(북4/남4)**으로 줄인 재현용 소스입니다. 외부 실제 도면이나 광주 원본을 포함하지 않습니다.

- `executed-generator.py`: 실제 실행한 `scripts/correct-workbook-office-furniture.py`의 동일 바이트 사본입니다. PDF의 가구 사각형 11개만 바꾸고, 새 크기 안내 한 줄을 기존 빈 여백에 추가합니다. 원래 벽·문·치수·텍스트 연산은 유지합니다.
- `baseline/`: 승인 전 커밋 `7f5924ca4e47e00c58a20446926819360a424acc`에서 읽은 자체 제작 PDF·PNG·선화입니다.
- `furniture-rectangles.json`: 기준 파일 해시, 기존/변경 사각형 11개, 종이 좌표에서 실제 미터로 환산하는 식, 최종 배포용 파일 해시입니다.
- `office-geometry.json`: 수정된 가구 치수와 축선 최대 24×16m / 중심선 다각형 348㎡(약105평)의 교육용 설정을 담은 활성 JSON 사본입니다.

## 안전한 재현

Python의 Pillow·pypdf·reportlab, Poppler `pdftoppm` 및 맑은 고딕(`C:/Windows/Fonts/malgun.ttf`)을 사용합니다.

```powershell
python reproduce.py --pdftoppm "설치된 Poppler의 pdftoppm.exe 경로"
```

기본 출력은 이 폴더의 **`reproduction-output/`** 입니다. 다른 출력은 `--output-dir`로 지정합니다. 기존 출력 폴더가 있으면 중단하고, 저장소 루트나 활성 `public/`에는 출력할 수 없습니다. 기존 Blender·서버·활성 이미지·ZIP·manifest는 건드리지 않습니다.

## 검수 기준과 한계

PDF의 도면 종이는 A3 가로이며 `1m = 종이 10mm`입니다. 좌표 변환은 `paperX = 60 + worldX × 10`, `paperY = 70 + worldY × 10`입니다. PNG에서는 `1m = 40px`입니다. JPEG 선화는 가구 영역을 정밀 수정하고 다시 인코딩하므로 영역 밖에도 미세한 JPEG 압축 차이가 생길 수 있지만, 의도적 문자 오류인 `이사실`·`13연승`은 바꾸지 않습니다. 기존 3D 이미지 및 파생본은 이 패키지로 재생성하지 않습니다.

실제 수정에서는 가구 보정 후 안내 각주를 추가하는 두 단계로 저장했습니다. 이 정리본은 동일 실행 함수로 두 작업을 함께 수행합니다. PDF 객체 직렬화·JPEG 재인코딩 횟수와 라이브러리 버전에 따라 재현 출력의 파일 해시는 달라질 수 있으므로, 기록된 최종 해시는 배포 파일의 식별 기준이며 재현 출력이 무조건 같은 바이트라는 주장은 하지 않습니다. 11개 벡터 사각형·추출된 기존 텍스트·각주·이미지 크기·보호된 공간 배치를 대조합니다.

축선/중심선 면적은 법정 바닥면적·실측 면적이 아닙니다. 계단·승강기는 판독·동선 검토용 교육 설정이며 실제 규격·구조·법규 적합성을 보증하지 않습니다.
