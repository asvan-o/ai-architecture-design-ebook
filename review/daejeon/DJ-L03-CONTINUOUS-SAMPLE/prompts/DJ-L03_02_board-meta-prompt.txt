[목적]
첨부한 재질을 적용한 수정 공간을 분석하고, 디자인 방향 보드 제작용 이미지 생성 Prompt 초안을 작성해줘. 지금은 이미지를 생성하지 마.

[맥락]
재직자 대상 건축·인테리어 초기 기획 실습이다. 보드는 공간의 재질·색상·조명·분위기를 한 장에 정리해 다음 이미지 생성의 방향을 전달하는 시각적 기준 자료다.

[입력자료]
A: 리셉션 뒤 지정 벽면에 재질을 적용한 수정 공간 이미지.
B: 제공된 M-21 Dark Walnut 참고 이미지와 이름. 이는 입력자료의 이름이며 실제 시공 제품이 확인되었다는 뜻이 아니다.
기준 공간의 구조·카메라·주요 가구 위치를 유지하고 지정 벽면만 수정하도록 요청했다는 실행 조건.

[작업 단계]
1. 구조·카메라·문·창호·배치와 디자인 요소를 구분한다.
2. 재질, 색상, 조명 인상, 기존 가구의 형태, 공간 분위기, 형태적 특징을 분석한다.
3. 각 내용을 '직접 관찰', '제공된 정보', '추정·확정 불가', '다음 변경 제안'으로 구분한다.
4. 대표 공간 이미지 1장, 주요 표면 정보 약 2개, 팔레트 3색, 조명 인상 1개, 방향명, 키워드 3개, 짧은 설명으로 보드를 구성한다.
5. 사람이 검토한 뒤 이미지 도구에 전달할 수 있는 보드 생성 Prompt 초안을 작성한다.

[조건·제한]
브랜드·제품명·치수·가격·제품성능·조도·실제 색온도를 이미지에서 만들어내지 않는다.
이미지에서 갈색 목무늬가 보이는 것과 실제 월넛이 시공된 사실을 구분한다.
회색 좌석이 패브릭처럼 보여도 실제 섬유 구성과 제품은 확정하지 않는다.
보드용으로 새로운 공간·가구·배치를 창작하지 않는다.
새 스타일이나 재질을 분석 결과인 것처럼 추가하지 않는다.
대표 공간 이미지를 보드에 유지하도록 요청하되 픽셀 보존을 보장한다고 말하지 않는다.
공간과 무관한 장식, 긴 글, 제품 사양표를 넣지 않는다.

[출력 형식]
1. 근거 위치와 정보 구분이 있는 디자인 요소 분석
2. 사람이 확인해야 할 항목
3. 목적 / 맥락 / 입력자료 / 작업 단계 / 조건·제한 / 출력 형식 / 검토 기준으로 나눈 보드 생성 Prompt 초안

[검토 기준]
관찰·제공 정보·추정·제안이 구분되어 있는가?
입력에 없는 사실이나 브랜드가 추가되지 않았는가?
기준 공간과 보드의 역할이 분리되는가?
16:9 보드 한 장으로 읽기 쉬운가?
