# 평면도 수정 체크리스트

- [ ] 외곽 14,400 × 8,400 mm와 비율 12:7을 대조한다.
- [ ] 오피스 X=7,800 구획과 우측 Y=5,400 구획이 7,800/6,600 및 5,400/3,000 치수와 일치한다.
- [ ] 외벽 200 mm, LW 100 mm, 기둥 400 × 400 mm 표기를 읽는다.
- [ ] 업무공간 4석과 회의실 상·하 3석씩 총 6석을 센다.
- [ ] 문 이동의 입력이 실제 회의실 6석 반영 결과다.
- [ ] 기존 D2 문자·문짝·개폐호가 없어지고 새 위치에 D2 한 세트와 90도 개폐호가 있다.
- [ ] D3는 업무공간·진입홀에서 탕비 코어로 직접 연결된다.
- [ ] 탕비 싱크·커피바 2,800 × 650 mm와 수납장을 확인한다.
- [ ] 계단이 없고 W1/W2/W3가 기둥·가벽과 겹치지 않는다.
- [ ] 카페 X=4,800 구획과 4,800/9,600 치수가 일치한다.
- [ ] 카페 중앙 상·하 3석씩 총 6석과 하단 2석을 센다.
- [ ] 카페 북측 W1 2,400 mm와 W2 4,800 mm가 가벽 양쪽에 분리되어 있다.
- [ ] 카페 바 3,600 × 700 mm, 백바 3,600 × 600 mm와 싱크·머신·쇼케이스를 확인한다.
- [ ] 세 중첩 이미지에서 수정 영역 밖의 선·문자·가구가 일치한다.

## 생성과 합성·검수의 역할
- 이미지 AI: 가구·문 이동의 부분 후보를 생성합니다.
- 이미지 편집기·CAD 레이어 또는 실제 Python 연산: 원래 Crop 위치로 합성하고 원본 배열과 영역 밖 변화를 확인합니다.
- PlanOverlay 슬라이더: 실제 전후 파일을 겹쳐 사람이 관찰합니다. 색 차분 PNG는 코드가 실제로 계산한 결과를 사용합니다.
- 아직 합성을 완료하지 못했다면 제공된 6석 전체 결과 PLAN-BASE-01-result.png로 D2 이동을 이어가고, 자신의 부분 출력을 전체 완성본으로 표시하지 않습니다.
