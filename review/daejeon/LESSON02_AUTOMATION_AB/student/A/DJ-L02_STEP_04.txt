앞 단계의 같은 프로그램에 app/ui/의 로컬 브라우저 화면과 외부 폴더 가져오기를 실제로 연결해 주세요.
START.bat 실행 후 http://127.0.0.1:4174/에서 감시 상태, 폴더별 파일 수, 최근 처리·오류, 99_분류확인 대기 목록을 보여 주세요. 사용 중인 포트나 다른 프로세스를 임의 종료하지 마세요.
대기 파일은 사람이 분류를 선택해 이동하게 하고, 00_수집함 직접 입력도 그대로 유지해 주세요.
Windows 실제 폴더 선택과 폴더 경로 입력을 제공해 주세요. 선택한 외부 폴더만 읽기 전용으로 목록 확인한 뒤, 사용자가 가져오기를 누르면 최상위 일반 파일을 00_수집함으로 복사해 기존 감시·분류 흐름에 연결해 주세요. 외부 원본의 내용·이름·위치는 변경하지 마세요.
하위 폴더·링크·임시파일은 제외하고 건너뜀·읽기 오류를 표시해 주세요. 명시적으로 선택한 외부 폴더 읽기 이외에는 실습 루트 밖에 접근하거나 쓰지 마세요.
STOP.bat과 화면 종료는 이 프로그램만 정상 종료하게 하고, Node.js 준비·실행·입력·수동 선택·종료·한계를 쉬운 README로 정리해 주세요.
자동 분류·사람 선택·외부 가져오기·종료를 실제 확인하고, 실패하거나 확인하지 못한 동작을 성공으로 쓰지 마세요.
