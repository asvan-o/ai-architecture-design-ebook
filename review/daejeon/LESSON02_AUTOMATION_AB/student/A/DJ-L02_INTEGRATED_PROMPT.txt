작업 루트는 그 폴더 안의 AI_파일자동정리입니다. 이미 같은 프로그램이나 업무 파일이 있으면 덮어쓰지 말고 먼저 알려 주세요.

구조
START.bat / STOP.bat, app/watcher.js, classifier.js, file-manager.js, rules.json, app/ui/, data/와 사용방법 README를 만들어 주세요. 시스템 Node.js로 실행하며 별도 유료 서비스나 외부 AI API를 쓰지 않습니다.
00_수집함, 00_원본보관, 01_CAD도면, 02_BIM건축모델, 03_레퍼런스, 04_이미지결과, 05_3D모델, 06_포인트클라우드, 07_문서, 08_영상, 09_데이터, 10_압축파일, 11_디자인소스, 99_분류확인을 구성해 주세요.

분류 규칙
수집함 최상위 파일을 감시하고 직접 분류 확장자를 먼저 적용해 주세요.
.dwg/.dxf→01_CAD도면, .rvt/.ifc/.skp→02_BIM건축모델, .blend/.fbx/.abc→05_3D모델, .e57/.las→06_포인트클라우드, .docx/.txt/.md→07_문서, .mp4/.mov→08_영상, .xlsx/.csv/.json→09_데이터, .zip/.7z→10_압축파일, .psd/.ai→11_디자인소스.
PNG·JPG·PDF 등 애매한 확장자는 파일명 단서만 비교합니다. floorplan/elevation→01_CAD도면, ref/material/lighting→03_레퍼런스, render/final→04_이미지결과, report/proposal→07_문서입니다.
영문 단서는 구분자로 나뉜 단어 전체를 비교하고, 같은 분류 단어끼리는 충돌로 보지 마세요. 서로 다른 분류 단서가 겹치거나 단서가 없거나 미등록 확장자이면 99_분류확인으로 보내 주세요. 파일 내부 의미를 분석해 강제로 분류하지 마세요.

안전장치
처리 전 00_원본보관에 먼저 복사하고 SHA-256으로 보관본을 확인한 뒤 작업 복사본을 옮겨 주세요. 실패하면 입력·원본을 유지하고 오류를 보여 주세요.
같은 이름·다른 내용은 _v02, _v03으로 저장하고 덮어쓰지 마세요. 동일 SHA-256은 중복을 알리고 추가 보관·출력하지 마세요. 입력에 남은 동일 중복을 한 실행 중 반복 처리하거나 로그를 계속 늘리지 마세요.
.tmp/.part/.crdownload, ~$ 시작 파일, 하위 폴더·링크는 제외하고 복사 중인 파일은 상태가 안정될 때까지 기다려 주세요.

화면과 가져오기
START.bat으로 http://127.0.0.1:4174/ 로컬 UI를 열고 감시 상태·폴더별 수·처리/오류 기록·99_분류확인 목록과 수동 분류 선택을 보여 주세요. 포트 충돌은 이유를 알리고 다른 프로그램을 종료하지 마세요.
00_수집함 직접 입력과 함께 Windows 실제 폴더 선택·폴더 경로 입력을 제공합니다. 명시적으로 선택한 외부 폴더만 읽기 전용으로 목록을 확인하고, 가져오기 버튼을 누르면 최상위 일반 파일만 수집함으로 복사해 같은 분류 흐름으로 처리해 주세요.
외부 원본은 이동·삭제·이름/내용 변경하지 마세요. 제외·복사·읽기 오류를 표시하고, 허용한 외부 폴더 읽기 이외에는 루트 밖을 검색·수정하지 마세요.
STOP.bat과 UI 종료로 이 프로그램의 감시·처리만 정상 종료해 주세요. 실행 중인 다른 Node.js·Blender·서버는 건드리지 마세요.
