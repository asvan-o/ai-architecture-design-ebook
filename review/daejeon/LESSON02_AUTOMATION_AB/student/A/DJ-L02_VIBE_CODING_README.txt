건축 프로젝트 파일 자동 정리 프로그램 · 단계별 제작 안내

1. 실습 환경
Windows의 쓰기 가능한 빈 실습 폴더를 Codex 등 로컬 파일 생성·실행 권한이 연결된 코딩 에이전트에 연결합니다.
일반 웹 채팅의 코드 답변은 로컬 파일 생성·실행과 다릅니다. Node.js는 이번 로컬 프로그램을 실행하는 환경입니다.

2. 두 가지 진행 방법 중 하나 선택
단계별 방법: 같은 폴더·같은 대화에서 DJ-L02_STEP_01.txt → STEP_02 → STEP_03 → STEP_04 순서로 실행합니다.
각 요청은 실제 구현 지시입니다. 만들어진 기능을 짧게 실행해 보고 관찰한 오류를 이어서 전달합니다.
통합 방법: 새 빈 폴더에서 DJ-L02_INTEGRATED_PROMPT.txt 하나로 전체 기능을 구현합니다.
4단계를 완료했다면 통합 예시문으로 같은 프로그램을 다시 만들지 않고 요구사항 대조용으로 읽습니다.
표현과 생성 코드가 달라도 폴더·규칙·원본 보호·사람 확인·실행 결과를 기준으로 비교합니다.

3. 제공 완성 프로그램 사용
직접 만든 프로그램의 구현을 기다리는 대신 제공 프로그램 ZIP으로 같은 기능을 실행해 볼 수 있습니다.
직접 만든 프로그램과 제공 프로그램은 별도 폴더에 둡니다. 두 프로그램을 동시에 실행하지 않습니다.
제공 예제는 수업용 기능 검증을 거친 자료이며, 이 짧은 요청문을 한 번 넣어 똑같이 생성했다는 기록은 아닙니다.
실행·입력·수동 분류·종료는 DJ-L02_FILE_SORTER_README.txt를 따릅니다.

4. 확인할 것
SORT_TEST 11개만 00_수집함에 넣어 기준표와 화면을 비교합니다. README와 manifest는 넣지 않습니다.
자동 분류 9개, 처음 99_분류확인으로 보내는 image001.png / scan003.pdf 2개가 기준입니다.
사람이 파일 한 개의 용도를 선택한 뒤 이동 폴더를 확인하고 STOP.bat으로 종료합니다.
분류 시험용 .blend/.abc는 실제 모델·캐시가 아니며 lighting_ref_3000K.jpg도 측정·보증 자료가 아닙니다.
파일 내부 의미를 이해하는 AI 분류가 아니고 확장자·파일명 규칙 기반입니다. 실제 업무 원본 대신 복사본을 사용합니다.
