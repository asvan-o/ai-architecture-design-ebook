======================================================================
건축 용역 착수계 · 반복 행정서류 4종 자동 생성기 (AI_착수계자동작성)
======================================================================

1. 이 프로그램은 무엇인가요?
- 용역명·발주처·계약금액·착수/준공일·참여기술자를 한 번만 입력하면
  [서식 1] 용역 착수신고서(변경착수신고서)
  [서식 2] 책임기술자(총괄건축사) 선임계
  [서식 3] 분야별 참여기술자 명단
  [서식 4] 보안각서
  4종 서류를 한 번에 계산·동기화해 주는 로컬 업무 자동화 프로그램입니다.
- 실행 중 OpenAI/클라우드 API를 전혀 호출하지 않으므로 실행 크레딧이 0원입니다.

2. 실행 방법 (두 가지 중 편한 방법 선택)
- 방법 A (권장 · 서버 모드): START.bat 더블클릭 → 브라우저에서 http://127.0.0.1:4175/ 자동 열림
  (Node.js LTS 22.x 이상 환경에서 output/ 폴더 버전 보존 저장까지 모두 동작)
- 방법 B (무설치 · 즉시 열람): AI_착수계자동작성_단일실행본.html 더블클릭
  (Node.js가 없는 PC에서도 계산·검증·4종 미리보기·Word(.doc) 다운로드·A4 인쇄 가능)

3. 종료 방법
- STOP.bat을 더블클릭하거나 열려 있는 검은색 콘솔 창을 닫습니다.
- 이미 4175 포트를 다른 실습 프로그램이 사용 중이면 임의로 다른 업무 앱을 종료하지 마세요.

4. 원본 보호 및 사람 최종 검수 원칙
- 자격번호·개설신고번호·변경사유 누락, 날짜 역전, 부가세 미확정 항목은 프로그램이 임의로 지어내지 않고
  [사람 확인(검수 대기)] 상태로 분리해 경고를 표시합니다.
- output/ 폴더 저장 시 기존 파일을 덮어쓰지 않고 동일 SHA-256이면 중복 안내, 변경본이면 _v02, _v03을 붙입니다.
- 발주기관 고유 표지 양식·예정공정표·자격증 사본 첨부 및 실제 직인 날인은 사람이 최종 마감합니다.
