제2차시 바이브 코딩 실습 안내 · 착수계·반복 행정서류 4종 자동 생성기
======================================================================

1. 왜 이 실습을 하나요?
- 건축사사무소에서 매 용역 착수·설계변경·연장 때마다 반복 작성하는
  착수신고서·책임기술자 선임계·참여기술자 명단·보안각서의 오타(금액 한글 표기,
  부가세, 과업일수, 서류 간 용역명 불일치)를 로컬 자동화 도구로 해결합니다.
- Codex 크레딧은 "프로그램을 처음 만들고 고칠 때"만 소량 사용하고,
  완성된 생성기를 매일 실행할 때는 AI 크레딧이 0원입니다.

2. 진행 경로 선택 (둘 중 하나만 선택하세요)
- 경로 A · 단계별 제작(권장 학습): 빈 폴더 연결 후 DJ-L02_DOC_STEP_01.txt ~ 04.txt를
  같은 대화창에 순서대로 입력하며 실행·보완합니다.
- 경로 B · 한 번에 통합 제작(크레딧 절약형): 새 빈 폴더에서
  DJ-L02_DOC_INTEGRATED_PROMPT.txt 1개만 입력해 전체 구조를 한 번에 구현합니다.

3. 실행 및 검증
- 완성 후 DOC_TEST 폴더의 6개 시나리오 JSON을 불러와
  자동 조립 완료(4건)와 사람 확인·검수 대기(2건)가 기준표와 일치하는지 확인합니다.
