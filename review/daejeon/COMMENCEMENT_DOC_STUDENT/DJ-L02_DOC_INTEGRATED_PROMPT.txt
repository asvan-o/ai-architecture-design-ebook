현재 연결된 빈 실습 폴더 안에 건축 용역 착수계·반복 행정서류 4종 자동 생성 프로그램(AI_착수계자동작성) 전체를 한 번에 실제 구현하고 검증해 줘.

[1. 목표와 크레딧 절약 원칙]
- 용역명·발주처·계약금액·기간·기술자 정보를 1회 입력하면 ① 용역 착수신고서(변경착수신고서), ② 책임기술자 선임계, ③ 분야별 참여기술자 명단, ④ 보안각서 4종을 동시 조립하는 로컬 웹 프로그램(http://127.0.0.1:4175)을 만든다.
- 실행 중에는 외부 AI 모델을 호출하지 않는 순수 Node.js 표준 모듈 기반 규칙 프로그램으로 작성해 실행 크레딧 소모를 0원으로 유지한다.
- 현재 연결한 실습 폴더 루트 밖의 파일은 읽거나 수정하지 않는다.

[2. 폴더·파일 구조(Hierarchy)]
- START.bat / STOP.bat / README.txt
- app/calculator.js (한글 법정 금액 "일금 ...원정" 변환, 부가세포함·별도 계산, 착수~준공 총 N일간 계산)
- app/validator.js ("자동 조립 완료" vs "사람 확인(검수 대기)" 판정)
- app/templates.js (서류 4종 HTML/Word 조립, 서류별 페이지 분리 및 다인원 유동 페이지 확장, 검수 대기 표시)
- app/rules.json (필수 항목·신고 구분·임시파일 제외 규칙)
- app/server.js + app/ui/ (127.0.0.1:4175 화면, 탭 전환, A4 페이지 분리 인쇄, Word .doc 페이지 분리 내보내기)
- samples/ (테스트용 JSON), projects/ (입력 원본 보관), output/ (생성 결과 저장)

[3. 자동 처리 규칙 vs 사람 확인(검수 대기) 경계]
- 자동 처리: 숫자 금액의 한글 금액 변환·부가세 10% 연산, 착수일~준공일 일수 산출, 4종 서식 공통 항목 일괄 동기화, A4 PDF 및 Word(.doc) 합본 출력 시 서류마다 독립 페이지 분리(선임계·참여기술자 인원 증가 시 표 머리글 반복 및 유동 페이지 확장)
- 사람 확인(검수 대기): 필수 항목·건축사 자격번호·개설신고번호 누락(임의 생성 금지), 준공일 < 착수일 날짜 역전, 변경착수계의 변경사유·당초 기준 누락, 부가세 미확정

[4. 원본 보호와 버전·중복 관리]
- 외부에서 가져오는 JSON은 읽기 전용으로만 읽어 원본을 보존한다.
- projects/ 및 output/ 저장 시 기존 파일을 덮어쓰지 않고, 동일 SHA-256 해시는 중복 안내로 건너뛰며 내용이 바뀐 경우 _v02, _v03 버전을 부여한다.
- 임시파일(.tmp, .part, .crdownload, ~$)은 대상에서 제외한다.

[5. 완료 확인]
- 정상 착수계 샘플과 누락·날짜역전 샘플을 넣어 계산·검수 분기·버전 저장·서류별 페이지 분리·4175 화면 렌더링이 모두 정상 작동하는지 자체 테스트 후 결과를 요약해 줘.
