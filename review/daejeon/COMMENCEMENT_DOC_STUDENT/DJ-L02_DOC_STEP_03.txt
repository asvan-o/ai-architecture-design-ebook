Step 2까지 만든 같은 프로그램에 행정서류 4종 동시 조립 템플릿과 페이지 분리·원본 보호·중복/덮어쓰기 방지 기능을 이어서 구현해 줘.

[Step 3 추가 구현 사항]
1. 서류 4종 동시 조립기 및 문서별 페이지 분리(app/templates.js):
   - 한 번 입력한 프로젝트·계약·기술자 정보를 공유해 아래 4종 서식을 동시에 생성해 줘:
     ① 용역 착수신고서(변경착수계일 때는 용역 변경착수신고서 제목과 당초 대비 변경 사유란 자동 표시)
     ② 책임기술자(총괄건축사·분야별책임) 선임계 (선임 대상이 여러 명이면 인원수만큼 페이지 자동 추가)
     ③ 분야별 참여기술자 명단 표 (인원이 늘어 여러 장으로 넘어갈 때 표 머리글 반복 및 행 잘림 방지)
     ④ 보안각서
   - 하나의 파일로 합본 출력(A4 PDF 인쇄 및 Word .doc)할 때 각 서류가 줄바꿈으로 붙지 않고 반드시 새 페이지에서 시작하도록 페이지 나누기(CSS break-before: page 및 Word 인쇄 모양 물리 페이지 브레이크)를 적용해 줘.
   - "사람 확인(검수 대기)" 상태일 때는 서식 상단에 검수 대기 초안 배너와 누락 위치를 눈에 띄게 표시해 줘.
2. 원본 보호·버전·SHA-256 중복 방지:
   - projects/와 output/에 저장할 때 기존 파일을 절대 덮어쓰지 마.
   - 바이트 단위 SHA-256 해시가 기존 저장본과 완전히 같으면 반복 생성하지 않고 중복 안내만 반환해 줘.
   - 같은 용역명인데 금액·일정 등 내용이 바뀌었으면 _v02, _v03 순서로 새 버전을 붙여 저장해 줘.
   - 폴더 안의 임시파일(.tmp, .part, .crdownload, ~$로 시작하는 파일)은 목록과 처리 대상에서 제외해 줘.
3. 확인 방법:
   - 동일 입력 2회 저장 시 SHA-256 중복 안내가 나오고, 금액 수정 후 저장 시 _v02 파일이 생성되는지 실제로 검증해 줘.
