# 제7차시 체크리스트와 한국어 Prompt

## Gaussian 시점의 확인 영역과 추정 영역 나누기

[목적]
Gaussian 캡처에서 후속 현실화에 사용할 시점을 고릅니다.

[맥락]
단일 입력에서 생성한 3D 표현은 보이지 않던 면을 추정합니다. 보기 좋은 결과와 원자료로 확인되는 정보를 구분합니다.

[입력자료]
실제로 확보한 Gaussian 캡처 한 장입니다. 원래 입력 이미지를 함께 확보한 경우에만 추가 첨부합니다.

[작업 단계]
벽·개구부·가구의 보이는 관계를 정리합니다. 번짐·늘어짐·구멍이 보이는 곳을 짚습니다. 원래 입력이 있으면 같은 위치를 대조합니다. 후속 렌더링에 쓸 수 있는지 이유를 적습니다.

[조건·제한]
원래 입력이 없으면 보존 여부를 확정하지 않습니다. 보이지 않는 후면·측면의 실제 구조와 치수를 만들지 않습니다. 없는 시점 이미지를 분석했다고 쓰지 않습니다.

[출력 형식]
확인되는 요소 / 추정·불명확한 요소 / 현실화 시 유지할 기준을 표로 정리합니다.

[검토 기준]
캡처에서 실제 보이는 내용인지, 원자료 대조가 필요한 항목을 분리했는지 사람이 확인합니다.

### 짧은 실행 요청
첨부한 Gaussian 캡처에서 보이는 벽·개구부·가구 관계와 번짐·늘어짐을 나누어 정리해 주세요. 원래 입력이 없으면 보존 여부를 확정하지 마세요. 확인되는 요소, 추정·불명확한 요소, 현실화 시 유지할 기준을 표로 주세요.

## Gaussian 캡처를 현실적인 공간 제안 이미지로 정돈하기

[목적]
첨부한 Gaussian 캡처를 현실적인 건축·실내 제안 이미지로 정돈합니다.

[맥락]
새 설계를 만드는 단계가 아닙니다. 선택한 시점의 공간 관계를 유지하며 입자 번짐과 흐릿한 재질 표현을 정돈합니다.

[입력자료]
gaussian-source.png 한 장을 기준으로 사용합니다.

[작업 단계]
카메라·벽체·주요 개구부·가구의 위치를 먼저 읽습니다. 같은 구도에서 경계 번짐을 줄이고 유리·목재·패브릭·바닥의 표현을 자연스럽게 정돈합니다. 가려진 부분은 억지로 드러내지 않습니다.

[조건·제한]
카메라 시점, 보이는 매스 비례, 주요 개구부와 가구 위치를 유지합니다. 새 층·문·창·가구·텍스트·로고를 추가하지 않습니다. 자료가 흐린 곳의 실제 재료·치수는 확정하지 않습니다.

[출력 형식]
같은 시점의 현실형 이미지 한 장을 출력합니다.

[검토 기준]
원본과 나란히 놓고 벽·창·문·가구 수와 위치, 새 요소 발생, 번짐 감소를 따로 확인합니다. 선명함만으로 구조 보존을 판정하지 않습니다.

### 짧은 실행 요청
첨부한 Gaussian 캡처를 같은 카메라와 공간 비례로 현실적인 실내 이미지 한 장으로 정돈해 주세요. 보이는 벽·주요 개구부·가구 위치를 유지하고 입자 번짐과 재질 경계만 자연스럽게 정리하세요. 새 층·문·창·가구·글자·로고를 추가하거나 가려진 부분을 보이게 옮기지 마세요.

## 선택한 의자 한 개의 연결부만 국소 보정하기

[목적]
실내 렌더링에서 선택한 의자 한 개의 연결부를 정돈합니다.

[맥락]
전체 장면을 다시 설계하지 않습니다. 지정 영역의 변화와 다른 영역의 변화를 따로 검토합니다.

[입력자료]
route-01.png 한 장입니다. 대상은 화면 가운데 뒤쪽 검은 식탁 앞의 검은 의자입니다.

[작업 단계]
검은 등받이의 직선 가장자리와 양쪽 지지대가 자연스럽게 이어지도록 정돈합니다. 의자의 위치·크기·색·재질·방향을 유지합니다.

[조건·제한]
대상 의자 밖의 소파·테이블·화분·다른 의자·주방·문·창·천장·조명을 바꾸지 않습니다. 카메라와 전체 밝기·색감을 유지합니다. 사람·글자·로고를 추가하지 않습니다. 가려진 가구를 옮기지 않습니다.

[출력 형식]
같은 구도의 보정 이미지 한 장을 출력합니다.

[검토 기준]
등받이·지지대 연결과 의자 위치를 먼저 확인하고, 소파 직물·주변 의자·조명 등 비대상 변화도 원본과 비교합니다. 요청 밖 변화가 있으면 성공으로 숨기지 않고 기록합니다.

### 짧은 실행 요청
첨부 이미지 가운데 뒤쪽 검은 식탁 앞의 검은 의자 한 개만 보정해 주세요. 등받이 가장자리와 양쪽 지지대를 자연스럽게 연결하되 위치·크기·색·방향을 유지하세요. 소파·다른 가구·주방·문·창·조명·카메라·전체 밝기는 바꾸지 마세요. 같은 구도로 한 장 출력하세요.

## 원본·Bicubic·SR1033 결과를 같은 위치에서 대조하기

[목적]
업스케일의 선명도 개선과 원본에 없던 정보 발생을 구별합니다.

[맥락]
SR1033은 이미지를 세 배로 확대하는 초해상화 도구입니다. 자연어 요청은 실행 명령이 아니라 결과 검토에 사용합니다.

[입력자료]
render-source.png, render-source_Bicubic_3x.png, render-source_SR1033_3x.png를 순서대로 첨부합니다.

[작업 단계]
전체 구도와 벽·가구 위치를 대조합니다. 같은 창틀·의자 연결부·직물 부분을 확대해 경계와 반복 무늬를 살핍니다. 개선·변경·확인 불가를 구분합니다.

[조건·제한]
더 선명해졌다는 이유로 실측 치수·제품·문자·시공 정보를 확정하지 않습니다. 보이지 않는 디테일의 복원을 사실이라고 말하지 않습니다.

[출력 형식]
비교 위치 / 원본 / 일반 확대 / AI 확대 / 사람의 판단을 표로 정리합니다.

[검토 기준]
같은 부분을 대조했는지, 과도한 윤곽·새 패턴·색 변화와 실제 개선을 나눴는지 확인합니다.

### 짧은 실행 요청
첨부한 원본, Bicubic 세 배, SR1033 세 배 결과를 같은 창틀·의자 연결부·직물 위치에서 비교해 주세요. 선명도 개선과 새 패턴·색·윤곽 변화를 나누어 표로 정리하고, 실제 치수·재료·문자를 복원했다고 단정하지 마세요.

- 업스케일: 동일 위치에서 일반 확대와 AI 확대의 윤곽·무늬·색 비교

실측·법규·구조·시공 판단은 원자료와 전문 검토를 기준으로 합니다. 없는 PLY·6시점·GPU 실행을 완료했다고 기록하지 않습니다.
