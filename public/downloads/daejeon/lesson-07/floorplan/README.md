# 자체 제작 1층 오피스 · 도면 판독과 관계도

1. DJ-L07-Office-Floorplan-Original.pdf를 내려받아 NotebookLM 소스로 추가합니다. 텍스트 레이어가 있으며 가로 정방향입니다. 실명·문·창·치수의 기준은 이 원본입니다.
2. 판독 결과를 원본과 교차검수해 KEEP·REVIEW·UNKNOWN 기준표를 만듭니다.
3. DJ-L07-clean-line-preprocess.txt로 선화 정리를 시도하고, 필요하면 images/01-clean-line.jpg로 이어갑니다.
4. 비교 선화의 이사실·13연승, 입체의 사장실·이사실·계단창·1.5인승은 의도한 교육용 문자 오류입니다. 실제 AI가 해당 오류를 냈다는 증빙이 아니며 원본·기준표로 교정합니다.
5. 원본 PDF·기준표·선화를 Top View 입력으로 함께 사용합니다. 입체의 재료·높이·빛은 가정이며 문·공간 관계는 원본에서 확인합니다.
6. 공간 관계는 원본 PDF·기준표만으로 검증하고 Graphviz DOT로 구조화합니다. 두 PNG는 같은 DOT의 세로·가로 렌더링이며 실제 NotebookLM/ChatGPT 서비스 화면이 아닙니다.

외부 공유 도면·개인 프로젝트 PDF·내부 DOCX는 넣지 않습니다. 이 교육용 도면은 실측·실시설계·법규·구조·승강기 성능을 확정하지 않습니다. 축선·치수·레벨은 교육용 설정이며 계단참 EL+2,200은 확정 층고가 아닙니다.

## 크기와 가구를 읽는 기준
- 축선 기준 최대 범위는 24×16m이고, 중심선 다각형 면적은 348㎡(약 105평)입니다. 최대 외곽 직사각형 384㎡와 혼동하지 않습니다. 이는 교육용 설정이며 법정 바닥면적·실측 면적이 아닙니다. 외부 휴게데크는 별도입니다.
- 소장실 책상은 1,800×800mm, 8인 회의테이블은 3,200×1,200mm입니다. 회의 의자는 북측 4석·남측 4석으로 정돈했습니다. 수정된 2D PDF·PNG·클린 선화 및 office-geometry.json이 가구 치수 기준입니다.
- 기존 Top View·Gaussian 입력과 그 파생 3D 이미지는 그대로 보존한 분위기·공간 관계 참고본입니다. 가구 크기를 수정한 3D 결과로 읽지 않습니다.
- JSON의 room bounds는 위치를 찾는 범위이며 복도·실 경계의 일부 범위가 겹칩니다. bounds 면적의 단순 합산으로 면적을 산정하지 않습니다.
- 계단의 UP/DN·계단참 EL+2,200과 승강기 출입면은 판독·동선 대조를 위한 교육용 설정입니다. 층고·층간 연결·단수·유효높이·승강기 규격·구조·법규 적합성이 검증된 실시설계가 아닙니다.
