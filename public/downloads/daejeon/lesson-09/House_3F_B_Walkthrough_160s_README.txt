1. 다운로드와 열기
이북 제9차시의 '160초 카메라 동선 포함 Blender 파일 다운로드'를 누르고 PC에 저장합니다.
기존 Blender 작업은 먼저 저장한 뒤 File → Open에서 위 .blend 파일을 엽니다.
기존 주택 원본을 덮어쓰지 말고 이 별도 파일로 실습합니다.
재질 이미지 7개가 파일 안에 포함되어 있어 별도 텍스처 폴더를 지정할 필요가 없습니다.

2. 재생
처음 열 때 재질 준비를 잠시 기다립니다.
카메라 화면이 아니면 3D 화면 위에 마우스를 두고 Numpad 0을 누릅니다.
숫자패드가 없으면 View → Cameras → Active Camera를 선택합니다.
이미 카메라 화면이면 다시 전환하지 않아도 됩니다.
타임라인 위에 마우스를 두고 Space: 재생/일시정지. ▶ 버튼으로도 재생할 수 있습니다.
일시정지 후 Shift + ←: 처음으로. 현재 프레임 숫자 입력: 원하는 시점으로 이동.
재생이 느리면 3D 화면에서 Z → Solid로 바꾸거나 창 크기를 줄여 동선을 확인합니다.

4. 동선 수정과 파일 구성
Outliner의 [Step 5] B_Walkthrough_160s 컬렉션을 펼칩니다.
Cam_B_Walkthrough_160s: 재생 카메라. 위치와 회전이 프레임별 키프레임으로 저장되어 있습니다.
Target_B_Walkthrough_160s: 시선 확인용 타깃.
B_Rails_8_Shots: 8개 구간을 보여 주는 확인용 경로선.
경로선이나 타깃을 움직이는 것만으로 카메라 애니메이션이 바뀌지는 않습니다.
동선 수정은 카메라 키프레임을 편집하거나 수정 구간의 위치·시선을 다시 계산해 반영합니다.
경로선과 타깃은 렌더 이미지에 표시되지 않습니다.
기존 Astra 주택의 형상·가구·문·창·재질·조명·확인용 카메라는 보존했습니다.

5. 웹 뷰어와의 관계 및 한계
웹 뷰어의 160초 동선을 별도 Blender 파일로 옮긴 예제입니다.
HTML 파일을 열거나 기존 모델 ZIP을 받는 것만으로 이 애니메이션이 추가되는 것은 아닙니다.
웹 뷰어와 현재 Astra 원본은 옥상 파라펫 일부 끝단 길이에 약 20cm 차이가 있으며, 이 파일은 Astra 원본 형상을 유지합니다.
카메라 3,840프레임과 컷을 제외한 연속 프레임 사이 선분을 Blender 메시와 대조했으며 표면 관통은 없었습니다.
이 결과는 카메라 점·선분 검사입니다. 사람의 몸통·발밑·실제 건축 안전을 보증하지 않습니다.
Blender와 웹 뷰어는 조명·유리를 다르게 표현할 수 있습니다. 별도 최종 MP4 렌더 파일은 아닙니다.
