3층 주택 B안 — 160초 시네마틱 워크스루

실행 방법
1. House_B_Walkthrough.html을 Chrome 또는 Edge로 엽니다.
2. 모델이 표시되면 재생 버튼을 누릅니다.

House_B_Walkthrough.html 한 파일에 모델, 재질 이미지, 카메라 경로와
Three.js를 포함했습니다. 인터넷 연결, Blender 설치, 별도 서버가 필요 없습니다.
이 HTML 파일 하나를 다른 폴더나 컴퓨터로 복사해 열 수 있습니다.
9차시 다운로드는 독립 실행 HTML과 이 안내문입니다. 실행 도우미나 별도 assets 폴더 없이도 작동합니다.

화면과 조작
- 왼쪽: 전체 건물, 이동 경로, 현재 카메라 위치와 바라보는 방향
- 오른쪽: 실제 이동 카메라의 시점
- 재생 / 일시정지, 처음으로, 시간 슬라이더, 구간 버튼
- 전체 건물 / 현재 층 단면 전환 및 경로 표시 켜기·끄기
- 왼쪽 화면 드래그: 회전 / 휠: 확대 / 우클릭 드래그: 이동
- Space: 재생·일시정지 / 좌우 화살표: 1초 이동 / Home: 처음으로
- 기본 속도 1배가 원래 계획한 느린 160초입니다. 0.75배, 0.5배도 지원합니다.

- 126초: 닫힌 테라스 유리문을 유지한 채 테라스 쪽 카메라로 컷 전환
컷 사이에는 카메라 이동이나 경로 선을 보간하지 않습니다.

사용 모델
House_3F_Full_Complete_Astra.fbx에서 변환한 실제 주택 모델입니다.
메시 1,469개, 사용 재질 17개, 재질 이미지 7개를 GLB로 포함했습니다.
원본 FBX와 건축 형상, 문 상태는 변경하지 않았습니다.
현재 층 단면은 왼쪽 검토 화면에만 적용되며, 오른쪽 카메라는 전체 형상을 봅니다.

경로 점검
각 연속 촬영 구간을 원본의 모든 메시 삼각형과 대조했습니다.
카메라 주변 반경 0.18m, 최대 약 0.02m 간격의 샘플과
그 사이의 선분을 검사해 표면 교차와 설정 여유 위반이 없는지 확인합니다.
상세 수치와 방법은 뷰어의 경로 점검 결과에서 확인합니다.
이 결과는 설정된 카메라 경로와 카메라 주변 공간에 대한 검사입니다.
사람 몸 전체의 통행 가능성이나 실제 드론의 비행 안전을 판정하는 자료는 아닙니다.
카메라 경로·화각·클리핑 거리·모델을 수정하면 다시 검사해야 합니다.

9차시 실습에 활용하기
원하는 공간 순서 → 이동과 시선 구분 → 높이·속도·컷 조건 → 여러 안 비교
→ 선택 후 제작 → 시간 슬라이더로 확인 → 시간과 현상을 적어 수정 요청
순서로 진행합니다. 처음부터 모호하게 '멋지게 찍어줘'라고만 요청하기보다
'어디로 이동하고 무엇을 얼마나 오래 볼지'를 구간별로 설명합니다.
수정 요청 예: '48초 계단 회전이 답답해. 위치 경로와 시선 목표를 따로 확인하고,
회전을 더 일찍 시작해줘. 통로가 좁으면 컷으로 나누고 수정 구간을 다시 검사해줘.'
