# 주택 도면·3D 대조 체크리스트
- [ ] 같은 버전의 도면과 house-design.json을 사용한다.
- [ ] 외곽 12×9m와 축선·원점·층 높이를 확인한다.
- [ ] 바닥판이 계단 구멍을 덮지 않는다.
- [ ] 문 경첩·문짝·손잡이가 한 세트이고 벽·가구와 간섭하지 않는다.
- [ ] 창문과 방문 위치에 실제 벽 구멍이 있다.
- [ ] 거실·주방·현관·욕실·세탁실의 필수 가구가 남아 있다.
- [ ] 침대·베개·협탁·책상·의자·옷장·욕조·샤워 가구가 남아 있다.
- [ ] 3층 실내와 서측 야외 데크가 구분된다.
- [ ] 옥상 소파·식탁·의자·파라솔·화단·식물이 남아 있다.
- [ ] FBX·GLB를 새 파일에서 다시 불러와 형상·축·단위·가구·재질을 대조한다.
- [ ] 계단·난간·피난·실내 치수의 실무 검토를 별도로 남긴다.
