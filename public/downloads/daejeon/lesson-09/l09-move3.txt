목적
선택한 B안으로 약 160초의 느리고 부드러운 주택 카메라 워크스루를 만들어줘.

맥락
현관 밖에서 시작해 내부의 1·2·3층을 경험하고 테라스 밖에서 건물 전체를 드러내는 분할 촬영이야. 건물·가구는 완성 상태로 고정해줘.

입력자료
House_3F_Full_Complete_Astra.fbx 또는 [선택한 실제 모델]. 앞서 고른 동선안과 모델 확인 결과. 원본을 보존하고 별도 결과 파일을 만들어줘.

작업 단계
1. 현관 밖 → 1층 거실·주방 → 실제 계단 → 2층 홀 → 실제 계단 → 3층 스튜디오 → 테라스 → 외부 상승·후진 → 건물 전체 순서로 샷을 나누어줘.
2. 이 주택의 막힌 2층 계단 도착부와 닫힌 3층 D301 문 전후는 컷으로 연결해줘. 원본 벽·유리·난간을 삭제하지 마. 다른 모델에서는 실제 형상을 다시 확인해줘.
3. 실내는 현재 바닥·계단 진행면 + 약 1.6m 눈높이, 이동 위치와 시선을 따로 제어해줘. 계단참에서 감속하고 다음 진행 방향을 조금 먼저 바라봐줘.
4. 외부의 빈 공간에서 드론 상승을 시작하고 집을 바라보며 후진·상승·완만한 원호 이동으로 건물 전체를 보여줘. 마지막 구도는 4–5초 유지해줘.
5. 각 연속 샷의 전체 경로와 프레임 사이 이동을 점검하고, 수정한 구간은 다시 검사해줘.
6. 실제 모델을 쓰는 브라우저 뷰어를 만들고 전체 모델·경로·카메라 위치 화면과 카메라 시점 화면을 함께 보여줘. 재생·일시정지·시간 슬라이더·컷 표시를 넣어줘.

조건·제한
벽·기둥·가구·닫힌 유리·난간·천장·지붕을 통과하지 않게 해줘. 컷 사이에는 이동을 보간하지 마. 속도를 올려 160초에 억지로 맞추지 말고, 실제 거리상 부족하면 컷 조정이나 길이 변경을 설명해줘. 급회전·급가속·화면 기울임·갑작스러운 줌은 피하고 충돌을 시선 숙이기로 숨기지 마. 문을 바꿔야 한다면 별도로 설명해줘.

출력 형식
실행 가능한 HTML, 사용한 모델 또는 변환한 GLB, 샷별 시간·이동·시선·컷 목록, 점검 결과, 파일 경로와 여는 방법. FBX·GLB와 브라우저 재생 데이터의 역할도 설명해줘.

검토 기준
실제 모델 사용, 요구한 공간 순서, 눈높이·속도·시선, 재생/일시정지/시간 이동을 확인해줘. 충돌 검사는 사용한 모델·샷·간격·여유 반경·결과·미검사 항목을 기록해줘. 카메라 경로 점검과 사람이 걸을 수 있는 발밑·몸통 점검은 구분하고, 수행한 검사보다 강하게 안전을 단정하지 마.
