목적
실제 모델의 불일치를 근거 도면별로 분리하고 수정 범위를 좁힙니다.

맥락
먼저 검수 보고만 작성합니다. 사람이 수정 범위를 확인하기 전에는 기존 모델을 자동 수정하지 않습니다.

입력자료
자신의 권한 있는 평면·단면·입면과 현재 모델/렌더, 객체 치수·검증 로그.

작업 단계
1. 계단 경사 하부면과 방화문 경로를 측정하고 기존 감사 모델의 샘플 최소 2.112m(약 2.11m)와 현재 모델의 측정값을 분리합니다. 이 수치를 법규 적합 판정으로 사용하지 않습니다.
2. P/D 외곽·위생기구·실내 유효 공간을 평면에서 대조합니다.
3. 옥탑 스크린의 정면 폭·평면 깊이·지붕/리턴 접합을 세 방향에서 확인합니다.
4. 층간 경계의 외장 연속면·중복 면·뒤집힌 노멀·커터 잔존을 검사합니다.
5. 관찰 / 실제 측정 / 확인 불가 / 수정 제안을 구분하고 객체명과 위치를 기록합니다.
6. 승인된 항목만 국소 수정할 후속 요청문을 작성합니다.

조건·제한
정면 렌더만으로 후면 연결이나 구조 안전을 확인 완료로 쓰지 않습니다. 기존 다른 차시·모델·원자료를 건드리지 않습니다.

출력 형식
항목별 Before 상태·근거·수정 후보·After 검증 방법·남은 가정 표.

검토 기준
미실행을 PASS로 쓰지 않고 원인·변경 객체·보호 대상·재검증 범위가 명확한지 확인합니다.
