목적
완성된 집이 배포 도면의 벽·문·창·가구와 맞는지 확인합니다.

맥락
새 형태를 만들지 않고 먼저 관찰·실제 측정·확인 불가를 나눠 보고합니다.

입력자료
자체 제작 모던 3층 단독주택 도면 6파일과 house-design.json. 외곽 12.0×9.0m, 남서쪽 1층 바닥=(0,0,0), X 축선=[0,4.5,8,12], Y 축선=[0,3.5,6,9], 바닥 높이=0/3.2/6.2m, 지붕 9.0m, 상단 9.6m. 미터 단위로 사용합니다. 현재 집 모델과 위·사선·눈높이 캡처.

작업 단계
1. 층별 폴더를 켜고 끄며 도면과 같은 방향으로 봅니다.
2. 외곽·층 높이·계단 구멍·문 경첩·창 위치를 대조합니다.
3. 소파·식탁·침대·욕실·옥상 가구의 수와 방향을 대조합니다.
4. 벽과 겹친 가구·문 앞 장애물·계단 연결 오류는 부위와 위치를 적습니다.
5. 사람이 수정 범위를 확인한 뒤 해당 부분만 고칠 후속 요청문을 제안합니다.

조건·제한
실무 원도면이나 외부 가구 모델은 사용하지 않습니다. 다른 프로젝트가 열려 있으면 삭제·덮어쓰기 없이 멈춥니다. 확인되지 않은 값은 교육용 가정으로 기록합니다. 실제 설계·구조·피난·난간·계단·인허가 적합성을 보증하지 않습니다. 이전 상업시설의 치수·검증값을 이 주택에 적용하지 않습니다.

출력 형식
일치 / 다름 / 추가 확인 표와 해당 화면·위치·측정 방법.

검토 기준
실행하지 않은 항목을 완료로 쓰지 않고 도면·모델·가구의 버전이 같은지 확인합니다.
