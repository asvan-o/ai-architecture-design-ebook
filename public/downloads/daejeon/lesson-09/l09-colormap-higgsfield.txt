목적
일반 재질 영상과 프레임별로 카메라가 일치하는8초 컬러맵 미리보기를 만듭니다. 이후AI 영상 도구에 부위별 재질 의도를 설명하는 참고 자료로 사용합니다.

맥락
일반 영상은 이미 확인한 주택 카메라를 사용합니다. 원본 Blender의 재질은 보존하고 별도 사본이나 파생 씬에서 컬러맵을 만듭니다. Higgsfield 변환 자체를 실행하는 요청은 아닙니다.

입력자료
확정된8초 일반 카메라 씬, 주택의 객체·부재 목록, 아래 색상표. 24fps, 1~192프레임을 사용합니다. 일반 영상과 카메라 위치·시선·렌즈·키프레임·해상도·화면 비율·객체 표시 상태를 동일하게 유지합니다.

작업 단계
1. 일반 씬을 복제하고 프레임마다 카메라의 위치·회전·렌즈와 표시 부재가 일치하는지 비교합니다. 컬러맵용 경로를 따로 추정하거나 다시 만들지 않습니다.
2. 실제 객체와 면의 역할을 확인해 단색으로 구분합니다. 벽#2563EB(37,99,235), 바닥#10B981(16,185,129), 천장·슬래브 하부·지붕 덮개#F59E0B(245,158,11), 문·문틀#EF4444(239,68,68), 유리#06B6D4(6,182,212), 계단·디딤판·챌판·계단 난간#9333EA(147,51,234), 가구·조경#EC4899(236,72,153), 창틀·기타#64748B(100,116,139)로 지정합니다. 배경은#F1F5F9(241,245,249)로 두며 객체 분류에서 제외합니다. 역할이 섞인 객체는 필요한 면을 나누고 매핑 목록을 기록합니다.
3. 컬러맵 유리는 불투명하게 만듭니다. 질감·그림자·반사 하이라이트가 부위색을 바꾸지 않도록 단색 Emission 또는 Workbench Flat을 사용하고, 얇은 윤곽선으로 경계를 읽기 쉽게 합니다. 색 관리 설정과 실제 출력 색을 확인합니다.
4. 일반 영상과 컬러맵을 각각8초·192프레임 MP4로 저장합니다. 두 버전 모두1·96·192프레임 PNG를 저장합니다.
5. 같은 프레임을 나란히 비교해 형상·카메라·표시 부재가 같고 표면 표현만 달라졌는지 확인합니다. 프레임 수·길이·카메라 대조 결과와 색상별 객체 수를 기록합니다.

조건·제한
원본 PBR 재질·기하·가구 배치를 수정하거나 덮어쓰지 않습니다. 가려진 실내색을 보여 주려고 벽을 숨기거나 유리를 투명하게 하지 않습니다. 건축6색을 가구·조경에 섞어 쓰지 않습니다. 윤곽선·안티앨리어싱·MP4 압축 경계의 픽셀은 원래HEX와 다를 수 있으므로 PNG와 색상표를 함께 제공합니다. 이 색상표는 수업용 약속이며 Higgsfield의 자동 정밀 마스크 규격이 아닙니다. AI로 재질을 바꾼 뒤 형상·경계·카메라가 유지되는지는 별도로 검토합니다.

출력 형식
house_astra_camera_normal_8s.mp4, house_astra_camera_colormap_8s.mp4, 두 버전 시작·중간·끝 PNG6장, 색상별 의미표, 새 작업 파일 또는 재현 스크립트, 프레임별 카메라 일치·색상 매핑 검사 결과.

검토 기준
192프레임 전체의 카메라가 일반 영상과 일치하는지, 원본 재질과 모델이 보존됐는지, 유리가 불투명한 단색인지, 부위가 올바른 색으로 분류됐는지 확인합니다. 실제 제작·검사한 내용과 아직 수행하지 않은AI 재질 변환을 구분해 보고합니다.
