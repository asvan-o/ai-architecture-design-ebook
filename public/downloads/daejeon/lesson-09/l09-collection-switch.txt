목적
층과 카메라를 따로 켜고 끌 수 있도록 작업을 나눕니다.

맥락
새 주택 실습 파일에서 현재 장면·객체·미터 단위를 먼저 확인합니다.

입력자료
자체 제작 모던 3층 단독주택 도면 6파일과 house-design.json. 외곽 12.0×9.0m, 남서쪽 1층 바닥=(0,0,0), X 축선=[0,4.5,8,12], Y 축선=[0,3.5,6,9], 바닥 높이=0/3.2/6.2m, 지붕 9.0m, 상단 9.6m. 미터 단위로 사용합니다.

작업 단계
1. [Step 1] 1F_House_Interior, [Step 2] 2F_House_Rooms, [Step 3] 3F_Roof_Facade, [Step 4] Cameras_Lighting을 만듭니다.
2. 바닥·벽·문·창·가구는 해당 층 폴더에만 넣습니다.
3. 눈 아이콘을 꺼 위층을 잠시 숨기고, 카메라 아이콘으로 렌더에서도 숨길지 구분합니다.
4. 지붕만 잠깐 숨겨 3층 실내를 보는 방법을 보여 줍니다.

조건·제한
같은 이름의 기존 폴더를 중복 생성하지 않습니다. 폴더를 끈다고 객체를 삭제하지 않습니다. 실무 원도면이나 외부 가구 모델은 사용하지 않습니다. 다른 프로젝트가 열려 있으면 삭제·덮어쓰기 없이 멈춥니다. 확인되지 않은 값은 교육용 가정으로 기록합니다. 실제 설계·구조·피난·난간·계단·인허가 적합성을 보증하지 않습니다.

출력 형식
폴더 이름·객체 수·현재 켜짐 상태와 화면 캡처.

검토 기준
1층만 / 1·2층 / 전 층 표시를 각각 확인하고 기존 부재가 사라지지 않았는지 봅니다.
