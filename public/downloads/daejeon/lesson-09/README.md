이번 작업에서 직접 설계·작도·모델링·재질 제작한 교육용 자료입니다.

수강생 배포·다운로드·수정 실습을 위해 마련했습니다. 실제 인허가·구조·피난·계단·난간 안전 검토를 대체하지 않습니다.

## 설계 기준
외곽 12×9m / 축선 X=0,4.5,8,12m / Y=0,3.5,6,9m.
1층 바닥 0m / 2층 3.2m / 3층 6.2m / 실내 지붕 9m / 지붕 낮은 벽 상단 9.6m.
동측 3층 실내, 서측 열린 옥상 테라스. 계단과 세부 가구 위치·교육용 가정은 house-design.json을 확인합니다.

2층: 안방 침대·베개 2개·협탁·등·옷장·화장대, 침실 2 침대·책상·의자·책장, 가족실 소파·탁자·책장, 욕조·샤워·세면대·변기, 발코니 가구.
3층: 라운지 소파·홈바·스툴 2개·책상·수납, 야외 소파·식탁·의자·파라솔·목재 데크·화단·식물.

## CAD 방식 도면 읽기
- 도면 묶음에는 평면·단면·4면 입면 PNG 6장과 같은 버전의 DXF 6장이 들어 있습니다.
- 굵은 선은 절단되는 벽체, 중간 선은 보이는 부재, 가는 선은 가구·치수·보조 표시에 사용합니다. 축선, 북쪽 표시, 문·창 번호, 단면 위치와 층 높이를 함께 대조합니다.
- 평면도의 문짝 직선과 개폐호는 서로 다른 표시입니다. 계단의 진행 화살표·계단참·층별 바닥 구멍을 3D와 함께 확인합니다.
- DXF는 교육용 2D 선·문자 자료이며 단위는 mm입니다. DWG 원본이나 BIM·파라메트릭 건축 객체가 아닙니다. CAD 프로그램에서 단위·글꼴·선종류·축척을 확인한 후 사용합니다.
- PNG를 화면에 맞춰 축소한 크기는 실제 인쇄 축척과 다릅니다. 치수 문자와 축선 좌표를 기준으로 확인합니다.
- 도면과 Blender 모델은 같은 house-design.json을 사용하며, 입면 창호와 계단 단면은 실제 모델과 추가 대조합니다. 자체 검증은 독립 검수나 실제 설계·시공 승인과 다릅니다.

## Astra·Argon 비교 모델 열기
- Models ZIP의 `Astra/`와 `Argon/`에 같은 주택을 표현한 두 버전이 나뉘어 있습니다. 각 폴더의 `models/`는 Blender 원본·FBX·GLB, `renders/`는 같은 8개 시점의 이미지, `verification/`은 실제 모델·내보내기 재검증 기록입니다.
- 두 `.blend`를 각각 열어 같은 이름의 카메라와 층별 컬렉션을 선택합니다. 동일한 12×9m 도면·배치 기준과 수업 요청 조건을 사용했으며, 벽·문·창·계단·가구의 위치를 먼저 대조한 뒤 색·빛·부재의 세부 표현을 비교합니다.
- 두 결과 모두 223개 기하·동선 검사와 FBX·GLB 빈 장면 재불러오기 검증을 통과했습니다. 같은 검증 항목을 통과했다는 뜻이며, 두 파일의 모든 부재·재질·빛 설정이 같다는 뜻은 아닙니다.
- Astra의 작은 기준점(Empty)과 관계선은 기본 화면에서 숨겼습니다. 필요한 경우 뷰포트 표시 설정에서 다시 켤 수 있습니다. 기준점 자체나 부모-자식 연결을 삭제한 것은 아닙니다.
- Argon `.blend`와 렌더는 제공된 기준 산출물을 그대로 복사했습니다. 배포용 FBX·GLB는 원본의 색·이미지 재질이 전달되도록 별도 파일로 다시 내보내고 새 빈 장면에서 재검증했습니다. 원본 모델·기존 내보내기 파일은 수정하지 않았으며, 변환 범위와 원본·파생 파일 해시는 `verification/house-argon-export-provenance.json`에 기록했습니다. 다른 프로그램에서는 빛·유리 표현이 달라질 수 있습니다.
- 모델을 열 때 각각 별도 파일로 작업하고 상대 버전이나 원본을 덮어쓰지 않습니다.
- PNG는 해당 카메라의 렌더 결과입니다. 다른 프로그램에서 FBX·GLB를 열면 조명·유리·색이 다르게 보일 수 있습니다. 검증 결과는 실제 설계·시공·구조·법규 승인과 구분합니다.

## Blender에서 보기
원본 .blend를 엽니다. 층별 폴더의 눈 아이콘으로 위층을 잠시 숨깁니다.
[Step 1] 1F_House_Interior / [Step 2] 2F_House_Rooms / [Step 3] 3F_Roof_Facade / [Step 4] Cameras_Lighting.
FBX·GLB에는 세 층과 실내외 가구·재질이 들어 있습니다. 카메라·조명·배경판은 전달용 형상에서 제외했습니다.
Blender 원본에는 확인용 카메라 8개와 조명이 있습니다. 브라우저 B안의 이동은 HTML 뷰어가 제어합니다. Blender 이동 레일·영상이 필요하면 별도 작업 결과 형식으로 요청합니다.

## 내보내기 확인
검증한 Blender에서 FBX·GLB를 각각 새 빈 장면으로 다시 불러와 부재 수·외곽·층·이미지 재질 7종을 대조했습니다.
FBX/GLB에 포함된 재질은 색·거칠기·이미지 표현을 전달합니다. 다른 프로그램의 빛·유리·노출 표현은 달라질 수 있습니다.
옮긴 프로그램에서 단위·축·계단 구멍·문·가구·텍스처를 다시 확인합니다.

## 검토할 한계
도면의 방 배치·치수는 교육용 설계 설정입니다. 구조·설비·법규·동선·가구 사용 여유는 별도 설계 검토가 필요합니다.
특히 계단의 단 높이·너비·계단참·난간 값은 적법성·안전 승인 값이 아닙니다.
이전 상업시설의 치수와 측정 기록은 이 주택에 승계하지 않습니다.

## 같은 경로의 일반 영상과 컬러맵 영상
- `house_astra_camera_normal_8s.mp4`: 실제 Astra 주택 모델에서 렌더한 8초 일반 재질 영상.
- `house_astra_camera_colormap_8s.mp4`: 같은 카메라 위치·시선·렌즈·프레임을 사용하는 8초 단색 구분 영상.
- 두 영상은 24fps·192프레임입니다. 시작 1f·중간 96f·끝 192f PNG를 같은 위치에서 비교합니다.
- `house_astra_normal_start/mid/end.png`, `house_astra_colormap_start/mid/end.png`는 교재의 PNG 다운로드에서 받습니다.
- `l09-camera-8s.txt`는 출발·이동 순서, 길과 시선, 높이·속도, 충돌 방지, 길이·확인 프레임을 정하는 카메라 요청문입니다.
- `l09-colormap-higgsfield.txt`는 새로 복사해 쓸 컬러맵 제작 요청문입니다. 두 TXT 모두 Prompts ZIP에 포함됩니다.
- 기존 약 160초 B안 브라우저 프리뷰와 이번 8초 Blender 렌더 영상은 별도 예시입니다. 8초 안에 모든 층을 방문한 것으로 설명하지 않습니다.
- B안의 전체 160초 동선은 원본 HTML을 보존한 채 실제 Three.js 카메라 화면을 7개 MP4로 나누어 기록했습니다. Blender에서 다시 렌더한 영상과는 구분합니다. 현관 12초 → 거실·주방 26초 → 1~2층 계단 22초 → 2층 20초 → 2~3층 계단 22초 → 3층 24초 → 테라스·바깥 조망 34초 순서이며, 원본 0~160초 구간을 빠짐없이 이어 볼 수 있습니다.
- 카메라 길과 바라보는 곳을 분리해 정한 뒤, 같은 동선을 두 재질 버전에 적용합니다. 원본 Astra 모델과 Models ZIP의 PBR 재질은 보존합니다.
