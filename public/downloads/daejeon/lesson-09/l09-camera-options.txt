목적
첨부한 실제 주택 모델을 확인하고, 카메라 동선을 먼저 3안 제안해줘.

맥락
FPV처럼 공간이 이어지는 느낌을 원하지만 속도는 빠르지 않게, 관객이 공간을 볼 수 있는 시네마틱한 움직임을 원해.

입력자료
House_3F_Full_Complete_Astra.fbx 또는 [내 모델 파일]. 원본을 보존해줘. 목표 길이는 약 160초야.

작업 단계
1. 모델 단위·층 높이·입구·실제 계단과 계단참·외부 출구·문 열림 상태를 확인해줘.
2. 현관 밖 → 1층 거실·주방 → 계단 → 2층 가족실·홀 → 계단 → 3층 스튜디오 → 서측 테라스 → 외부 상승·후진 → 건물 전체 순서로 제안해줘.
3. 각 구간에서 이동 방향과 바라볼 대상을 따로 적어줘.
4. A 연속 원테이크, B 자연스럽게 이어지는 분할 촬영, C 명확한 컷 편집을 비교하고 추천안과 이유를 알려줘.

조건·제한
실내는 현재 바닥·계단 진행면 + 약 1.6m 눈높이, 화면 수평 유지, 코너에서 감속. 급가속·급회전·갑작스러운 줌을 피하고 마지막 전체 구도는 4–5초 유지해줘. 벽·닫힌 유리·기둥·가구·난간·지붕을 통과하는 길을 만들지 마. 막힌 곳은 문제 위치와 우회 또는 컷을 제안해줘. 시간이 부족하면 속도를 올리기보다 컷이나 길이 조정을 제안해줘.

출력 형식
3안 비교표: 이동 순서, 시선, 목표 시간, 속도감, 전환 지점, 모델에서 확인한 제약, 아직 검사하지 않은 부분. 추천안 1개.

검토 기준
실제 모델에 근거했는지, 내가 말한 공간 순서가 유지되는지 확인해줘. 이 단계는 제안만 하고 내가 선택한 뒤 제작해줘.
