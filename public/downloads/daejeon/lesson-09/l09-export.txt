목적
모든 층과 실내외 가구·재질을 포함한 전달용 파일을 만듭니다.

맥락
Blender 원본을 먼저 다른 이름으로 저장하고 전달용 사본을 만듭니다.

입력자료
자체 제작 모던 3층 단독주택 도면 6파일과 house-design.json. 외곽 12.0×9.0m, 남서쪽 1층 바닥=(0,0,0), X 축선=[0,4.5,8,12], Y 축선=[0,3.5,6,9], 바닥 높이=0/3.2/6.2m, 지붕 9.0m, 상단 9.6m. 미터 단위로 사용합니다. 완성한 집과 내가 지정한 저장 폴더.

작업 단계
1. 1·2·3층 폴더를 모두 켭니다. 벽·문·창·계단·가구·식물·재질이 선택 범위에 있는지 확인합니다.
2. 바닥 배경판·불필요한 조명은 모델 내보내기 대상에서 제외합니다.
3. File → Export → FBX에서 .fbx, glTF 2.0에서 단일 파일 .glb를 저장합니다.
4. FBX는 이미지 재질을 함께 넣고, GLB는 재질을 포함하는 설정을 확인합니다.
5. 각각을 새 빈 파일로 다시 불러와 가로·세로·층 높이와 가구·재질이 남았는지 확인합니다.

조건·제한
같은 이름의 기존 파일을 덮어쓰지 않습니다. 확장자만 바꾸어 변환하지 않습니다. 대상 프로그램마다 재질의 빛·유리 표현이 다를 수 있습니다. 실무 원도면이나 외부 가구 모델은 사용하지 않습니다. 다른 프로젝트가 열려 있으면 삭제·덮어쓰기 없이 멈춥니다. 확인되지 않은 값은 교육용 가정으로 기록합니다. 실제 설계·구조·피난·난간·계단·인허가 적합성을 보증하지 않습니다.

출력 형식
저장 파일의 실제 위치·크기, 다시 불러온 부재·재질 목록과 누락 여부.

검토 기준
세 층·지붕·계단·문·창·실내외 가구와 이미지 재질을 대조하고, 내보내기 실패를 성공으로 쓰지 않습니다.
