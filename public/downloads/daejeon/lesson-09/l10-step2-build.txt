목적
Step1 위에 2층 슬래브·의원·복도·화장실·기둥·창호·계단을 별도 컬렉션으로 추가합니다.

맥락
검토한 Step1을 보호하고 새 객체는 [Step 2] 2F_Interior_Rooms에만 만듭니다. 실행 전 파일·컬렉션·객체 상태를 조회합니다.

입력자료
권한 있는 2층 평면·단면·입면, 확정 기준표, Step1 모델. 예제 2F FL=4.50, 바닥 슬래브 Z4.50~4.70, 지붕 기준 Z8.50. 1층 바닥 기준과 슬래브 상면 기준의 차이를 기록합니다.

작업 단계
1. 슬래브를 만들되 계단 보이드에는 면을 채우지 않습니다.
2. 의원·우측 복도·남녀 화장실을 기준표대로 구획합니다. 의원 328.9㎡는 자료 표기값이며 모델 순면적 계산 결과와 구분합니다.
3. X11.10,15.85,20.60 / Y8.40 기둥을 두고 1층 기둥과 수직 대조합니다.
4. P/D는 외부 돌출 X26.20~26.90,Y9.90~11.10에 둡니다. 남자 소변기 2개는 북벽, 남녀 세면대는 중앙 공유벽에 각각 1개씩 두되 도면을 다시 대조합니다.
5. 2층→옥상 계단은 동측 +Y 상승 → 북측 참 → 서측 -Y 상승으로 연결합니다. 예제 2층 참 Z6.50을 검토하고 통과 높이를 측정합니다.
6. 정면 3베이와 서측 연속 수평 띠창을 만들고 위아래 창 끝선을 비교합니다.
7. Step3을 끈 Top Ortho·절단 사선에서 내부 구획과 보이드를 검수합니다.

조건·제한
다른 프로젝트가 열려 있으면 삭제하거나 덮어쓰지 말고 중단합니다. 원본 자료를 수정하지 않습니다. 도면에서 확인하지 못한 항목은 교육용 가정 또는 미확정으로 표시합니다. 구조·법규·소방·시공 적합성을 보증하지 않습니다. Step1 객체를 재생성하지 않고 변경 전후를 비교합니다. 위생기구 배치는 배관·접근성·설비 검증 완료를 뜻하지 않습니다.

출력 형식
추가 객체/컬렉션, 슬래브 보이드, 기둥 정렬·P/D·위생기구·계단 검수표와 렌더.

검토 기준
1층 보호, Z레벨과 바닥 기준, 계단실 오픈부, P/D 외부 위치, 띠창 정렬, 누락·간섭을 확인합니다.
