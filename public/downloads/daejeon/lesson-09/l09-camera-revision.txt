목적
프리뷰에서 발견한 한 구간의 문제를 수정하고 수정 전후를 비교해줘.

맥락
전체 동선안은 유지하고 문제가 있는 구간만 조정하고 싶어. 아래 시간은 내가 실제로 본 시간으로 채울게.

입력자료
결과 파일: [뷰어/작업 파일]
시간 또는 샷: [예: 72–76초 / 2층 홀]
내가 본 현상: [시선 급회전 / 벽과 너무 가까움 / 높이가 튐 / 너무 빠름]
원하는 변화: [구체적으로 적기]

작업 단계
1. 해당 구간의 위치 경로·바라보는 목표·속도를 각각 확인해 원인을 설명해줘.
2. [예: 이동 경로는 유지하되 회전을 더 일찍 시작해 나누기 / 빈 통로 중앙으로 경로 옮기기 / 계단참에서 감속]를 적용해줘.
3. 연결할 실제 통로가 없으면 억지로 통과시키지 말고 컷을 제안해줘.
4. 수정 전후의 같은 시간 또는 같은 위치 화면을 비교하고, 수정 구간 전체의 간섭을 다시 검사해줘.

조건·제한
다른 층·가구·재질과 선택한 동선 순서는 유지해줘. 벽·유리·난간을 지우거나 시선을 숙여 문제를 숨기지 마. 길이가 바뀌면 새 시간표와 변경 이유를 알려줘.

출력 형식
원인 설명, 바꾼 항목, 수정 전후 화면, 새 파일, 재검사 결과와 남은 미확인 항목.

검토 기준
처음 지적한 현상이 줄었는지 같은 구간에서 비교하고, 앞뒤 샷의 연결·속도·높이에 새 문제가 생겼는지 확인해줘.
