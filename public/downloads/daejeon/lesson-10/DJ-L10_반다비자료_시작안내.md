# 제10차시 · 자료를 넣는 순서와 파일 사용법

## 오늘의 핵심 흐름
1. 노트북 A에 발주처 원자료를 넣고 신축 건물의 프로젝트 조건 기준서를 만듭니다.
2. 이 기준서를 노트북 B로 옮기고, ChatGPT 검색 보조로 필요한 공식 법규·조례·별표를 찾습니다.
3. 노트북 B에서 조건 기준서와 공식 법규를 대조해 1차 법규검토 체크리스트를 만듭니다.
4. ChatGPT가 공식 근거를 독립적으로 다시 찾아 오류·누락을 검증하고, 보완 후 사람이 최종 확인합니다.

## 기준서를 옮길 때 파일 번호가 바뀌는 이유
파일 번호는 작업 순서를 알아보기 위한 이름입니다. 노트북 A의 발주처 원자료(A01~A07)를 정리해 만든 결과 기준서를 A99(결과물 99번)라고 부릅니다. 사람이 검토한 이 기준서를 노트북 B의 첫 입력자료로 그대로 옮길 때 이름 앞부분만 B00(출발점 00번)으로 바꿉니다. A99와 B00은 내용이 100% 같은 파일입니다. 노트북 B에서 조건과 공식 법규를 대조해 만든 결과 체크리스트는 B99라고 부릅니다. 99는 결과물 구분 번호이며 최종 법적 적합성 승인이라는 뜻이 아닙니다.

## 노트북 A에 먼저 넣을 원자료
- A01_건축기획서.pdf
- A02_지구단위계획보고서.pdf
- A03_건축물등에관한결정도.pdf
- A04_설계공모_질의답변.pdf
- A05_기존국민체육센터_설계개요_층별면적표.pdf
- A06-1_기존국민체육센터_부지배치도_01.pdf
- A06-2_기존국민체육센터_부지배치도_02.pdf
- A07_현황측량도.pdf

원자료는 7개 번호 그룹이며 실제 PDF는 8개입니다. A06 배치도가 2개이기 때문입니다. 기존 국민체육센터의 도면·수치는 신축 건물 조건과 별도로 관리합니다. A03 결정도·A07 측량도는 도면형 PDF이므로 AI가 읽지 못한 값은 원문을 확대해 사람이 확인하고, 판독 불가를 임의로 채우지 않습니다.

## 긴 프롬프트는 외워 쓰지 않습니다
먼저 ChatGPT 등에 “내 자료와 목적에 맞는 프롬프트를 짜줘”라고 짧게 요청하고, 초안의 대상 건물·미확정 조건·출처·출력 표를 사람이 다듬습니다. AI가 길게 썼다고 정확해지는 것은 아닙니다. 본문의 13개 프롬프트마다 실행 플랫폼, 준비 자료, 목적, 구체적인 이유, 짧은 요청 예시가 있습니다. 원문 프롬프트의 본문은 변경하지 않았습니다.

## 실행 순서
- 노트북 A: 공통 규칙 → 자료 역할·조건 분석 → 오류 재검토 → 조건 기준서 표 정리. 최종 결과를 사람이 검토한 뒤 노트북 B로 옮깁니다.
- ChatGPT: 역할 설정 → 기준서 기반 공식 법규 검색. AI의 답변은 법적 근거가 아니므로 공식 원문을 실제로 확보합니다.
- 노트북 B: 전달한 조건 기준서 + 필요한 공식 조문·별표 → 가능한 검토 범위 → 첫 체크리스트.
- ChatGPT: 기준서 + 첫 체크리스트를 받아 독립 교차검증. 법규 문제는 공식 원문을 보강하고, 프로젝트 사실 문제는 노트북 A와 조건 기준서부터 고칩니다.
- 노트북 B 보완 → ChatGPT 재검증 → 사람 최종 확인.

## 자료 선택과 실제 사용 시 주의
- 조문 TXT는 공식 조문·부칙의 텍스트 사본입니다. 별표 그림·표는 포함하지 않으므로 해당 별표 원본을 함께 준비합니다.
- HWP/HWPX는 지원 편집기로 열어 확인한 뒤 PDF로 내보내 지원되는 형식으로 업로드합니다. 서산시 부설주차장 설치기준은 조례 제10조의 별표6입니다.
- 기존 수업 코드 B06은 2쪽 발췌본입니다. 전체 건축법 시행령은 N07 조문과 별표를 사용합니다. B08 TXT는 개정이유·개정문이므로 전체 조문은 N09와 별표1을 사용합니다.
- B07의 이전 보관 원본 파일명에는 20250811이 적혔지만 본문 시행일은 2025.12.10입니다. 제공 파일명은 본문 시행일을 명시했으며 원본 내용은 바꾸지 않았습니다.
- B90은 2023 화재안전 참고책이며 현행 NFPC/NFTC의 대체 근거가 아닙니다. 대상 설비가 정해지면 해당 공식 기준을 추가 확보합니다.
- 자료 확인일 2026-10-19. 2025 공모조건과 현재 시행 법규를 혼용하지 않고, 적용일·부칙·경과조치를 확인합니다.
- 도면 ZIP은 공식 원본 DWG 4종입니다. A05~A07 PDF는 수업 아카이브 판본이며 신축 확정 설계도면이 아닙니다.
- 강사 DOCX는 AI 작성 예시이며 정답·공식 기준서·최종 적합성 검토서가 아닙니다. 먼저 직접 작성한 결과와 비교합니다.
- 분할 완료 대지 경계, 최신 결정고시·토지이용계획확인서, 확정 신축 도면/면적표, 피난·주차·BF·소방 상세설계가 없는 항목은 추가 확인으로 남깁니다.
