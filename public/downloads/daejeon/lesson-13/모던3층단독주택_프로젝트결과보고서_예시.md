# 모던 3층 단독주택 설계 제안 결과보고서

## 1. 도면에서 출발한 프로젝트 목적

교육용 주택 도면과 기준 모델을 읽고, 1층 공용 생활·2층 사적인 휴식·3층 다락과 루프탑을 연결하는 제안서를 기획했다. 외곽 12×9m, 레벨 0 / 3.2 / 6.2 / 9 / 9.6m는 모델 입력값이다. 대지·주소·실제 건축주 요구·법정 면적은 미확정이다. 108㎡는 외곽 직사각형 계산값이며 법정 건축면적이나 연면적이 아니다.

## 2. 콘셉트와 설계 브리프

콘셉트는 WARM CONTEMPORARY HOUSE, 밝은 석재와 오크의 온기로 층별 생활을 잇는 집으로 제안했다. 함께 머무는 1층, 조용히 쉬는 2층, 실내외 휴식의 3층을 프로그램의 우선순위로 삼았다. 이는 교육용 생활 시나리오이며 실제 발주처 협의를 완료한 사실은 아니다.

## 3. 내외장재·가구·조명 무드보드

Warm Ivory, Travertine Beige, Natural White Oak, Soft Taupe Fabric, Deep Walnut Accent의 5색 팔레트를 정했다. 실제 재료 참조의 트라버틴·크림 마이크로시멘트·화이트오크·다크 월넛·타지마할 이미지를 원본 수정 없이 크롭해 4개 재료 묶음으로 조합했다. AI로 생성한 실내 히어로와 소파·식탁·아일랜드·조명 컷아웃을 에디토리얼 그리드에 배치했다. 이 선택은 색·질감·적용 위치의 제안이며 제품 규격·가격·성능·시공 확정은 아니다.

## 4. 입체·조닝·렌더의 발전

실제 이미지 생성 도구에 기준 렌더를 첨부해 층별 실사형 아이소메트릭과 실내·외관·석양 이미지를 제작했다. 목재 결·석재·패브릭·채광을 보강했으며, 생성 과정에서 식재·소품·문 디테일이 달라질 수 있어 원도면과 기준 모델을 비교 근거로 보존했다. 3층 컷어웨이의 라운지 가구·책장·계단 노출과 새로운 아이레벨의 가려진 면은 AI 해석이 포함된 공간 제안이다. 정밀 CAD나 실제 시공 모델로 확정하지 않았다.

주간과 석양은 같은 주간 제안 이미지를 입력해 시간대와 조명을 바꿔 비교했다. 이는 일조·조도 성능 시뮬레이션이 아니다. 층별 조닝은 공용 → 사적 → 루프탑 생활 관계를 색으로 설명하며 피난 경로 검증과 구분했다. 기존 Blender 모델의 형상과 도면은 수정하지 않았다.

## 5. 로고·포트폴리오·PPT 제작

ARCHI NOVA의 건축 라인 심볼과 영문·한글 워드마크를 새로 생성했다. 6단계 설계 설득 논리를 8장 발표와 4장 보드로 전개했다. AI 레이아웃 시안과 실제 질감 자료를 참고하고 제목·캡션·표·로고·조닝은 편집 가능한 객체로 조합했다. 표지는 여백과 외관 히어로로 구성하고, 내지는 재료·입체·도면·법규 검토 근거를 연결했다. 로고는 교육용 제안이며 상표 등록이나 권리 승인을 받은 브랜드가 아니다.

## 6. 검수와 설계 판단

채택: 도면의 층별 생활 관계와 따뜻한 재료 콘셉트. 수정: 단색 스와치와 자료 목록 중심 설명을 실제 질감·가구·설계 이유 중심으로 바꿨다. 보류: 생성 이미지의 정밀 개구부·법정 면적·피난·구조의 확정 판정. 제외: 잘못된 문자·형상과 측정하지 않은 성과 표현. 실제 실행하지 않은 법규·구조 검증을 완료했다고 기록하지 않았다.

제10차시의 프로젝트 조건 기준서 → 공식 근거 → 독립 교차검증 → 사람 판단 방법을 후속 검토 구조로 적용한다. 반다비체육관의 법규 결론은 이 주택에 전용하지 않는다. 대지·용도지역·면적·피난·방화·계단 유효폭·접근성, 구조·설비·재료 성능·시공비는 추가 자료와 전문가 확인이 필요하다.

## 7. 인계와 다음 설계 단계

보드 4장, 편집 원본 PPTX 8장, PDF·PNG, 무드보드·로고·재료 참조·실사형 입체, 결과보고서·의사결정 기록, 원도면·모델·출처·생성 프롬프트·해시를 함께 인계한다. 같은 주택 B안 브라우저 워크스루는 원본 HTML과 사용안내를 포함하며 고화질 MP4 영상과 구분한다.

현재 상태는 review/draft · instructor-review · design-pending이다. 제작자의 기술·시각 검수는 독립 검수나 사용자 최종 승인을 대체하지 않는다. 후속 단계에서는 원도면 대조와 실제 대지·법규·제품 자료를 보완하고 전문가와 적용 여부를 판단한다.
