목적
도면을 읽어 프로젝트 콘셉트와 8장 PPT·4장 포트폴리오의 스토리보드를 만든다.
맥락
교육용 모던 3층 단독주택 또는 사용 권한을 확인한 나의 실무 도면으로 건축주 제안서를 기획한다.
입력자료
첨부 평면·단면·입면, 사용자 요구, 도면에서 직접 확인한 조건을 사용한다.
작업 단계
① 표지·아이덴티티 ② 기획·설계 브리프 ③ 5색 팔레트와 내외장재·가구 무드보드 ④ 평면·아이소메트릭·동선 조닝 ⑤ 모델·입단면·핵심 렌더 ⑥ 법규 검토·설계 개요의 6단계 논리를 세운다. PPT는 표지 → 기획·브리프 → 내외장재·가구 무드보드 → 평면·3D 아이소메트릭·조닝 → 1~2층 공간 → 3층 루프탑·입단면 → 주간·석양 렌더 → 법규·요약 순서의 8장으로 나눈다. 보드는 표지, Intro·무드보드, Overview·입체·동선, Verification·입단면·검토의 4장으로 구성한다.
조건·제한
대지·법정 면적·실제 발주처 요구를 임의로 채우지 않는다. 생활 시나리오와 재료는 설계 제안으로 표시한다. 이미지를 사실 근거와 혼동하지 않는다.
출력 형식
8행 표: 장 번호 / 제목 / 설계 의도 한 문장 / 필요한 도면·무드보드·아이소메트릭·렌더·법규표 / 확인 근거 / 추가 작업. 이어서 4장 보드의 대응표를 쓴다.
검토 기준
도면에서 출발해 기획·재료·공간·검증이 연결되는가, 모든 장에 설계 주장이 있고 이를 보여줄 자료가 있는가를 확인한다.
