목적
8장 발표 제안서의 헤드라인·설계 카피·재료 스펙·검토표 문안을 작성한다.
맥락
건축주에게 공간·재료 선택의 이유를 설명하는 PPT다.
입력자료
확정한 8장 스토리보드, 도면·생성 렌더·무드보드, 실제 치수·레벨과 검토 메모를 사용한다.
작업 단계
표지 → 기획·브리프 → 무드보드 → 평면·조닝 → 1~2층 → 루프탑·입단면 → 주간·석양 → 법규·요약 순으로 쓴다. 각 장에 설계 결론 한 줄, 이유 두 문장, 이미지 캡션과 출처를 제안한다. 스펙 표는 부위 / 제안 재료 / 선택 이유 / 확인할 제품·성능으로 만든다.
조건·제한
외곽 12×9m와 0 / 3.2 / 6.2 / 9 / 9.6m는 교육용 입력값이다. 108㎡를 법정 건축면적·연면적으로 쓰지 않는다. 대지·용도지역·허가·구조·피난은 미확정이면 그대로 남긴다.
출력 형식
8장 문안 표와 편집 가능한 재료표·설계 개요·법규 확인 필요 표. 제목·본문·표는 이미지에 구워 넣지 않고 개별 객체로 만든다.
검토 기준
짧은 문장에 설계 이유가 담기는가, 표·수치·이미지가 같은 도면과 대응하는가, 과장한 성능·법규 결론이 없는가를 확인한다.
